CICS 발표 대본 — 한국어 슬라이드 / 한국어 발표, 총 10분

본문 18장, 목표 발화 9분 20초 + 화면 전환·호흡 여유 40초.
페이지별 시간은 리허설에 맞춰 조정. 부록은 질의응답용.

01. 표지
00:00–00:15 / 15초
안녕하십니까. 3-DOF planar 로봇 매니퓰레이터의 QP 기반 순차적 기구학 제어에 대해 발표하겠습니다. 이것은 짧게 말해, 최종 목표를 바로 추종하기 전에 link의 위치를 순서대로 제어하여 목표 도달을 돕는 방법입니다.

02. 안전한 목표 도달이 필요한 이유
00:15–00:45 / 30초
로봇팔이 물체를 옮기거나 장비를 조작할 때는 원하는 위치와 방향으로 이동하는 것만으로 충분하지 않습니다. 주변 장비와 충돌하지 않으면서 작업을 완료해야 합니다. 사진은 실험실에서 시료를 다루는 mobile robotic chemist의 예입니다. 이런 작업에서는 end-effector뿐 아니라 팔 전체의 안전한 움직임이 필요합니다. 본 연구는 우선 이 요구를 단순한 planar 모델에서 다룹니다.

03. 팔 전체의 충돌 회피와 목표 도달
00:45–01:20 / 35초
여기서는 세 개의 회전 관절을 가진 planar 로봇팔을 관절 속도로 제어합니다. 상태 q는 관절각, 입력 u는 관절 속도이므로 q의 시간 미분이 u가 됩니다. Task는 로봇이 달성할 제어 목표를 뜻합니다. 여기서는 end-effector의 현재 위치 p3와 방향 psi3를 초록색 별의 목표 위치 p d와 화살표의 목표 방향 psi d로 이동시키는 것입니다. 이동하는 동안 팔 전체의 장애물 충돌과 자기충돌을 피하고, 관절각 제한도 만족해야 합니다.

04. 안전 제약: Control Barrier Function (CBF)
01:20–01:55 / 35초
안전 제약에는 Control Barrier Function, CBF를 사용합니다. Link는 두께가 있는 capsule로 모델링합니다. 장애물과의 표면 거리 d는 관절각 q에 따라 달라집니다. 이 거리에서 안전 여유를 빼서 h를 정의하면, h가 0 이상인 configuration들이 safe set입니다. 이 CBF 부등식은 안전 경계에서 h가 더 작아지지 않도록 요구합니다. 자기충돌과 관절각 한계에도 같은 형태의 제약을 적용하고, 전체 안전 제약을 h r로 묶어 표현합니다.

05. CLF--CBF QP 기반 목표 추종
01:55–02:35 / 40초
목표 추종에는 end-effector의 위치 오차와 주기적인 yaw 오차를 합한 Control Lyapunov Function, CLF V를 사용합니다. CLF 부등식은 V의 감소를 요구하며, c는 감소율 계수입니다. Quadratic Program, QP는 입력과 완화 비용을 최소화하면서 CLF, CBF, 관절 속도 제한을 적용합니다. Delta는 CLF 조건만 완화하며 안전 제약은 유지합니다. 이 QP를 매 제어 주기 풀어 처음부터 최종 end-effector pose를 추종하는 방식을 본 연구에서는 Direct라고 부릅니다. 다음 슬라이드에서 이 방식이 목표에 도달하지 못하는 사례를 보겠습니다.

06. Direct 제어가 실패할 수 있는 이유
02:35–03:00 / 25초
CLF는 목표 도달을 유도하지만, 완화변수 때문에 CLF 값의 감소가 항상 강제되지는 않습니다. 이 episode의 Direct는 QP 실행 불가능으로 종료되었습니다. 이와 별개로 Tan 연구는 비목표 평형점을 분석합니다. 목표 도달을 돕는 subtask를 어떻게 구성할지, 관련 연구부터 보겠습니다.

07. 선행 연구와 본 연구의 설계 초점
03:00–03:35 / 35초
각 연구의 설계 초점을 비교하겠습니다. 첫번째 연구는 제약에 대응하도록 task 일부를 해제하고 다시 활성화합니다. 두번째 연구는 CLF–CBF QP를 계층적으로 풀어 상위 task의 성능을 보존합니다. 저희는 subtask의 목표를 어떻게 구성할지에 주목했습니다. 최종 목표를 만족하는 역기구학 해, IK에서 링크별 위치 목표를 만들고, 이를 순차적으로 제어하면 목표 도달을 도울 수 있는지 살펴보았습니다. 다음 슬라이드에서 이 목표들의 구성 방법을 설명하겠습니다.

08. 제안 방법: IK에서 링크 목표 구성
03:35–04:20 / 45초
먼저 최종 end-effector의 위치와 방향을 만족하는 안전한 IK configuration 하나를 선택합니다. 회색 점선이 그 자세입니다. 이 configuration에서 forward kinematics로 link 1과 link 2의 끝점 위치를 계산하면, 파란색 별과 주황색 별로 표현된 목표 위치를 얻습니다. Subtask는 전체 task를 수행하기 위한 단계별 제어 목표입니다. 먼저 각 link의 끝점을 해당 별로 이동시키는 목표를 일시적으로 사용합니다. Sequential은 이 subtask들을 base에 가까운 순서로 실행한 뒤 최종 end-effector pose를 제어합니다. 전체 관절각을 그 IK 해에 고정하는 방식은 아닙니다.

09. Sequential 1단계: 링크 1의 끝점 위치
04:20–04:45 / 25초
이제 link별 CLF를 구분하기 위해 첨자를 붙입니다. 첫 단계의 V1은 파란색 link 1의 끝점과 목표 사이의 위치 오차를 나타냅니다. 다른 link를 고정하는 것이 아니라 관절 속도 입력을 QP로 결정합니다. 장애물과 자기충돌, 관절 한계 제약은 계속 유지합니다. 이때 end-effector의 오차는 증가할 수 있습니다.

10. Sequential 2단계: 링크 2의 끝점 위치
04:45–05:10 / 25초
다음으로 활성 CLF를 V2로 바꾸어 주황색 link 2의 끝점을 목표로 보냅니다. 이때 이전 V1 조건은 해제하므로 link 1이 앞의 목표에서 벗어날 수 있습니다. 안전 제약과 입력 비용은 유지하면서 추종할 link를 바꿉니다. 그림처럼 팔의 배치와 end-effector의 위치가 달라집니다.

11. Sequential 최종 단계: End-effector pose
05:10–05:35 / 25초
마지막 단계는 link 3 끝점인 end-effector의 pose를 제어하므로 CLF를 V3로 표기합니다. 앞서 Direct에서 V로 소개한 함수와 같고, 감소율 계수도 동일합니다. 이 episode에서는 앞의 두 단계로 팔을 재배치한 뒤 위치와 yaw 목표에 도달합니다. 전체 관절각이 선택한 IK 해와 반드시 일치할 필요는 없습니다.

12. 각 단계에서 하나의 CLF만 활성화
05:35–06:15 / 40초
매 제어 주기에는 현재 단계의 QP 하나를 풉니다. V1과 V2는 link 위치 오차의 이차함수이며, V3에는 yaw 항이 추가됩니다. 중간 목표에 도달하거나 정체가 감지되면 이전 link task를 해제하고 다음 CLF를 활성화합니다. 이 그림은 task error에 따른 함수 모양이며 configuration 공간 전체의 지형은 아닙니다. 모든 단계에서 안전 제약과 입력 제한은 동일합니다.

13. 링크 subtask가 도움이 되는 이유
06:15–06:55 / 40초
이 표의 task는 링크 끝점 위치 또는 최종 pose입니다. Task Jacobian J_i는 관절각 변화와 task의 변화를 연결하며, CLF gradient는 아래 식처럼 이 Jacobian을 통해 계산합니다. 특이점을 제외하면 rank는 1, 2, 3이며, 링크 subtask는 뒤쪽 관절로 팔을 재배치할 여지를 남깁니다. 표의 null-space 차원은 scalar CLF 부등식으로 구성한 QP의 실제 가용 방향 수와는 다릅니다. CBF와 입력 제한도 움직임을 제한하므로, 이는 제어 순서의 설계 근거이며 항상 성공한다는 증명은 아닙니다.

14. 모의실험 조건과 성공 기준
06:55–07:30 / 35초
효과를 확인하기 위해 세 link의 길이가 각각 1미터인 모델과 두 개의 원형 장애물을 사용했습니다. 초기 관절각은 모두 0으로 고정하고, 목표 pose와 장애물 배치를 무작위로 생성했습니다. 안전한 IK 후보가 있는 동일한 300개 episode에 두 제어기를 적용했습니다. 제한 시간은 35초입니다. 성공 기준은 위치 오차 0.1미터 이하, yaw 오차 0.1라디안 이하이며, 기록된 장벽함수 최솟값의 허용 기준은 마이너스 0.01미터입니다.

15. 목표 도달 성공률의 향상
07:30–08:10 / 40초
Direct는 216개, Sequential은 253개 episode에 성공했습니다. 성공률은 72퍼센트에서 84.33퍼센트로, 차이는 12.33퍼센트포인트입니다. 실패 원인 중 가장 큰 비중인 timeout이 65개에서 36개로 감소했습니다. QP 실행 불가능과 안전 기준 위반도 일부 남아 있습니다. 따라서 이 결과는 평가한 episode에서 성공률이 개선되었다는 의미이며, 모든 경우의 수렴이나 완전한 안전성을 실증했다는 뜻은 아닙니다.

16. Subtask 전환을 통한 목표 도달 사례
08:10–08:50 / 40초
앞서 확인한 성공률 개선이 어떻게 가능한지, 이 사례를 보겠습니다. Sequential은 먼저 V1, 이어서 V2를 줄이면서 팔의 배치를 바꿉니다. 이 과정에서 최종 end-effector의 오차는 일시적으로 증가하기도 합니다. 다음 단계로 넘어가면 이전 link의 CLF 제약은 해제합니다. 왼쪽 그래프에서 V1이 다시 커지는 것은, 다음 목표를 위해 팔을 다시 움직일 수 있다는 의미입니다. 이렇게 배치를 바꾼 뒤에는 Direct와 동일한 최종 CLF V3를 사용합니다. 오른쪽을 보면 Direct에는 큰 오차가 남지만, Sequential은 목표에 도달합니다. 즉, link subtask는 최종 pose 제어를 시작하는 configuration을 바꾸어, 이 사례에서 목표 도달에 유리한 움직임을 만드는 역할을 합니다.

17. 결론
08:50–09:20 / 30초
하나의 goal IK에서 두 link 목표를 만들고, 이를 일시적인 subtask로 실행한 뒤 최종 pose를 제어했습니다. 동일한 300개 episode에서 성공률은 72퍼센트에서 84.33퍼센트로 향상되었습니다. 다만 Direct만 성공한 10개 episode도 있어 항상 더 좋은 방법이거나 전역 수렴을 보장하는 것은 아닙니다. 후속 방향은 spatial manipulator 확장입니다. 감사합니다.
