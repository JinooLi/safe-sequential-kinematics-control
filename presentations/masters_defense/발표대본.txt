04. Kinematic Control and Goal-Error Reduction
01:10–01:50 / 40초
먼저 이번 연구는 kinematic control입니다. Joint configuration q를 상태로, joint velocity u를 입력으로 사용하므로 q의 시간 미분이 u입니다. Torque 동역학을 직접 제어하는 문제와는 구분됩니다. e는 현재 task와 목표 사이의 오차이고, CLF V는 그 오차를 하나의 값으로 모읍니다. CLF constraint는 그림의 그릇을 내려가듯 V를 감소시키는 속도를 요구합니다. 같은 task를 만족하는 configuration은 여러 개일 수 있으므로 특정 joint configuration 하나로의 수렴을 뜻하지는 않습니다.

05. Background (2/3): CBF for Safety
01:50–02:30 / 40초
안전 조건에는 link와 장애물 사이의 표면 거리 d와 필요한 여유 거리 d safe의 차이 h를 사용합니다. Safe set은 h가 0 이상인 configuration들의 집합입니다. 안전 경계에서 충분히 떨어진 상태에서는 장애물에 접근할 수 있지만, h가 0인 경계에서는 h가 더 감소하지 못하도록 합니다. CBF constraint는 이 속도 조건을 표현합니다. 항상 장애물에서 멀어지라는 조건은 아닙니다. Joint limit과 self-collision도 같은 제약 구조로 다룰 수 있습니다.

06. QP-Based Kinematic Control
02:30–03:15 / 45초
이제 CLF와 CBF constraint를 같은 joint velocity에 적용한 QP-based kinematic control입니다. QP는 입력과 slack의 비용을 최소화하며, V 자체를 최소화하지는 않습니다. Slack delta는 CLF constraint만 완화하고 CBF와 입력 제한은 hard constraint로 유지합니다. Delta가 양수이면 V의 감소가 느려지거나 V가 증가할 수 있으므로, 안전 조건을 유지하면서도 목표에 도달하지 못할 수 있습니다. 매 제어 주기 현재 q에서 QP를 다시 풉니다. CLF slack만으로 모든 QP의 실행 가능성이 보장되는 것은 아닙니다.

07. Related Work: Challenges in Goal Reaching
03:15–03:55 / 40초

Planar manipulator 실험도 있으므로 로봇팔에 적용하지 않았다고 말할 수는 없습니다. 구분점은 이들이 일반적인 제어 구조나 제약을 바꾸는 반면, 본 연구는 로봇팔의 IK와 link 구조에서 중간 task를 구성하고 순차적으로 추종한다는 점입니다.

19. Resolving Deadlock through Task Transition

Sequential에서는 현재 task의 CLF만 활성화하고, 전환하면 이전 task를 해제합니다. 따라서 이전 CLF나 최종 EE 함수가 중간에 커지는 것도 허용됩니다. 이 자유도로 팔의 configuration을 바꾼 후 마지막 EE task에서 목표에 도달합니다. 이는 같은 목표를 향한 즉각적인 감소를 강제하는 대신 중간 task로 우회하는 방식입니다. 다만 모든 교착 상태를 제거하거나 전역 수렴을 증명하는 결과는 아닙니다.

21. Self-Collision CBFs from RDF
08:50–09:45 / 55초
RDF는 query 위치에서 link 표면까지의 signed distance를 주는 함수입니다. 등고선은 link b의 거리장이고, 주황색 점들은 link a의 표면 표본입니다. 각 점을 b의 좌표계로 바꾼 뒤 그 좌표를 b의 거리 함수에 대입합니다. 본 연구에서는 이 거리값들을 smooth minimum으로 모으고 필요한 safety margin을 빼서 CBF를 구성합니다. 또한 두 link의 운동을 함께 반영한 gradient를 QP 제약에 사용합니다. RDF는 형상 정보이고, 이러한 추가 구성으로 제어에 사용할 안전 제약을 얻습니다. 그림은 capsule의 개념 단면이며, 실제 self-collision에는 다항식 근사 RDF를 사용합니다.

22. Spatial IK: Target Search with Null-Space Updates
09:45–10:45 / 60초
Spatial Manipulator에서는 여러 초기값으로 수치 IK를 탐색합니다. 첫 항은 damped inverse로 end-effector pose error를 줄입니다. 두 번째 항은 clearance gradient를 Jacobian의 null space로 투영해 순간적인 end-effector twist를 바꾸지 않으면서 joint를 조정합니다. 첫 항의 damped inverse와 직교 projector에 사용하는 Moore--Penrose inverse는 구분해야 합니다. 탐색에는 capsule 형상을 사용하고, 얻은 후보는 RDF를 포함한 제어기의 충돌 모델로 다시 검사합니다. 채택한 configuration 하나에서 중간 link 목표를 얻습니다. IK 반복을 로봇 경로로 실행하는 것은 아니며, 안전한 IK가 제어 성공까지 보장하지는 않습니다.

23. Spatial CLFs: Position and Orientation
10:45–11:25 / 40초
Planar에서는 중간 task에 위치, 최종 task에 위치와 yaw를 사용했습니다. Spatial Manipulator에서는 모든 단계에 위치와 relative unit quaternion의 vector part를 사용합니다. 단계마다 같은 형태이지만 추종하는 link와 목표가 바뀝니다. Quaternion vector의 norm은 회전각 절반의 sine 절댓값이며 회전각 자체가 아닙니다. 같은 식의 형태라는 뜻이지 joint space에서 같은 함수 지형이나 시간 변화를 가진다는 뜻은 아닙니다.

24. All-link Sequential: Spatial Manipulator Results

27. Link-Pair Selection: A Potential Upper Bound near 80\%
13:30–14:10 / 40초
같은 episode도 선택한 pair에 따라 결과가 달라집니다. Validation에서 적어도 하나의 후보가 성공하는 episode는 82퍼센트입니다. 열 개 결과를 모두 확인한 사후 oracle 상한이며 실행 전 모델의 성능은 아닙니다. Validation의 최고 단일 pair는 (2,5)이고 Train에서 선택한 Preset pair는 (3,5)입니다. 학습의 목적은 고정 pair들의 작은 순위 차이가 아니라 episode마다 성공할 pair를 골라 oracle과의 격차를 줄이는 것입니다.

28. Training Labels and Losses
14:10–15:00 / 50초
Episode마다 열 개의 이진 label이 있으며 여러 pair가 동시에 성공할 수 있습니다. 이 예에서는 Preset pair가 실패하고 다른 두 pair는 성공합니다. 모델의 logit에 sigmoid를 적용하고 Binary Cross Entropy로 각 pair의 성공 여부를 예측합니다. Selection loss는 같은 logit의 softmax에서 성공 후보에 모인 확률을 키웁니다. 정답을 하나만 지정할 필요는 없습니다. 모든 pair가 실패하면 selection 항만 0으로 두고 Binary Cross Entropy는 유지합니다. 최종 목적 함수는 두 항을 가중합해 전체 Train episode에서 평균하며, Validation과 Test는 포함하지 않습니다.
