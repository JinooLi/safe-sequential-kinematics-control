## 비교 기준이 되는 내 연구

이 문서의 “내 연구”는 **현재 석사 발표자료에 정리된 IK 기반 sequential kinematic control과 supervised two-link selection**을 가리킴. 별도로 기록된 다른 학습 loss 실험이나 향후 기능을 현재 기여에 포함하지 않음.

- 안전 조건을 만족하는 goal IK에서 forward kinematics로 link별 target을 구성하고, 한 번에 하나의 활성 Control Lyapunov Function(CLF)을 사용하는 Control Barrier Function(CBF) 기반 quadratic program(QP)으로 subtask를 실행.
- Subtask를 전환해도 충돌 회피·joint limit·입력 제한의 구조를 유지하며, 완료한 link task를 계속 만족하도록 강제하지 않는 구성. 선택된 link task에서도 해당 task의 Jacobian을 통해 joint velocity를 계산하므로 “두 link 선택”은 “두 joint만 구동”을 의미하지 않음.
- 최종 성공 목표는 end-effector pose이며, 특정 IK configuration 자체로의 수렴은 요구하지 않음. 학습은 rollout 성공 label을 이용하여 사전 정의한 10개 오름차순 two-link pair 중 하나를 실행 전에 선택하는 역할.
- 현재 평가의 fixed-IK 조건, 제한된 pair 후보와 실행 순서를 기준으로 비교. 온라인 IK 재선택, 임의의 task 순서·개수 결정, 전역 목표 수렴은 현재 검증 범위에 포함하지 않음.
- 안전성은 모델·CBF 조건·QP feasibility·구현 조건과 함께 해석하고, 실험의 목표 도달 성공률과 구분. Simulation의 충돌 판정 결과를 실제 로봇의 무조건적인 안전 보장으로 해석하지 않음.

## 공통 실험 원칙

각 항목의 실험은 다음 조건을 기본으로 두고, 해당 논문에서 바꾸는 요소를 추가하는 제안.

1. **동일한 문제:** 같은 초기 자세, 목표 pose tolerance, 장애물·로봇 형상, joint·입력 제한과 독립적인 충돌 평가 기준 사용. 서로 다른 제어 차수·관측 정보·문제 설정이 있으면 먼저 그 차이를 명시.
2. **Goal과 IK의 공정한 처리:** Subtask 구성 요소만 비교하는 ablation에서는 IK를 고정. 전체 planning 방법과 비교할 때는 같은 end-effector 목표를 만족하는 goal configuration의 선택을 허용하고 IK 탐색 비용 및 IK 실패 episode의 포함·제외 기준도 통일.
3. **성공·안전·비용의 분리:** Pose 성공률, 최소 clearance와 제약 위반, 실패 유형을 구분하고, offline 학습·데이터 생성, online 준비·계산, simulated motion time을 따로 기록. 두 방법의 공동 성공 episode에서 비교한 완료 시간은 전체 episode 성능과 구분.
4. **평가와 불확실성:** 공통 episode를 짝지어 비교하고 학습·확률적 방법에는 여러 seed 사용. 기존 Test를 개발 중 확인한 이력이 있으므로 최종 비교에는 설정을 고정한 뒤 새 평가 집합을 사용하며, 같은 episode의 여러 pair를 독립 표본처럼 세지 않음.

## A. 경로·궤적 계획

<a id="p01"></a>

### P01. Hart, Nilsson & Raphael — A* (1968)

*A Formal Basis for the Heuristic Determination of Minimum Cost Paths.* IEEE Transactions on Systems Science and Cybernetics. [원문](https://www.cs.auckland.ac.nz/courses/compsci709s2c/resources/Mike.d/astarNilsson.pdf)

- **해결 문제:** 주어진 graph에서 시작점과 목표 사이의 최소 비용 경로를 효율적으로 탐색하는 문제.
- **핵심 방법:** 시작점부터의 누적 비용과 목표까지의 heuristic 추정치를 더해 탐색 순서를 결정하는 A* 구성. Heuristic과 탐색 조건 아래 최적 경로 탐색에 대한 이론 제시.
- **내 연구와의 공통점:** 목표에 도달하기 위한 움직임을 결정한다는 상위 목적의 공통점. 충돌 없는 state와 edge로 graph를 구성하면 안전한 로봇 이동 문제에 활용 가능.
- **차이점:** A*는 graph search의 기반 알고리즘이며, 로봇의 IK·충돌 검사·feedback 제어를 자체적으로 정의하지 않음. 본 연구는 연속 상태에서 활성 subtask에 대한 제어 입력을 매 주기 계산하는 방식.
- **비교에 필요한 실험:** 직접적인 단독 baseline보다 P02 같은 로봇팔용 search planner로 구체화한 뒤 비교하는 것이 적절. 직접 구현한다면 state 해상도와 edge 충돌 검사를 명시하고, 탐색 시간·메모리·실제 실행 성공률을 함께 평가.

<a id="p02"></a>

### P02. Cohen, Chitta & Likhachev — Search-based manipulation (2010)

*Search-based Planning for Manipulation with Motion Primitives.* ICRA. [원문](https://www.cs.cmu.edu/~maxim/files/SBPlanningwithMotionPrims_icra10.pdf)

- **해결 문제:** 고차원 로봇팔에서 heuristic search의 계산 부담을 낮추면서 cluttered environment의 충돌 없는 경로를 계획하는 문제.
- **핵심 방법:** 작은 motion primitive를 graph의 action으로 구성하고, 계산이 빠른 heuristic과 anytime search인 ARA*를 결합. 구축한 탐색 공간에서 해의 비용에 대한 bound를 다루며 7-DOF 로봇팔로 검증.
- **내 연구와의 공통점:** 로봇 기구학과 장애물 정보를 활용하여 end-effector의 목표 도달을 생성한다는 공통점.
- **차이점:** Motion primitive의 연결로 경로를 탐색하는 방식이며, IK에서 link별 target을 만든 뒤 활성 CLF를 바꾸는 제어 구조와 차이. Graph에서의 탐색 보장을 연속 로봇의 실행 안전 보장과 구분할 필요.
- **비교에 필요한 실험:** 같은 목표 pose 허용 오차와 whole-arm collision model에서 planner와 본 제어기의 실행 성공률·clearance·총 소요 시간을 비교. Primitive 해상도와 탐색 시간 예산을 변화시켜 계획 비용과 실행 성능의 관계를 확인.

<a id="p03"></a>

### P03. Kavraki, Švestka, Latombe & Overmars — PRM (1996)

*Probabilistic Roadmaps for Path Planning in High-Dimensional Configuration Spaces.* IEEE Transactions on Robotics and Automation. [원문](https://web.ics.purdue.edu/~rvoyles/Classes/ROSprogramming/Kavraki_Latombe.PRM_PathPlanning.TRA96.pdf)

- **해결 문제:** 정적인 환경의 고차원 로봇에서 여러 시작–목표 질의에 사용할 충돌 없는 경로를 효율적으로 찾는 문제.
- **핵심 방법:** Collision-free configuration을 sampling하고 local planner로 연결하여 roadmap을 구축한 뒤, 시작과 목표를 roadmap에 연결하여 경로 탐색. 원문의 learning phase는 이 roadmap 전처리 단계이며 신경망 학습과 다른 의미.
- **내 연구와의 공통점:** 로봇 전체 형상과 장애물의 관계를 이용하여 안전한 목표 도달을 다루는 공통점.
- **차이점:** 환경의 연결성을 roadmap으로 저장·재사용하는 방식인 반면, 본 연구는 목표 IK에서 subtask target을 구성하고 feedback QP를 실행. Roadmap이 반환한 기하학적 경로의 무충돌성과 실제 tracking 중 안전성은 별도 검증 대상.
- **비교에 필요한 실험:** 한 환경에서 여러 목표를 수행하는 조건과 episode마다 장애물이 바뀌는 조건을 구분하여 평가. Roadmap 구축·재검사 비용을 포함한 총 시간과 재사용 후 질의 시간을 별도로 보고하고, goal pose를 만족하는 복수 IK 해를 허용.

<a id="p04"></a>

### P04. Kuffner & LaValle — RRT-Connect (2000)

*RRT-Connect: An Efficient Approach to Single-Query Path Planning.* ICRA. [원문](https://kuffner.org/james/papers/kuffner_icra2000.pdf)

- **해결 문제:** 고차원 configuration space에서 사전 roadmap 구축 없이 하나의 시작–목표 질의에 대한 충돌 없는 경로를 빠르게 찾는 문제.
- **핵심 방법:** 시작과 목표 configuration에서 각각 RRT를 확장하고, 두 tree를 적극적으로 연결하는 greedy 절차 사용.
- **내 연구와의 공통점:** 로봇팔의 obstacle avoidance와 goal reaching을 함께 다루며, 목표 configuration 또는 IK 정보가 움직임 생성에 활용된다는 공통점.
- **차이점:** Configuration space를 탐색하여 전체 경로를 얻는 방식인 반면, 본 연구는 link target별 feedback 제어를 순차 실행. Sampling-based 탐색의 성질과 본 연구의 조건부 안전성·경험적 도달률은 서로 다른 평가 축.
- **비교에 필요한 실험:** 같은 episode에서 RRT-Connect와 본 연구를 비교하되, 목표 pose의 복수 IK 해를 허용하는 구성과 실제 path tracking을 포함. 반복 seed에 따른 성공률, 계획·IK 시간, 실행 시간 및 최소 clearance를 기록.

<a id="p05"></a>

### P05. Karaman & Frazzoli — PRM* / RRT* (2011)

*Sampling-based Algorithms for Optimal Motion Planning.* The International Journal of Robotics Research. [원문](https://arxiv.org/pdf/1105.1186)

- **해결 문제:** Sampling-based planner가 sample 수를 늘려도 최적 경로 비용에 수렴하지 않을 수 있는 문제.
- **핵심 방법:** 연결 이웃의 구성과 tree의 rewiring 등을 설계한 PRM*·RRT*를 제안하고, 관련 가정 아래 경로 비용의 asymptotic optimality 증명.
- **내 연구와의 공통점:** 안전한 목표 도달 가능 여부뿐 아니라 생성되는 움직임의 품질을 평가할 수 있다는 공통점.
- **차이점:** 충분한 sample에 따른 경로 비용의 극한 성질이 핵심인 반면, 본 연구는 선택한 subtask로 목표 도달 성공률과 실행 효율을 개선하려는 제어 구조. 본 연구에는 경로 최적성이나 전역 목표 수렴의 동등한 보장이 없음.
- **비교에 필요한 실험:** 제한된 계산 시간별 최초 feasible path 획득률과 최종 경로 비용을 비교하고, 실행 시간은 별도 측정. 짧은 budget에서의 실패만으로 이론적 최적성을 평가하지 않도록 budget–성능 곡선과 반복 실행 결과를 함께 제시.

### P06. Ratliff, Zucker, Bagnell & Srinivasa — CHOMP (2009)

*CHOMP: Gradient Optimization Techniques for Efficient Motion Planning.* ICRA 2009 판본. [원문](https://mzucker.github.io/swarthmore/papers/icra09-chomp.pdf)

- **해결 문제:** 고차원 로봇의 초기 경로를 매끄럽고 장애물을 피하는 trajectory로 개선하는 문제.
- **핵심 방법:** Smoothness와 obstacle cost를 결합한 목적함수를 covariant gradient로 최적화. 충돌을 포함한 초기 trajectory도 입력으로 허용하지만, 결과는 초기화와 국소 최적화의 영향을 받음.
- **내 연구와의 공통점:** 로봇 기구학과 장애물과의 거리 정보를 이용하며, 목표로 향하는 움직임과 collision avoidance를 함께 고려한다는 공통점.
- **차이점:** Trajectory 전체의 waypoint를 조정하는 최적화인 반면, 본 연구는 현재 상태의 제어 입력에 대한 QP와 subtask 전환을 사용. Trajectory objective의 local minimum과 QP feedback의 undesired equilibrium은 구분해야 할 현상.
- **비교에 필요한 실험:** 동일한 goal pose를 만족하는 IK 후보들로 초기화하고, 초기 trajectory·restart 수에 따른 성공률과 계산 시간을 평가. 도달 후 경로 길이·smoothness·clearance와 tracking 성공률을 비교하여 초기화 효과와 제어 방식 효과를 분리.

<a id="p07"></a>

### P07. Kalakrishnan et al. — STOMP (2011)

*STOMP: Stochastic Trajectory Optimization for Motion Planning.* ICRA. [원문](https://whiteoak.umd.edu/roswiki/attachments/Papers%282f%29ICRA2011_Kalakrishnan/kalakrishnan_icra2011.pdf)

- **해결 문제:** 장애물·smoothness·추가 제약의 비용을 함께 고려하면서 비용의 미분을 요구하지 않는 trajectory optimization 문제.
- **핵심 방법:** 초기 trajectory 주변에 noise를 더한 여러 trajectory를 생성하고, 평가된 비용을 이용해 trajectory를 반복 갱신. Stochastic exploration으로 일부 국소 정체에서 벗어나는 효과를 실험적으로 확인.
- **내 연구와의 공통점:** 목표 도달을 위한 여러 움직임 대안의 성능을 활용한다는 공통점. 다만 STOMP의 대안은 trajectory sample이고 본 연구의 학습 대상은 사전 정의된 link pair.
- **차이점:** 실행 전에 trajectory 전체를 반복 탐색하는 방식이며, 비용 기반 탐색 자체가 CBF의 forward-invariance 조건을 제공하는 것은 아님. 본 연구는 선택된 pair에 대한 subtask를 실행하면서 동일한 안전 제약을 적용.
- **비교에 필요한 실험:** Sample 수·iteration·초기화별 계산 예산을 맞추고 반복 seed로 성공률의 변동을 평가. 생성 경로의 충돌 여부와 실제 실행 결과를 구분하여 도달률·계산 시간·실행 시간·smoothness 비교.

<a id="p08"></a>

### P08. Schulman et al. — TrajOpt (2013)

*Finding Locally Optimal, Collision-Free Trajectories with Sequential Convex Optimization.* RSS 2013 판본. [원문](https://people.eecs.berkeley.edu/~pabbeel/papers/Schulmanetal_RSS2013.pdf)

- **해결 문제:** 복잡한 장애물이 있는 고차원 로봇에서 충돌 제약을 포함한 trajectory optimization을 효율적으로 수행하는 문제.
- **핵심 방법:** 비선형 trajectory 문제를 convex subproblem으로 반복 근사하고 collision penalty를 조정. Waypoint 사이의 swept volume을 고려하여 구간 중 충돌까지 다루는 구성.
- **내 연구와의 공통점:** 최적화 문제에 목표와 안전 관련 조건을 함께 넣어 로봇 움직임을 생성한다는 공통점.
- **차이점:** TrajOpt의 sequential은 convex approximation을 반복한다는 의미이며, 본 연구의 link subtask 순차 실행과 다른 의미. 모델상 계획 trajectory의 충돌 제약 충족과 feedback 제어의 safe-set invariance도 구분 필요.
- **비교에 필요한 실험:** 동일한 collision geometry·margin과 goal pose 조건에서 초기화·iteration budget을 변화시키며 성공률과 계산량을 비교. 얇은 장애물과 waypoint 사이 충돌을 포함한 사례에서 계획 경로 및 실제 tracking의 clearance를 함께 확인.

### P09. Khatib — Operational-space formulation (1987)

*A Unified Approach for Motion and Force Control of Robot Manipulators: The Operational Space Formulation.* [저자 공개 원문](https://khatib.stanford.edu/publications/pdfs/Khatib_1987_RA.pdf)

- **해결 문제:** Joint 좌표만으로 기술하기 어려운 end-effector의 motion·force control을 task가 정의된 공간에서 일관되게 다루는 문제.
- **핵심 방법:** Operational-space dynamics를 구성하여 task-space 명령을 joint force로 연결하고, redundant manipulator와 singular configuration까지 확장.
- **내 연구와의 공통점:** 로봇의 kinematics와 task-space 정보를 이용하여 end-effector 목표를 joint 제어로 변환한다는 점.
- **차이점:** 원문은 motion·force control의 동역학적 기반이며, 본 연구의 goal IK 기반 link target 구성·순차 CLF 전환·CBF QP와는 기여의 층위가 다름. 따라서 이 논문만을 whole-arm safety controller로 간주한 성능 비교는 부적절.
- **비교에 필요한 실험:** **기반·구조 검토용 제안:** 동일한 동역학 플랜트와 하위 추종기를 사용할 수 있을 때 task-space controller를 구성하여 목표 오차·singularity 부근 거동을 비교하고, 충돌 회피를 추가했다면 그 추가 요소를 명시. 전체 방법의 필수 baseline으로 구현하기보다는 로봇 구조 활용의 선행연구로 우선 정리.

### P10. Kanoun — Prioritized kinematic control (2011)

*Real-time Prioritized Kinematic Control under Inequality Constraints for Redundant Manipulators.* [공식 학회 설명](https://www.roboticsproceedings.org/rss07/p21.html) · [원문](https://www.roboticsproceedings.org/rss07/p21.pdf)

- **해결 문제:** Redundant robot에 여러 equality·inequality task가 동시에 주어졌을 때 우선순위를 지키며 실시간으로 joint motion을 계산하는 문제.
- **핵심 방법:** 우선순위별 QP 계층을 효율적으로 풀고 Tikhonov regularization으로 수치적 안정성을 개선하며, HRP-2 humanoid simulation에서 검증.
- **내 연구와의 공통점:** 여러 task와 안전·joint 제약의 충돌을 optimization으로 처리하고, redundancy를 이용하여 가능한 motion을 찾는다는 점.
- **차이점:** 원문은 동시에 활성화된 task 사이의 priority를 다루며, 본 연구는 하나의 active CLF를 시간에 따라 전환하고 완료된 link target을 계속 강제하지 않음. 우선순위와 실행 순서는 같은 개념이 아님.
- **비교에 필요한 실험:** **구조 비교 제안:** 동일한 link target·joint-velocity 플랜트·충돌 제약으로 task를 누적 유지하는 hierarchy와 완료 후 해제하는 sequential 방식을 비교하여 성공률·task 잔여 오차·제어 계산 시간을 측정. 비교용 hierarchy에 CBF를 넣었다면 원문 자체의 재현이 아닌 적용 변형임을 표시.

### P11. Khatib — Artificial potential field (1986)

*Real-Time Obstacle Avoidance for Manipulators and Mobile Robots.* [저자 공개 원문](https://khatib.stanford.edu/publications/pdfs/Khatib_1986_IJRR.pdf)

- **해결 문제:** Manipulator와 mobile robot이 움직이는 장애물을 포함한 환경에서 실시간으로 충돌을 피하는 문제.
- **핵심 방법:** Goal의 attractive potential과 obstacle의 repulsive potential으로 reactive motion을 만들며, 회피를 모든 link와 joint 제약에 적용.
- **내 연구와의 공통점:** 현재 상태와 obstacle geometry를 이용해 매 순간 목표 지향 motion과 whole-arm obstacle avoidance를 결합한다는 점.
- **차이점:** 원문은 potential field로 motion을 구성하고, 본 연구는 CBF·입력 제한을 QP 제약으로 두며 IK 기반 subtask를 전환함. 원문의 potential field에 본 연구의 조건부 safe-set invariance 보장이 그대로 있는 것으로 취급할 수 없음.
- **비교에 필요한 실험:** **대표 reactive baseline 제안:** 동일한 초기 상태·목표·장애물에서 성공률·최소 clearance·정체 빈도를 비교하고 potential gain의 민감도를 확인. Force/acceleration 방식과 joint-velocity 방식의 차이를 먼저 맞추고, 변환한 제어기는 원문의 적용 변형으로 표기.

### P12. Rimon & Koditschek — Navigation functions (1992)

*Exact Robot Navigation Using Artificial Potential Functions.* [원문](https://www.cs.cmu.edu/~motionplanning/papers/sbp_papers/r/rimon_koditschek_potential.pdf)

- **해결 문제:** 일반 potential field에서 발생하는 잘못된 정체점을 피하면서 planning과 feedback execution을 연결하는 문제.
- **핵심 방법:** 자유 공간과 goal을 navigation function으로 표현하고, 구성 가능한 공간에 대한 가정 아래 거의 모든 초기 configuration에서 collision-free goal convergence를 얻는 feedback 설계.
- **내 연구와의 공통점:** 안전한 목표 도달을 위한 feedback의 형상과 정체 문제를 함께 다룬다는 점.
- **차이점:** 원문은 navigation function을 구성할 수 있는 공간·모델의 가정 아래 수렴을 분석하며, 본 연구는 로봇팔 IK로 subtask를 구성한 뒤 도달 성능을 실험으로 평가. 해당 수렴 결과를 복잡한 Panda configuration space나 본 연구의 EE pose 목표에 자동 적용할 수 없음.
- **비교에 필요한 실험:** **이론·저차원 비교 제안:** 우선 원문의 구성 조건을 만족하는 저차원 공간에서 attraction basin과 정체점을 비교하고, manipulator 적용에는 configuration-space 표현 및 함수 구성 비용을 별도 기록. 구성 조건이 충족되지 않으면 무리하게 수치 baseline을 만들기보다 적용 가정의 차이를 정리.

### P13. Ching-An Cheng et al. — RMPflow (WAFR 2018)

*RMPflow: A Computational Graph for Automatic Motion Policy Generation.* [확인 원문: arXiv v2, 2019](https://arxiv.org/pdf/1811.07049v2)

- **해결 문제:** 여러 task space의 goal attraction·collision avoidance·joint-limit policy를 고차원 로봇의 일관된 reactive motion으로 결합하는 문제.
- **핵심 방법:** Task map과 Riemannian metric을 이용해 개별 motion policy를 computational graph에서 합성하며, stability의 충분조건과 cluttered manipulation 실험을 제시.
- **내 연구와의 공통점:** 로봇의 task geometry와 link 정보를 활용하여 goal reaching과 obstacle avoidance를 결합한다는 점.
- **차이점:** RMPflow는 여러 motion policy를 동시에 합성하고, 본 연구는 하나의 active CLF와 공통 안전 제약을 둔 QP를 순차 실행. RMPflow의 stability 결과를 모든 환경에서의 collision avoidance와 goal convergence 보장으로 확대할 수 없음.
- **비교에 필요한 실험:** **대표 reactive baseline 제안:** 동일한 obstacle·목표 pose·입력 제한에서 성공률·최소 clearance·도달 시간·주기별 계산 시간을 비교. Acceleration 기반 RMP와 joint-velocity QP를 같은 플랜트에서 실행하도록 하위 제어와 제한 처리를 맞추고 그 변환 비용도 포함.

### P14. Ames, Xu, Grizzle & Tabuada — CLF–CBF QP (2017)

*Control Barrier Function Based Quadratic Programs for Safety Critical Systems.* [원문](https://arxiv.org/pdf/1609.06408)

- **해결 문제:** 목표 성능과 안전 조건이 충돌할 수 있는 시스템에서 안전을 우선하면서 실시간 제어 입력을 계산하는 문제.
- **핵심 방법:** CLF 성능 조건은 relaxation이 가능한 제약으로, CBF 안전 조건은 hard constraint로 QP에 결합하며, 입력 제한을 포함한 차량 제어 사례로 검증.
- **내 연구와의 공통점:** 매 제어 주기 CLF·CBF·입력 제한을 함께 고려하는 QP가 본 연구의 제어 기반.
- **차이점:** 원문은 일반적인 안전 제어 framework이며, goal IK에서 link target을 구성하거나 실행할 subtask pair를 선택하는 구조를 제안하지 않음. 본 연구의 추가 기여도 CBF 안전성 자체와 구분하여 평가할 필요.
- **비교에 필요한 실험:** **핵심 baseline 제안:** 동일한 CBF·입력 제한·CLF 가중치·제어 주기에서 최종 EE 목표만 쓰는 Direct와 All-link Sequential, 선택된 pair의 Sequential을 비교. 원문의 차량 실험 재현이 아니라 framework의 동일 manipulator 적용 비교로 표시하고 IK 전처리 시간도 보고.

### P15. Reis, Aguiar & Tabuada — Undesirable stable equilibria (2021)

*Control Barrier Function-Based Quadratic Programs Introduce Undesirable Asymptotically Stable Equilibria.* [확인 원문: arXiv v4, 2020](https://arxiv.org/pdf/2003.07819v4)

- **해결 문제:** CLF–CBF QP가 안전을 유지하면서도 목표가 아닌 asymptotically stable equilibrium에 머무를 수 있는 문제.
- **핵심 방법:** 폐루프 equilibrium과 안정성 조건을 분석하고, boundary equilibrium의 발생 조건을 피하도록 QP에 제약을 추가하는 확장도 제시.
- **내 연구와의 공통점:** 안전한 국소 제어만으로는 목표 도달이 충분하지 않다는 동일한 문제의식과, 정체를 줄이기 위한 제어 구조의 변경.
- **차이점:** 원문은 equilibrium 조건과 회피 제약을 분석하며, 본 연구는 IK 기반 target 및 active CLF의 전환으로 도달 성능을 개선하려는 접근. 원문의 결과를 모든 비볼록 manipulator 환경으로 확대하거나 본 연구가 모든 equilibrium을 제거한다고 해석할 수 없음.
- **비교에 필요한 실험:** **실패 원인 검증 제안:** QP가 feasible한 정체 episode에서 입력 norm·goal error·CBF 활성 여부·CLF slack과 작은 상태 perturbation에 대한 반응을 기록하고, infeasibility로 종료된 episode는 별도 분류. 이는 평형점 가설의 수치적 증거이며 안정성 증명과 구분하고, 원문 확장 제어기의 비교는 적용 가정을 확인한 경우에 수행.

### P16. Tan & Dimarogonas — Undesired equilibria analysis (2024)

*On the Undesired Equilibria Induced by Control Barrier Function Based Quadratic Programs.* [저자 공개 원문](https://people.kth.se/~dimos/pdfs/Xiao_Automatica_2024.pdf)

- **해결 문제:** 일반 control-affine system의 CBF QP에서 undesired equilibrium이 어디에 생기며 설계변수에 따라 어떻게 달라지는지 밝히는 문제.
- **핵심 방법:** Equilibrium을 분류하고 nominal controller를 포함한 수정 QP를 제안하여, 정리의 가정 아래 safe-set 내부와 boundary의 특정 유형 equilibrium을 제거하고 목표의 local asymptotic stability를 확보.
- **내 연구와의 공통점:** CLF–CBF QP 구조 안에서 안전과 목표 도달의 불일치를 다룬다는 점.
- **차이점:** 원문은 nominal controller 및 QP 구성의 수정과 이론적 분석이 중심이고, 본 연구는 goal IK로 만든 link target을 순차적으로 사용. 원문과 본 연구 모두 모든 환경의 boundary equilibrium 제거 및 global convergence가 자동으로 따라오는 것은 아님.
- **비교에 필요한 실험:** **가까운 방법 비교 제안:** 동일한 kinematic plant·CBF·입력 제한에 수정 QP를 적용 가능한 범위에서 구현하여 Direct 및 Sequential과 정체 빈도·성공률을 비교. 입력 제한이나 다중 CBF를 추가했을 때 원문 정리의 가정이 유지되는지도 별도 점검.

### P17. Gonçalves et al. — Circulation inequalities (2023)

*Using Circulation to Mitigate Spurious Equilibria in Control Barrier Function — Extended Version.* [확인 원문: arXiv v1](https://arxiv.org/pdf/2307.09901v1)

- **해결 문제:** Goal 지향 nominal input과 CBF의 국소 정보만으로는 장애물 주위에서 정체할 수 있는 문제.
- **핵심 방법:** Configuration space에서 장애물 주위를 도는 circulation 방향에 대한 inequality를 QP에 추가하고 feasibility·연속성·equilibrium 조건을 분석.
- **내 연구와의 공통점:** 안전 제약을 둔 QP의 도달 실패를 완화하고, integrator 형태의 제어 및 manipulator obstacle avoidance를 다룬다는 점.
- **차이점:** 원문은 circulation 제약을 추가하며, 본 연구는 IK 기반 active subtask를 전환. 기본 구성은 짝수 차원을 가정하지만 IV-C에 홀수 차원 확장이 있고 circulation 방향 소실 시 infeasibility 가능성이 명시되므로, 3/7-DOF에는 적용 조건을 따로 확인해야 함.
- **비교에 필요한 실험:** **가까운 방법 비교 제안:** 홀수 차원 확장의 조건을 확인한 뒤 동일한 목표 pose·입력 제한에서 성공률·circulation 방향에 대한 민감도·QP infeasibility를 비교. 원문의 configuration 목표를 사용하는 재현과 EE pose 목표로 바꾼 적용 변형을 구분하여 목표 조건의 불공정을 방지.

### P18. Rubagotti et al. — MPC obstacle avoidance (2019)

*Semi-Autonomous Robot Teleoperation with Obstacle Avoidance via Model Predictive Control.* [공식 원문](https://www.roboticsproceedings.org/rss15/p81.pdf)

- **해결 문제:** 사람의 손 pose를 따라가는 manipulator가 whole-arm collision과 joint·속도·가속도 제한을 피하면서 실시간으로 움직이는 문제.
- **핵심 방법:** Operator motion을 예측하고 유한 horizon의 joint motion을 nonlinear MPC로 반복 최적화하며, UR5 teleoperation에서 검증.
- **내 연구와의 공통점:** End-effector pose 목표와 whole-arm safety를 함께 고려하고 매 주기 optimization으로 motion을 생성한다는 점.
- **차이점:** 원문은 시간에 따라 변하는 사람의 reference를 추종하며 미래 motion을 최적화하고, 본 연구는 주어진 목표에 대해 IK 기반 subtask의 국소 QP를 실행. 원문 teleoperation과 autonomous goal reaching의 성공률을 그대로 비교할 수 없음.
- **비교에 필요한 실험:** **예측 제어 baseline 제안:** Reference를 고정 goal pose로 바꾼 MPC 적용 변형을 동일 플랜트·제약·계산 예산에서 비교하고 horizon에 따른 성공률·도달 시간·최악 계산 시간을 측정. MPC의 가속도 모델과 본 연구의 속도 모델을 먼저 일치시켜 제어차수의 차이가 결과를 대신 설명하지 않도록 구성.

### P19. Mitchell, Bayen & Tomlin — Hamilton–Jacobi reachability (2005)

*A Time-Dependent Hamilton–Jacobi Formulation of Reachable Sets for Continuous Dynamic Games.* [저자 공개 원문](https://www.cs.ubc.ca/~mitchell/Papers/publishedIEEEtac05.pdf)

- **해결 문제:** Control과 disturbance가 대립하는 nonlinear system에서 주어진 target set에 도달 가능한 상태 집합을 계산하고 안전성을 분석하는 문제.
- **핵심 방법:** Backward reachable set을 time-dependent Hamilton–Jacobi–Isaacs PDE의 viscosity solution의 sublevel set으로 표현하고 수치적으로 계산.
- **내 연구와의 공통점:** 모델과 입력 제약에 근거하여 안전한 제어의 조건을 다룬다는 점. 본 연구도 CBF 조건과 QP feasibility에 의존하지만 reachable set 전체를 계산하는 것은 아님.
- **차이점:** 원문은 reachable set 계산의 기반 연구이며 IK 기반 manipulator task sequencing 방법이 아님. 본 연구가 주어진 CBF로 국소 제어를 수행하는 데 비해, 원문의 격자 기반 계산은 state dimension에 따라 메모리·시간 부담이 빠르게 증가.
- **비교에 필요한 실험:** **안전 분석용 제안:** 작은 state dimension의 별도 모델에서 같은 입력·disturbance 조건으로 reachable set과 CBF가 인증하는 영역을 비교. 7-DOF 전체 시스템의 필수 성능 baseline으로 두기보다 보장 범위와 계산 규모를 비교하는 근거로 활용.

- **내 연구와의 공통점:** 안전 제약을 유지하면서 서로 다른 task의 QP를 순차 실행한다는 점.
- **차이점:** 원문은 주어진 task 사이의 매끄러운 전환이 중심이며 IK 기반 link target 생성이나 어떤 pair를 선택할지는 다루지 않음. Mobile robot의 barrier 기반 reachability 결과를 manipulator의 CLF switching에 그대로 옮길 수 없음.
- **비교에 필요한 실험:** **전환 방식 ablation 제안:** 동일한 subtask sequence에서 즉시 CLF 전환과 매끄러운 전환의 적용 변형을 비교하여 입력 jump·peak acceleration·전환 지연·성공률을 측정. 전환 구간에 여러 조건이 겹칠 때 QP feasibility와 안전 제약 유지 여부도 확인.

<a id="p28"></a>

### P28. Karimi & Ahmadi — Learning Task Priorities (2022)

*A Reinforcement Learning Approach in Assignment of Task Priorities in Kinematic Control of Redundant Robots.* IEEE RA-L. [공식 출판사 페이지·초록](https://ieeexplore.ieee.org/document/9645158/)

확인 범위: 공식 초록의 검색 인덱스 확인; 본문·참고문헌 미확인. 안전 제약의 세부 처리와 구현 조건은 추가 원문 확인 대상.

- **해결 문제:** Redundant robot이 서로 충돌할 수 있는 여러 task를 동시에 수행할 때 상황에 맞는 priority를 정하고, priority 전환으로 생기는 joint velocity 불연속을 완화하는 문제.
- **핵심 방법:** Deep Q-Network(DQN)으로 미리 정의된 kinematic task들의 strict priority를 상태에 따라 재배정하고, smoothing으로 연속적인 reference velocity 생성. 공식 초록에 따르면 5-DOF planar manipulator와 7-DOF planar biped의 simulation으로 검증.
- **내 연구와의 공통점:** 학습이 저수준 action 전체를 대체하지 않고 기존 kinematic controller의 task 구성에 영향을 준다는 공통점. 무엇을 우선 실행할지에 대한 선택이 goal 수행 성능을 바꾸는 구조.
- **차이점:** 이 연구는 동시에 고려하는 task들의 priority를 실행 중 재배정하며, 본 연구는 실행 전 하나의 two-link pair를 선택한 뒤 정해진 순서로 하나의 CLF를 활성화하는 구조. 본 연구에서는 완료한 subtask를 계속 유지하도록 강제하지 않는다는 차이도 비교 대상.
- **비교에 필요한 실험:** 본문 확보 후 동일한 subtask 후보를 사용하는 priority 재배정 방식과 본 연구의 pair 선택 방식을 구현하여, 목표 도달·전환 횟수·joint velocity 변화를 비교하는 실험. 원 논문에서 가져온 부분과 새 manipulator 문제에 맞춘 수정 부분을 구분하고, 학습 및 평가에 쓰는 정보·안전 조건을 맞출 필요.

### P29. Pham, De Magistris & Tachibana — OptLayer (2018)

*OptLayer — Practical Constrained Optimization for Deep Reinforcement Learning in the Real World.* ICRA. [원문](https://arxiv.org/pdf/1709.07643v2) · [본문 HTML](https://arxiv.org/html/1709.07643v2)

- **해결 문제:** RL의 trial-and-error 과정에서 제약을 위반하는 action이 실제 로봇과 환경을 손상시킬 수 있는 문제.
- **핵심 방법:** Neural policy가 예측한 action을 지정한 제약을 만족하는 가장 가까운 action으로 바꾸는 optimization layer를 적용하고, 제약 위반 예측을 학습에 반영하는 방식. 로봇 reaching 과제에서 joint·collision 제약을 다루며 simulation과 실제 로봇으로 검증.
- **내 연구와의 공통점:** 학습 요소와 명시적 제약 최적화를 결합하여 최종 로봇 입력을 결정한다는 공통점. 안전한 행동을 reward만으로 유도하는 구조와 구분 가능.
- **차이점:** OptLayer는 policy가 제안한 action을 수정하며, 본 연구는 학습기가 선택한 subtask에 대해 QP가 joint velocity를 계산하는 구조. 제약 만족의 의미는 실제로 넣은 joint·collision 모델과 구현 조건에 따라 평가해야 하므로, 두 방법의 안전성을 이름만으로 동일시할 수 없음.
- **비교에 필요한 실험:** 동일한 관측·입력 범위·collision distance 모델에서 action 학습+OptLayer와 pair 선택+QP를 비교하는 실험. 성공률·최소 clearance·계산 시간과 함께 OptLayer의 action 수정량 및 본 연구의 CLF slack을 각각 기록하여 목표 진행이 제한되는 이유를 분석할 필요.

### P30. Richard Cheng et al. — RL-CBF (2019)

*End-to-End Safe Reinforcement Learning through Barrier Functions for Safety-Critical Continuous Control Tasks.* AAAI. [논문 정보](https://arxiv.org/abs/1903.08792) · [원문](https://arxiv.org/pdf/1903.08792)

- **해결 문제:** 불확실한 동역학을 가진 실제 시스템에서 RL을 학습하는 동안 안전 제약을 위반할 수 있는 문제.
- **핵심 방법:** Model-free RL, CBF 기반 제어, Gaussian process에 의한 동역학·불확실성 학습을 결합하여 가정 아래 높은 확률의 학습 중 안전성 확보. Inverted pendulum과 car-following으로 검증.
- **내 연구와의 공통점:** 학습과 CBF를 결합하고, 학습 성능과 안전 조건을 분리해 다룬다는 공통점. 따라서 비교 논점을 단순히 ‘RL에는 안전 보장이 없음’으로 설정할 수 없음.
- **차이점:** RL-CBF는 action policy와 동역학 모델을 학습하며, 본 연구는 주어진 kinematic model에서 link pair를 지도학습으로 선택하는 구조. 원 논문의 확률적 안전성 조건과 본 연구의 CBF 모델·QP feasibility 조건이 다르며, 원 실험도 manipulator whole-arm avoidance와 다른 문제.
- **비교에 필요한 실험:** 먼저 동일한 kinematic model과 CBF를 사용하는 RL+CBF baseline으로 목표 도달·안전 위반·학습 비용을 비교하는 실험. 모델 오차까지 주장하려면 별도 실험으로 센서·모델 오차를 도입하고 GP 보정 유무를 비교하되, 원 논문을 manipulator에 적용하기 위한 수정 사항을 명시할 필요.

### P31. Thumm & Althoff — Reachability-Based Safe RL (2022)

*Provably Safe Deep Reinforcement Learning for Robotic Manipulation in Human Environments.* ICRA. [원문](https://arxiv.org/pdf/2205.06311) · [본문 HTML](https://arxiv.org/html/2205.06311v1)

- **해결 문제:** 사람이 예측하기 어렵게 움직이는 환경에서 manipulator의 RL 학습·실행 중 위험한 충돌을 막으면서 goal에 도달하는 문제.
- **핵심 방법:** SAC+HER policy가 제안하는 joint 목표에 대해 robot·human reachable occupancy와 정지 trajectory를 검사하는 safety shield 적용. 사람 속도·측정 오차·trajectory 추종에 대한 가정 아래 위험한 접촉 전에 정지하는 방식으로, CBF-QP와 다른 안전 기구.
- **내 연구와의 공통점:** 로봇팔의 학습 기반 의사결정과 명시적 안전 검사를 결합하여 goal-reaching을 수행한다는 공통점. 저수준 제어를 포함한 전체 구조의 안전성과 성공률을 함께 평가할 필요.
- **차이점:** 원 논문은 동적인 사람 환경에서 특정 goal joint configuration에 도달하며, 본 연구는 goal IK를 link target 구성에 사용하되 최종 end-effector pose 도달을 목표로 하는 구조. 또한 정지한 로봇에 사람이 접촉하는 경우까지 모두 배제하는 보장은 아님.
- **비교에 필요한 실험:** Goal pose와 허용 goal configuration 집합을 먼저 맞추고, 정적 장애물 조건과 동적 사람 조건을 분리하여 성공률·위험한 충돌·정지 빈도·실행 시간을 비교하는 실험. 정지 후 사람의 접촉을 별도 분류하고, 본 연구에 동적 obstacle 처리와 정지 동작을 추가한다면 기존 결과와 구분하여 보고할 필요.

### P32. Theile et al. — Action Mapping (2025)

*Action Mapping for Reinforcement Learning in Continuous Environments with Constraints.* Reinforcement Learning Journal, 6:343–363; RLC 2025 최종 출판본. [논문 정보](https://rlj.org/papers/theile2025action) · [원문](https://rlj.cs.umass.edu/2025/papers/RLJ_RLC_2025_27.pdf) · [공식 신경망 구현](https://github.com/theilem/drl_am/blob/main/drl_am/agent/model.py) · [공식 로봇팔 환경](https://github.com/theilem/drl_am/blob/main/drl_am/gym/robot_arm.py)

- **해결 문제:** 연속 action space의 RL에서 충돌·관절 범위·속도 제약을 지키는 행동을 탐색하기 어렵고, 매번 action을 수정하는 projection에도 계산 비용이 발생하는 문제. 로봇팔 실험은 최대 20개 구형 장애물 사이에서 7-DOF 로봇의 end-effector를 목표 pose로 이동시키는 기구학 시뮬레이션.
- **핵심 방법:** Feasibility model로 latent action을 실행 가능한 action으로 변환하도록 feasibility policy를 사전학습한 뒤, 목표 수행에 유리한 latent action을 선택하는 objective policy를 PPO로 학습하는 2단계 구성. 로봇팔 objective policy는 현재 로봇 상태·목표의 feature를 Query로, 각 구형 장애물의 중심·반지름에서 만든 feature를 Key/Value로 사용하는 cross-attention으로 장애물 정보 통합.
- **내 연구와의 공통점:** 다수 구형 장애물의 정보를 로봇 상태로 조건화한 cross-attention으로 통합하고, whole-arm collision avoidance와 end-effector pose 도달을 함께 다룬다는 공통점. 따라서 여러 구형 장애물의 token화와 cross-attention 사용 자체보다, 그 정보로 무엇을 선택하고 제어에 어떻게 반영하는지가 차별화의 검토 대상.
- **차이점:** AM은 매 step의 연속 joint 변화량을 RL과 action mapping으로 생성하지만, 본 연구는 goal IK 기반 subtask의 two-link pair를 실행 전에 지도학습으로 선택하고 CLF–CBF QP가 joint velocity를 계산하는 구조. AM 신경망 단독에는 엄밀한 안전 보장이 없으며, AM-PPO + Replacement의 제약 위반 0은 정확한 feasibility model과 안전한 정지 action을 사용하는 실험 조건의 결과이므로 본 연구의 CBF·QP 가정과 구분 필요.
- **비교에 필요한 실험:** 같은 관측 정보·초기 상태·목표 pose tolerance·timeout·장애물·입력 제한과 독립적인 충돌 판정 아래 AM-PPO, AM-PPO + Replacement, 본 연구를 비교하고, pose 성공률·제약 위반·완료 시간 및 장애물 수·배치 변화에 대한 일반화를 별도 측정하는 실험. AM의 feasibility 사전학습·RL 비용과 본 연구의 IK·label rollout·지도학습 비용, online 계산 시간을 분리해 보고하며, 원 논문의 return이나 제약 위반율의 보수를 목표 도달 성공률로 대체하지 않도록 공통 성공 기준 적용.
