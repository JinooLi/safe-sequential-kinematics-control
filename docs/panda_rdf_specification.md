# Panda RDF 자기 충돌 확정 명세

기준일: 2026-09-28. 상태: 구현 요구사항이며 구현 완료 보고서가 아니다.
본 문서는 이전 RDF 설계 기록보다 우선한다. 실행 설정은 별도 구현·검증 후 적용한다.

## 1. 목적과 적용 범위

원 논문의 RDF 학습 방법을 활용하고, 연구 범위는 RDF 이후 self-collision 거리 집계와
CBF-QP 구성에 둔다. RDF 학습 알고리즘 자체의 개선은 목표로 하지 않는다.

- Self-collision에 Visual mesh 기반 RDF를 적용한다.
- 외부 장애물은 기존 capsule–sphere 방식으로 유지한다.
- Safe pose-IK null-space 안전 목적, IK 후보 검증, trajectory CBF에 모두 적용한다.
- 기존 capsule self-collision도 선택 가능하게 유지한다. YAML 기본 모델은 `rdf`다.
- RDF 준비 실패 시 capsule로 자동 전환하지 않는다.
- 실행 중 독립적인 mesh collision checker는 추가하지 않는다.
- Mesh 거리 계산은 학습 라벨과 오프라인 정확도 검증에 사용한다.
- 기존 pose CLF와 sequential stage 목적은 이 변경으로 재정의하지 않는다.

## 2. 로봇 형상

Visual mesh를 기준으로 base, arm 링크, hand, 양쪽 finger를 모두 포함한다.
Finger는 모델의 완전 닫힘 한계에 고정하고, 팔의 7-DOF만 제어한다.
Hand와 닫힌 양쪽 finger는 동일한 local 좌표계로 변환해 하나의 RDF 형상으로 합친다.
통합 형상 내부의 의도된 접촉은 별도 충돌 쌍으로 만들지 않는다.

RDF 학습용 형상은 원본 Visual mesh에서 공식 RDF 저장소의 voxel SDF 및
Marching Cubes 전처리로 재구성한다. 구체적인 채택 설정과 검증 정책은
9절의 결정 3·4에 기록한다. 원본 asset과 시뮬레이션 표시 mesh는 바꾸지 않는다.

통합 후 직접 연결된 인접 링크만 제외하고 나머지 모든 링크 쌍을 검사한다.
Base와 통합 hand도 검사에 포함한다. 정확한 mesh 파일, 닫힘 값, 좌표 변환 및
pair 목록은 실제 모델에서 확인하며 이름의 숫자 차이만으로 인접성을 판단하지 않는다.

위치·거리는 m, 시간은 s, 관절 각도는 rad로 표기한다. Gradient는 열벡터다.
Local → world 변환은 다음과 같다.

$$
T_i(q)=\begin{bmatrix}R_i(q)&t_i(q)\\0&1\end{bmatrix},\qquad q\in\mathbb R^7.
$$

## 3. RDF 학습 정책

Li et al., *Representing Robot Geometry as Distance Fields: Applications to
Whole-body Manipulation*의 RDF 학습 및 analytical derivative 방법을 따른다.
채택한 방식은 거리값 대상 recursive ridge regression이다.

$$
f_i(p)=\Psi_i(p)^\top w_i,\qquad
\nabla_pf_i=\left(\frac{\partial\Psi_i}{\partial p}\right)^\top w_i.
$$

Bernstein 기저의 해석적 미분과 좌표 정규화 chain rule을 사용한다.
Gradient loss, Eikonal loss, 독자적인 정규화 계수 탐색은 도입하지 않는다.
학습 알고리즘은 유지하되, 각 링크의 외부 구 r₁까지 학습 영역이 포함되도록 설정하는
변경은 허용하며 원 논문 대비 적용상의 차이로 명시한다.

공식 참조 구현은 `idiap/RDF`의 커밋
`550c13901ca62a659171b305b0d087d88c3fb580`으로 고정한다. 전처리는
`panda_layer/mesh_test.py`, 학습 표본 생성은 `sample_sdf_points.py`,
회귀는 `bf_sdf.py`를 기준으로 한다. 차수와 기저 개수, 좌표 정규화 및
거리 단위를 구분하며, Loss의 합/평균 정의가 다른 정규화 계수를 그대로 옮기지 않는다.

### 이전 독자 학습 설정의 상태

축별 12차, 학습점 50,000개, 학습 분포 60:40, 표면 근처 학습 범위 ±60 mm는
원 논문을 따르기로 변경하면서 보류되었다. 논문 설정으로 확인 없이 재사용하지 않는다.
독립 검증점 5,000개와 검증 분포 60:40은 이후 별도의 오프라인 품질 검사 설정으로
다시 확정되었으며 아래 9절에 적용한다.

## 4. 안전거리와 두 동심 구

물리적 self-collision 안전거리와 RDF 오차 여유는 다음과 같다.

$$
d_{\mathrm{physical}}=0.030,\qquad
\epsilon_{\mathrm{RDF}}=0.010,\qquad
d_{\mathrm{effective}}=0.040\ \mathrm m.
$$

링크별 Visual mesh의 최소 포괄 구 중심을 cᵢ, 반지름을 r_mesh,i로 정한다.

$$
r_{0,i}=r_{\mathrm{mesh},i}+d_{\mathrm{effective}},\qquad \alpha=0.5,
$$

$$
r_{1,i}=\max\left((1+\alpha)r_{0,i},\ r_{\mathrm{mesh},i}+0.060\right),
\qquad \Delta r_i=r_{1,i}-r_{0,i}.
$$

외부 구는 기본 비율뿐 아니라 표면 안팎 60 mm 검사 영역의 포함 조건도 만족해야 한다.
안전거리와 기본 전환 비율은 YAML에서 조절한다. 변경 시 기존 학습 영역과 artifact의
유효성을 다시 확인한다. 10 mm 오차 여유는 경험적 검증 기반이며 전역 오차 상한 증명은 아니다.

## 5. 표면 최댓값과 외부 함수

$$
M_i=\max_{\|x-c_i\|=r_{0,i}}f_i(x).
$$

오프라인에서 다음 방법으로 추정한다.

1. 내부 구 표면에 고르게 배치한 10,000개 점에서 RDF를 평가한다.
2. 값이 큰 영역에서 서로 떨어진 20개 초기점을 선택한다.
3. 각 초기점에서 구 표면 제약 수치 최적화를 수행한다.
4. 샘플 평가와 최적화에서 얻은 값 중 최댓값을 저장한다.

샘플 수와 초기점 수는 조절 가능하게 한다. 저장값은 추정치이며 엄밀한 전역 최대를
보장하지 않는다. 정확한 최적화 기법과 종료 허용오차는 구현자가 정해 기록한다.

링크 첨자를 생략하면 외부 함수는 다음과 같다.

$$
\rho=\|p-c\|,\qquad v=\frac{p-c}{\rho},\qquad F(p)=M+\rho-r_0.
$$

외부 구 표면에서 F = M + Δr이고, 바깥에서도 계속 방사 방향으로 증가한다.
외부 전체를 상수 M + Δr로 고정하지 않는다.

## 6. 스칼라 smoothstep과 정확한 기울기

$$
t=\frac{\rho-r_0}{r_1-r_0},\qquad
\sigma(\rho)=\begin{cases}
0,&\rho\le r_0,\\
3t^2-2t^3,&r_0<\rho<r_1,\\
1,&\rho\ge r_1.
\end{cases}
$$

$$
D(p)=\begin{cases}
f(p),&\rho\le r_0,\\
(1-\sigma)f(p)+\sigma F(p),&r_0<\rho<r_1,\\
F(p),&\rho\ge r_1.
\end{cases}
$$

전환 구간에서는 다음 전체 미분을 사용한다.

$$
\nabla_pD=(1-\sigma)\nabla_pf+\sigma v
+(F-f)\frac{6t(1-t)}{r_1-r_0}v.
$$

내부에서는 ∇f, 외부에서는 v를 사용한다. 구 중심에서는 v를 계산하지 않는다.
스칼라 함수와 무관한 별도 gradient 혼합은 사용하지 않는다.
RDF가 매끄러우면 두 경계에서 값과 1차 미분이 연결된다.

D는 실제 거리의 하한이 아니다. 내부 구가 물체와 유효 안전 여유 영역을 포함하도록
구성하고, 내부 RDF 판정의 정확성을 검증한다. 매끄러움만으로 gradient 방향·크기나
단조성이 보장되지는 않는다. 본 확장은 원 논문 학습법과 구분되는 runtime 설계다.

## 7. 표면 질의점과 거리 집계

### 질의점 표본

$$
N_i=\left\lceil\lambda_{\mathrm{query}}4\pi r_{0,i}^2\right\rceil,
\qquad\lambda_{\mathrm{query}}=500\ \mathrm m^{-2}.
$$

개수는 내부 구의 표면적으로 정하되 실제 점은 Visual mesh 표면에 배치한다.
Mesh 면적 비례 후보를 생성하고 서로 떨어진 점을 선택해 군집을 줄인다.
밀도는 YAML에서 조절한다. 최대 샘플 간격이나 연속 표면 전체의 충돌 누락 방지는
엄밀하게 보장되지 않는다. 이 점들은 RDF 학습점과 별개다.

### 고정 단방향 top-k

2026-10-01 사용자 승인으로 양방향 집계를 고정 단방향 집계로 변경했다.
순서는 `link0 < ... < link7 < hand`이며, 앞쪽 링크 i의 표면점을 뒤쪽 링크 j의
RDF에 질의한다. 예를 들어 `link1` 표면점 → `link4` RDF만 평가하며 역방향은
평가하지 않는다. 쌍 입력 순서나 모델 사전 순서로 방향이 달라지지 않는다.
RDF 평가가 필요한 쌍에서는 앞쪽 링크의 모든 질의점을 사용하며 반구 필터는
적용하지 않는다. 아래 구 선별로 생략된 먼 쌍은 질의점 대신 구 장벽을 사용한다.
기본 k=10이며,
매 평가마다 현재 값이 가장 작은 점들을 다시 선택한다. Hysteresis는 적용하지 않는다.
설정에서 k를 변경하거나 전체 샘플을 사용할 수 있다.

$$
n=\min(k,N_i) \quad (i<j).
$$

선택 교체 시 gradient 불연속은 우선 허용하고 검증 대상으로 남긴다.
동률은 재현 가능한 방식으로 처리하며 세부 규칙을 구현 문서에 기록한다.

### 비정규화 soft-min

$$
\varepsilon_{\mathrm{sm}}=0.005\ \mathrm m,\qquad
\beta=\frac{\log n}{\varepsilon_{\mathrm{sm}}},\qquad
\widetilde D_{ij}=-\frac1\beta\log\sum_{a=1}^n e^{-\beta D_a}.
$$

기본 k=10에서 n=10이면 beta는 약 460.52 m⁻¹이다. 현재 YAML의 k=2에서
n=2이면 약 138.63 m⁻¹이다. 단방향에서 선택된 실제 개수에 맞춰 계산한다.
합을 n으로 나누지 않고 stable log-sum-exp를 사용한다.
n=1이면 해당 거리 자체를 사용하고, n=0은 유효하지 않은 입력으로 처리한다.

$$
\min_aD_a-\varepsilon_{\mathrm{sm}}\le\widetilde D_{ij}\le\min_aD_a.
$$

Soft-min 오차는 YAML에서 조절하며 RDF 오차 여유와 별개다.
Soft-min의 보수 오차 5 mm를 barrier에서 다시 차감하지 않는다.

단방향 변경은 학습 계수·반경·질의점·오차 검증 기준을 변경하지 않지만,
역방향 표본의 보완이 사라지므로 이전 양방향 barrier와 안전 판정의 동등성을
보장하지 않는다. 원래 모델의 검증 기록도 새 정책의 충돌 보증으로 바꾸지 않는다.

### 연속 구 선별 (2026-10-01)

사용자 승인으로 `sphere_gate`를 추가했다. 기본값은 false이며 현재 YAML은 true다.
모델의 로컬 구 중심을 world로 옮긴 점을 $c_i(q)$, 두 번째 반경 합을
$R=r_{1,i}+r_{1,j}$, 중심 거리를 $L=\|c_j-c_i\|$라 한다.
초기화 때 각 artifact 중심에서 실제 Visual mesh의 전체 정점과 저장 질의점을
포함하는 반경 $b_i$를 확인한다(바깥쪽 수치 여유 $10^{-9}$ m 포함).
기존 모델 로더의 형상·배열·검증 검사는 유지한다.

$$
m=m_{\mathrm{physical,runtime}}+m_{\mathrm{error}},\quad
A=R-b_i-b_j-m>0,\quad
\Delta=\eta A,\quad 0<\eta<1.
$$

$\eta$는 `sphere_gate_transition_fraction`이며 기본값은 0.5다.
형상 포함 실패나 양의 전환 여유 부족은 명시적 실패로 처리한다.
기존 `transition_ratio`, 학습 반경·계수·질의점·보고서는 수정하지 않는다.

$$
h_s=L-b_i-b_j-m,\qquad h_R=\widetilde D_{ij}-m,
$$
$$
u=\operatorname{clip}((R-L)/\Delta,0,1),\quad w=3u^2-2u^3,
\qquad h_{ij}=(1-w)h_s+w h_R.
$$

$L\ge R$에서는 RDF를 계산하지 않고 구 장벽만 사용한다.
$L\le R-\Delta$에서는 기존 단방향 RDF를 그대로 사용한다.
중간 구간의 구 여유는 $h_s\ge A-\Delta>0$이므로, 기하학적으로 분리된 영역에서
두 표현을 연결한다. 쌍별 CBF 행을 삭제하거나 가중치로 제약식 자체를 축소하지 않는다.

$$
\nabla_q h_{ij}=(1-w)\nabla_q h_s+w\nabla_q h_R
 +(h_R-h_s)\nabla_q w.
$$

구 중심의 Jacobian에는 로컬 중심의 회전 운동도 포함한다. 두 경계에서
$\nabla_q w=0$이므로 선택 집합이 고정된 RDF 구간에 대해 C1으로 연결한다.
기존 top-k 교체의 gradient 불연속을 제거하거나, 표본 검증을 연속 공간의
충돌 안전성 증명으로 바꾸는 것은 아니다. 먼 쌍의 장벽은 이전 RDF와 달라진다.
상세 식·실측·검증 범위는 [실행 최적화 문서](panda_rdf_runtime_optimization.md)를 따른다.

## 8. 상대 Jacobian과 CBF

$$
x_{i,a}=R_is_{i,a}+t_i,\qquad
p_{j\leftarrow i,a}=R_j^\top(x_{i,a}-t_j) \quad (i<j),
$$

$$
\nabla_qD_a=\left(\frac{\partial p_{j\leftarrow i,a}}{\partial q}\right)^\top
\nabla_pD_j.
$$

질의하는 점과 질의받는 링크의 상대운동을 모두 반영한다. 선택 집합이 고정된 구간에서

$$
w_a=\frac{e^{-\beta D_a}}{\sum_b e^{-\beta D_b}},\qquad
\nabla_q\widetilde D_{ij}=\sum_aw_a\nabla_qD_a.
$$

$$
h_R=\widetilde D_{ij}-(m_{\mathrm{physical}}+m_{\mathrm{error}}),\qquad
\nabla_qh_{ij}^\top\dot q\ge-\gamma h_{ij},\qquad
\gamma=1\ \mathrm s^{-1}.
$$

구 선별을 끄면 $h_{ij}=h_R$이며, 켜면 7절의 혼합 장벽과 그 전체 미분을 사용한다.
모든 쌍에 공통 gain을 사용하고 YAML에서 조절한다. 링크 쌍별 hard CBF 제약을
사용하며 CLF slack을 공유하지 않는다.

## 9. 오프라인 검증

모델당 독립 검증점은 5,000개다.

- 외부 학습 구 전체에서 3,000개.
- 재구성 mesh 표면 안팎 60 mm에서 2,000개.
- 학습점과 독립적으로 생성하며 난수 흐름을 분리한다.

### 필수 거리 오차 기준

아래의 d_mesh는 voxel 전처리로 **재구성한 mesh**의 signed distance다.
원본 Visual mesh와 재구성 mesh 사이의 형상 오차와 혼합하지 않는다.

$$
\mathcal V_{\mathrm{near}}
=\{p\in\mathcal V:0\le d_{\mathrm{mesh}}(p)\le0.060\},
$$

$$
\max_{p\in\mathcal V_{\mathrm{near}}}
|f(p)-d_{\mathrm{mesh}}(p)|\le0.010\ \mathrm m.
$$

기준 거리 $d_{\mathrm{mesh}}<0$인 내부 점은 거리 정확도 평가에서 제외한다.
여기서 내부는 **로봇 링크의 기준 mesh가 둘러싼 물체 내부**를 뜻한다.
RDF 학습 구 내부라는 뜻이 아니며, 학습 구 안에 있더라도 물체 밖인 점은 평가한다.
표면($d_{\mathrm{mesh}}=0$)은 포함한다. 학습 구 전체의 오차도 외부 점에서만 기록하되,
위 10 mm 통과 기준은 외부 near-surface 점에 적용한다. 예측값이 음수라는 이유로
외부 점을 제외하지 않으며, 이 경우도 부호 오판과 거리 오차로 집계한다.
생성 표본 5,000개는 유지하고, 실제 평가점·near 평가점·내부 제외점 수를 기록한다.
외부 near 표본이 없으면 합격시키지 않는다. 내부 signed 학습 데이터와
공간·확장·경계·관절 미분 검사는 유지하며, 실행 중 거리값을 잘라내지 않는다.
이는 유한 검증점의 경험적 기준이며 연속 영역의 오차 상한 증명은 아니다.

### 학습 오차 개선 결정 기록 — 2026-09-28

아래 결정 1–11은 당시 조건과 실험 이력이다. 현재 허용오차·CBF 오차 여유는

- 새 점은 기준 mesh 표면의 면적 비례 표본 $s$와 바깥 단위 법선 $n(s)$에서

  $$
  p=s+\ell n(s),\qquad \ell\sim\mathcal U(0,0.060)
  $$

  로 제안한다. 기준 삼각형 signed distance로 $0\le d_{\mathrm{mesh}}(p)\le0.060$
  및 학습 구 포함 조건을 확인한 점만 채택한다. 법선 이동량의 균등 분포이며,
  오목한 영역을 포함한 실제 최근접 거리의 균등 분포를 주장하지 않는다.
  실제 거리의 10 mm 간격 히스토그램과 거부 수를 기록한다.
- 생성 RNG는 `SeedSequence(0, spawn_key=(4,7))`로 검증 RNG와 분리한다.
  검증점 또는 최악점 좌표를 새 학습점으로 재사용하지 않는다. 최대 후보 수는
  요구 표본 수의 10배이며 부족하면 오류를 내고 학습하지 않는다.
- **학습 라벨은 기존 scan/normal 방식**(100개 시점, 400×400 해상도,
  이웃 100개 법선, 외부 구 정규화)으로 계산한다. 기준 mesh 거리는 표본의
  영역 확인과 라벨 오차 진단에만 사용하며, 이를 학습 목표값으로 바꾸지 않는다.
  음수 라벨은 조용히 양수로 바꾸지 않고 개수와 오차를 보고한다.
- 새 점·학습 라벨·영역 판정용 기준 거리·생성 시간·표본 구성·파일 해시를
  저장한다. 실제 배치 구성은 metadata의 `training.exterior_sampling`에 기록하며,
  기존 기준 옵션은 `training.baseline_options`에 보관한다.
- 새 실험은 별도 경로에서 수행하며 데이터 준비 완료와 학습·검증 완료를
  단계별로 보고한다. 외부 near 최대·평균오차 및 최대 과대평가를 기존 400회
  결과와 비교한다. 5 mm 기준과 미분 검사는 유지하고 제어 모델은 교체하지 않는다.

**결정 11: 외부 보강 분포에서 400→800회를 비교하고 재귀 회귀 상태를 저장한다.**

- 기존 외부 풀 500,000개와 원래 near/random 풀을 파일 해시까지 동일하게
  재사용한다. 배치는 512/128/640을 유지하며 기존 400회 전체 인덱스 prefix를
  보존하고 같은 RNG 흐름에서 400회를 더 생성한다. 검증점은 학습에 넣지 않는다.
- `configs/archive/panda_rdf_training_bp24_800.yaml`은 400회 설정에서 `updates`만 800으로
  바꾼다. BP_24·float64·scan 라벨·기준 형상·구·정규화·5 mm 기준은 유지한다.
- 재개에 필요한 상태는 정규화된 계수 $w_k$와 역정보 행렬 $B_k$다.
  실행 RDF 파일의 미터 단위 계수만으로 $B_k$를 복원하거나, 이를 초기화한 채
  이어 학습했다고 주장하지 않는다. 재개 시 $w_k,B_k$를 복원하고 배치 $k+1$부터
  원래 재귀 갱신을 수행한다.
- 400회 간격과 마지막 회차에 체크포인트를 별도 디렉터리로 저장한다.
  BP_24의 $B_k$는 $13824\times13824$ float64로 약 1.42 GiB다.
  계수·행렬·누적 회차·누적 표본 수·학습 옵션·기저·정규화·입력 해시·처리한
  배치 prefix 해시를 기록한다. pickle 없이 저장하며 완료된 스냅샷을 덮어쓰지 않는다.
- 재개 시 무결성·배열 크기·정밀도·유한성·행렬 대칭·학습 조건·데이터·처리한
  배치 일치를 확인하고, 불일치하면 중단한다. 학습 목표 회차는 늘릴 수 있지만
  이전 배치를 중복 처리하거나 생략해서는 안 된다. 새 결과 디렉터리를 사용한다.
- 기존 완료된 400회에는 $B_k$가 없으므로 이번 800회는 처음부터 계산한다.
  400회 시점의 계수와 이전 결과의 일치를 검사하고 체크포인트를 남긴 뒤 계속한다.
  CPU 및 CUDA에서 연속 학습과 저장·복원 학습의 계수와 $B$ 일치를 먼저 시험한다.
- 데이터 생성 시간, 재귀 학습 시간, 체크포인트 전송·검사·저장 시간은 구분한다.
  이 상태 파일은 오프라인 재개 전용이며 제어기의 RDF 승인 기준을 변경하지 않는다.

**결정 12: 허용오차와 CBF 오차 여유를 함께 10 mm로 변경한다.**

- `safety.rdf.error_margin = 0.010 m`를 독립 외부 near 검증의 최대 절대오차
  기준과 CBF 오차 보정에 함께 사용한다. 물리적 여유 `0.030 m`는 유지한다.
  따라서 $h_{ij}=\widetilde D_{ij}-(0.030+0.010)$이며 총 차감 여유는 40 mm다.
- 검증 영역 `0 <= d_mesh <= 60 mm`, 내부 평가 제외, 독립 표본 5,000개,
  미분·경계·관절 gradient 검사, 실행 시 호환성 검사는 유지한다.
  Soft-min 오차 `0.005 m`, CLF/QP 구조와 외부 장애물 모델은 변경하지 않는다.
- 오차 여유는 내부·외부 구와 학습 정규화에도 연결되어 있다. YAML 변경만으로
  기존 5 mm 모델을 승인하지 않는다. `--validate-only`나 질의점 갱신도
  변경된 구의 재생성을 대체하지 않는다. 구형 모델의 metadata만 바꾸지 않는다.
- 기존 link4 BP_24 외부 보강 800회 후보는 기존 검증점에서 10 mm 기준으로
  오프라인 재판정할 수 있지만, 단일 링크 판정은 전체 로봇의 실행 승인이 아니다.
  호환되는 전체 9개 링크와 관절 gradient 검증이 끝나기 전 실행 모델을 교체하지 않는다.
- 기존 학습 후보·보고서·체크포인트는 보존한다. 과거 입력을 고정한 재개 실험은
  원래 구·정규화·5 mm 기준을 유지하며, 새 설정에 대한 학습으로 간주하지 않는다.
- 유한 표본의 10 mm 통과는 전역 오차 상한이나 원본 visual mesh·실제 로봇의
  안전 보증이 아니다. 10 mm 초과 또는 미분·호환성 검사 실패는 계속 거부한다.

**결정 13: 새 10 mm 설정으로 전체 9개 링크를 GPU에서 학습한다 (2026-09-29).**

- base 포함 link0–link7과 닫힌 finger를 포함한 hand를 순차 학습한다.
  각 링크 BP_24(축당 23차)·800회·float64, 배치 near/random/exterior
  512/128/640, 각 풀 500,000개를 사용한다. 10 mm 오차 여유와 30 mm 물리 여유에
  맞춘 새 구·정규화로 생성하며 기존 link4의 5 mm 모델이나 회귀 상태를 재개하지 않는다.
- 별도 `configs/training/panda_rdf_training_full_bp24.yaml`을 사용한다. 외부 표본은 기존 방식의
  0–60 mm mesh 영역 판정과 scan/normal 라벨을 유지한다. 기하 전처리·회귀 목적·
  허용오차·CBF 및 CLF 구조는 추가 변경하지 않는다.
- 링크 인덱스를 난수 spawn key에 반영한다. 목적 0=train, 1=validation,
  2=query, 7=exterior points, 8=exterior batches로 학습과 검증을 분리한다.
  기존 link4 전용 실험 함수의 기본 인덱스 4는 유지하여 과거 재현성을 보존한다.
- 각 링크의 실제 학습 풀·배치 인덱스·해시·독립 검증점·계수와 400/800회
  정규화 계수·역정보 행렬을 저장한다. 최종 모델은 별도 후보 파일에 누적하며
  기존 학습 결과·모델 파일을 덮어쓰지 않는다. 18개 행렬 총량은 약 25.6 GiB다.
- 단순 거리 기준 미달은 기록하고 다음 링크를 학습한다. 계산 실패는 중단·보고한다.
  전체 링크가 끝나면 기존 관절 gradient 검사와 CPU runtime benchmark를 수행한다.
  전체 거리·미분·호환성 검증 결과와 전송 무결성을 확인한 뒤 사용자에게 보고한다.
  이 학습 요청만으로 실행 모델을 자동 교체하거나 제어 시뮬레이션을 시작하지 않는다.

### 미분 및 경계 검사

- 같은 RDF의 해석적 gradient와 수치 미분 일치.
- 확장 함수의 gradient와 수치 미분 일치.
- 두 구 경계에서 함수값과 gradient 연속성.
- 제어 구현의 상대 Jacobian과 관절 gradient 일치.

검사는 오프라인에서 수행한다. 실행 시마다 수치 미분 검사를 반복하지 않는다.
수치 허용오차는 구현자가 합리적으로 정하고 근거와 함께 기록한다.

### 추가 통계

- 거리 오차와 부호 오판.
- Gradient 크기·방향 오차.
- 실제 mesh gradient가 정의되지 않거나 모호한 점의 별도 집계.

추가 통계는 우선 합격·불합격 기준에 추가하지 않는다. 실제 거리 gradient 정확도와
동일 모델의 analytic/수치 미분 일치는 서로 다른 검사다.

검증 실패 시 해당 RDF 사용을 중단하고 링크 및 실패 항목·오차를 보고한다.
설정을 검토한 후 별도로 재학습한다. 경고만 출력하고 사용하지 않는다.

## 10. 실행 및 실패 정책

- 기본 self-collision 모델은 RDF. Capsule은 명시적으로 선택할 때만 사용한다.
- Artifact가 없거나 검증에 실패했거나 설정과 호환되지 않으면 사용을 중단한다.
- 불일치 항목과 재생성 방법을 안내한다. 자동 재학습·자동 capsule fallback은 없다.
- 실행 시 오프라인 검증 통과 기록과 artifact–설정 호환성을 확인한다.
- Trajectory 초기 상태의 h가 음수이면 제어를 시작하지 않고 위반 쌍과 값을 보고한다.
- 초기 trajectory 검사와 Safe IK의 임의 seed 처리는 구분한다.
- 제어 중 QP infeasible 또는 수치 실패 시 시뮬레이션을 중단한다.
- 실패 시점, 관절 상태, barrier 값, solver 상태를 저장한다.
- 적분 후 추가 RDF barrier 검사 및 그 결과에 따른 자동 중단은 추가하지 않는다.
- 별도 runtime mesh collision checker는 없다.

이산 적분과 유한 표면 샘플링에 따른 안전 위반 가능성은 남는다.

## 11. 실행 환경, 재현성 및 로그

CPU 참조 구현과 계산시간 측정 후, 2026-10-01 사용자 승인으로 선택 CUDA 추론을
추가했다. `safety.rdf.runtime_device: cuda` 또는 `--rdf-device cuda`로 선택한다.
float64, 학습 계수·질의점·반경, 단방향·구 선별·top-k·soft-min·상대운동 미분을
유지하고 CPU와의 수치 일치를 검증한다. CUDA가 없으면 명시적으로 실패하며
자동 CPU fallback이나 정밀도 축소를 하지 않는다. 기본 CPU 경로는 보존한다.
상세 계산 경계·시간 계측 의미는 [실행 최적화 문서](panda_rdf_runtime_optimization.md)를 따른다.
기본 seed는 0이고 설정에서 변경할 수 있다. 학습·검증·query 샘플링에는
서로 구분된 난수 흐름을 사용한다.

### 오프라인 데이터 생성 실행 정책 (2026-09-29 결정)

- 다음 **새 실행**부터 여러 CPU 코어로 데이터 거리 질의를 처리한다.
  현재 진행 중인 9링크 학습은 코드 교체·중단·재시작 없이 기존 설정으로 끝낸다.
- CLI `--data-workers` 기본값은 affinity 내 최대 4개 프로세스다. `1`은 직렬
  재현용이고 명시적으로 수를 조절할 수 있다. BLAS `--threads`와 구분한다.
- Exterior 점 선택용 기준 mesh 거리, near/random/exterior scan/normal 라벨
  계산만 병렬화한다. 스캔 렌더링과 난수 생성은 부모에서 수행한다.
- 난수 흐름·표본 분포/수량·순서·기존 청크 경계·학습 라벨 방법은 유지한다.
  작업자 수에 따라 결과 배열이 달라지지 않는지 검증한다.
- 안전한 프로세스 시작 방식 `spawn`, 작업자별 BLAS 1스레드, 제한된 대기 청크를
  사용한다. 데이터 생성 후 작업자를 정리하고 GPU 회귀를 시작한다.
- 작업자 수는 실행 환경 정보로 기록한다. BP_24, 800회, float64 회귀,
  512/128/640 배치, 10 mm 기준 및 내부 점의 평가 제외 규칙은 바꾸지 않는다.
- 이번 변경은 다음 실험 시작이나 제어용 후보 설치 승인이 아니다.

기존 실험 로그에 다음을 추가한다.

- 최소 self-collision barrier와 해당 링크 쌍.
- RDF 거리 평가, 샘플 선택, gradient 계산, QP 풀이 시간.
- QP 상태 및 중단 사유.
- 사용한 RDF artifact 식별자와 설정.

Barrier 기록은 제어 시 계산한 값을 활용한다. 적분 후 추가 검사를 로그 명목으로
도입하지 않는다. Safe IK 단계에 QP가 없다면 QP 시간은 해당 없음으로 구분한다.

## 12. 설정·학습 산출물 요구

YAML 등 설정으로 제어할 대상은 self-collision 모델, query 밀도, top-k/전체 모드,
soft-min 오차, 물리적 안전거리, 전환 비율, 공통 CBF gain, 기본 seed 등이다.
RDF 오차 여유 기본 10 mm도 다른 오차와 구분해 명시한다.
정확한 키 이름과 학습/실행 설정의 파일 분리는 구현 세부사항으로 정해 기록한다.

Artifact는 형상 및 닫힘 자세, 좌표계·정규화, 학습 설정, c/r₀/r₁, M 추정 설정·결과,
검증 결과를 식별할 수 있어야 한다. 변경된 설정에 기존 artifact를 조용히 재사용하지 않는다.
관련 항목의 호환성은 의존성을 기준으로 검사하며 모든 runtime 값 변경을 곧바로
재학습 사유로 취급하지 않는다.

## 13. 구현자에게 위임된 사항과 남은 확인

원 논문·공식 구현에 명시된 값이 있으면 우선 따른다. 없는 구현 세부값은 합리적인
기본값을 정하고 근거·출처·실제 사용값을 기록한다. 최적화 종료 허용오차, batch 크기,
샘플링 구현과 artifact 형식 등을 작은 설정마다 다시 질문하지 않는다.

다음은 아직 확인·구체화가 필요한 작업이다.

1. 원 논문·공식 코드 버전과 학습 하이퍼파라미터.
2. Mesh 및 관절 매핑, 닫힘 수치, signed distance 라벨 생성 방법.
