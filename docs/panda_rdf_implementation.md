# Panda RDF 구현 상세

구현 기준은 [Panda RDF 확정 명세](panda_rdf_specification.md)다.
실측 결과는 [구현 진행 상황](panda_rdf_implementation_status.md)을 참조한다.
학습 후보를 생성했다고 실행 승인을 받은 것은 아니다. 9개 링크 모두의 검증과
관절 미분 검사를 통과해야 로더가 산출물을 받아들인다.

## 명령과 설정

```bash
uv sync --locked
make panda-train-rdf
make panda-validate-rdf
make panda-validate-rdf ARGS="--refresh-queries"
make panda-validate-rdf ARGS="--refresh-extension" # 계수는 유지하고 M을 다시 계산
# 일부 링크만 진단한다. 전체 로봇 산출물의 사용 승인을 받을 수는 없다.
make panda-train-rdf OUTPUT=outputs/panda_rdf/link0.npz ARGS="--links link0"
```

같은 작업을 수행하는 진입 명령은 `safe-ik-train-panda-rdf`다.
`--config`는 실행 YAML을, `--training-config`는
`configs/panda_rdf_training.yaml`을 선택한다. 기본 산출물은
`models/panda_rdf.npz`이며, 옆의 `.report.json`에는 실패 결과를 포함한
검증 근거를 사람이 읽을 수 있는 형태로 저장한다. 종료 코드 2는 후보가
승인되지 않았음을 뜻한다. 학습 중에는 미완성 중간 산출물을 원자적으로
저장하며, 실행용 로더는 이를 거부한다. 산출물 생성은 명시적으로 실행해야
하며, 제어기를 호출했다고 자동으로 학습하지 않는다.

스캔 생성에는 공식 `mesh-to-sdf` 렌더러를 사용한다. 기본값은 화면 없이
실행하는 EGL이며 `--gl-platform osmesa`도 지원한다. 수치 근사, 질의,
미분은 CPU에서 수행하며 BLAS 스레드 기본값은 1개다(`--threads`).
IK나 제어기에서는 렌더러나 삼각형 기준 거리 계산을 호출하지 않는다.

`safety.self_collision_model`의 기본값은 `rdf`다. 기존 `capsule`
방식은 명시적으로 선택할 수 있다. `safety.margin`과 `safety.alpha`는
기존 외부 장애물 캡슐 및 관절 한계 제약에 계속 사용한다.
자기 충돌 RDF 설정은 `safety.rdf` 아래에 둔다.

| 키 | 기본값 | 영향을 받는 항목 |
| --- | --- | --- |
| `artifact` | `../models/panda_rdf.npz` | YAML 위치를 기준으로 경로 해석 |
| `physical_margin` | 0.030 m | 내부·외부 구, 확장 함수 |
| `error_margin` | 0.005 m | 구와 오프라인 합격 판정 |
| `transition_ratio` | 0.5 | 외부 학습 구 |
| `query_density` | 500 m⁻² | 표면 질의점; 계수 재학습 없이 갱신 가능 |
| `seed` | 0 | 학습·검증·질의점의 독립 난수 흐름 |
| `top_k` | 10; null이면 전체 사용 | 실행 시 계산에만 영향 |
| `softmin_error` | 0.005 m | 실행 시 계산에만 영향; 장벽에서 다시 차감하지 않음 |
| `cbf_gain` | 1 s⁻¹ | 실행 시 계산에만 영향 |

형상이나 구 설정이 맞지 않으면 명시적으로 다시 생성해야 한다.
질의 밀도·시드 변경에는 `--refresh-queries`를 사용할 수 있다.
계수를 보존하면서 질의점을 다시 만들고 검증을 반복한다.
`--validate-only` 역시 계수를 보존한다. 실행 시 top-k, soft-min,
이득 변경은 계수 재학습을 요구하지 않는다. 기존 궤적 주기와
자세·순차 단계 CLF는 재정의하지 않았다.

## 형상과 오프라인 수치 방법

`panda_rdf_geometry.py`는 MuJoCo 그룹 2의 시각화 메시를 추출한다.
컴파일된 geom 변환으로 각 메시의 원래 위치를 복원하고, 링크의 로컬
좌표계로 표현한다. `link0`부터 `link7`, `hand`까지 총 9개 형상이다.
양쪽 손가락 본체의 손 기준 위치는 `[0, 0, 0.0584]`이고, 오른쪽의
쿼터니언은 `[0, 0, 0, 1]`로 유지한다. 원본 손가락 관절 범위는
`[0, 0.04]` m이며 현재 고정 모델은 관절값 0을 나타낸다.
양쪽 손가락의 시각화 메시는 손 형상에 포함한다.

병합 후 실제 부모–자식 인접 관계로 직접 연결된 8쌍을 제외한다.
베이스와 손을 포함한 나머지 무순서 쌍 28개를 모두 검사한다.
기존 캡슐 제외 목록은 RDF 쌍에 적용하지 않는다. 산출물에는 원본 메시
경로, 본체 변환, 관절, 쌍 목록, 형상 SHA-256 식별값을 기록한다.

최소 포괄 구는 볼록 껍질 정점에 대해 반지름 제곱을 최소화하는 볼록
문제로 풀며 SLSQP를 사용한다. 수치 조건을 개선하도록 정규화하고,
`ftol=1e-12`, 최대 1,000회 반복을 적용한다. 수렴 및 형상 포함 여부를
검사한다. 저장 반지름은 실제 정점 중 가장 먼 점까지 포함하며,
각 구의 반지름 정의는 명세 4절을 따른다.

학습은 [공식 RDF 커밋 dc08da7](https://github.com/yimingli1998/RDF/tree/dc08da7ec78e7cfb002f5a118d06d9eebbf9c37d)을 따른다.
축당 기저 함수 8개(7차), 초기 가중치 0, `B0=I/1e-4`, 갱신 200회를
사용한다. 매회 표면 근처 표본 1,024개와 무작위 표본 256개를 각각
500,000개 표본 풀에서 배치 내 중복 없이 선택한다. 기존 float64 재귀
해법을 보존했다. 목표값을 `r1`로 정규화하며, 저장 계수와 질의 결과는
미터 단위다. 기울기 손실이나 Eikonal 손실은 사용하지 않는다.

스캔 점군에는 해상도 400×400의 시점 100개와 이웃 100개의 법선 투표
부호 판정을 사용한다. 공식 표면 근처 표본 풀의 비율을 재현한다.
47%는 표면점에 정규화된 표준편차 0.0025의 가우스 잡음을 더하고,
47%는 0.00025의 잡음을 더하며, 나머지 6%는 구 내부 균일 표본이다.
학습 영역에 따른 변경은 다음과 같다. 외부 구로 정규화하고, 무작위
표본 풀을 원본의 정육면체 대신 해당 구 내부에서 생성하며, 드물게
구 밖으로 나가는 표면 근처 표본은 다시 뽑는다. 같은 스캔 점군을
공유하고 라벨을 2,048개씩 계산하여 중복 렌더링과 과도한 메모리 사용을
줄인다. 외부 학습 영역을 유지하기 위해 원본 래퍼의 추가 메시 정규화는
적용하지 않는다. 원본의 정규화된 최소 부피 휴리스틱도 확대된 구에
그대로 적용하지 않는다. 라이브러리 버전과 실제 사용 설정을 기록한다.

난수 흐름은 `SeedSequence(seed, spawn_key=(link_index, purpose))`를
사용한다. 용도 번호는 학습 0, 검증 1, 질의점 2, 관절 검사 3, 성능 측정 4다.
NumPy의 공유 전역 난수 상태는 사용하지 않는다. 질의점 후보는 메시 면적에
비례해 요청 개수의 30배, 최소 1,000개를 뽑고, 탐욕적 최원점 선택으로 줄인다.
첫 후보인 0번을 결정적인 시작점으로 삼는다.

최댓값 추정에는 피보나치 구 표면점 10,000개를 사용한다. 가장 큰 표본값을
포함하는 상위 10% 영역에서 서로 멀리 떨어진 시작점 20개를 고른다.
단위 구 제약 SLSQP에 `ftol=1e-12`, 최대 300회 반복을 적용한다.
각 결과는 구 표면에 다시 투영한 뒤 평가하며, 전체 표본과 최적화 결과의
최댓값을 저장한다. 중간 탐색점도 다항식 평가 전에 구 표면으로 정규화하고,
접평면 기울기의 연쇄법칙과 탐색 좌표 범위 제한을 적용하여 다항식 외삽과
오버플로를 방지한다. 각 최적화의 종료 상태를 기록한다.
이는 추정값이며 전역 최댓값의 증명은 아니다.

## 독립 검증

링크마다 외부 구 내부의 독립 균일 표본 3,000개와, 면적 비례 표면점에서
면 법선 방향으로 ±60 mm 균일 변위를 준 표본 2,000개를 생성한다.
독립 기준값은 정확한 삼각형 최근접 거리와
`trimesh.proximity.signed_distance`로 구하며, 외부가 양수가 되도록
부호를 뒤집는다. 스캔 학습 라벨을 재사용하지 않는다.
닫히지 않았거나 서로 겹치는 시각화 메시의 부호 있는 거리는 경험적
법선·광선 판정 규칙에 의존한다. 따라서 유일한 닫힌 입체의 SDF를
증명했다고 해석해서는 안 된다. 형상 보정, 볼록 형상 대체, 안전 여유
완화를 자동으로 수행하지 않는다.

`abs(d_mesh) <= 0.060`인 모든 검증점을 최대 오차 5 mm 합격 판정에
사용한다. 전체 영역 오차, 부호 오판, 기울기 크기·방향 오차, 기울기가
모호한 점의 개수는 별도로 기록한다. 표면에서 0.1 μm 이내인 점이나
삼각형 모서리에 가까운 점(최소 무게중심 좌표가 1e-5 미만)은 기울기
방향 통계에서 모호한 것으로 표시한다. **거리 합격 판정에서는 제외하지 않는다.**

해석적 공간 기울기와 중앙 차분의 비교에는 간격 1 μm, 절대 허용오차
1e-5를 사용한다. 내부·전환 구간·외부 표본에서는 C1 연속성만 갖는
경계에 차분 중심이 정확히 놓이지 않도록 한다. 경계 검사는 별도로
±10 nm 변위를 사용하고, 함수값 허용오차는 1e-5 m, 기울기는 1e-4로 둔다.
연속성 검사와 C1 접합부에서 발생하는 O(간격)의 차분 절단 오차를 구분하기
위함이다. 결정적으로 생성한 관절 상태 5개에서 모든 쌍의 집계 기울기를
간격 1e-6 rad, 허용오차 1e-4 m/rad로 검사한다. 두 이동 좌표계의 상대
Jacobian은 허용오차 1e-7 m/rad로 검사한다. top-k 구성 변경은 개수를
기록하고, 해당 매끄러운 집계 기울기 비교에서만 제외한다.
거리 표본을 제외하는 규칙이 아니다.

오프라인 CPU 측정에서는 예열 1회 후 같은 무작위 상태 20개에서 RDF와
기존 캡슐 평가기를 비교한다. 동일한 외부 장애물 캡슐을 포함하며,
제약 행 개수, 평균·95백분위 시간, 기존 제어 주기를 기록한다.
승인되지 않은 후보도 오프라인 시간 측정은 가능하지만 궤적 제어에는
사용할 수 없다.

## 실행 및 진단

`PandaRDFSafety`는 안전 자세 IK, 후보 거부, 궤적 CBF가 사용하는
공통 안전 인터페이스를 구현한다. 원본 표면점과 질의 대상 좌표계를
모두 변환하고, 양방향 평가와 매회 top-k 재선택을 수행하며,
비정규화된 안정적 log-sum-exp를 사용한다. 거리가 같으면 안정 정렬로
원래 표본 인덱스 순서를 유지한다. 기울기는 선택된 점에서만 계산하며
두 본체의 운동을 모두 반영한다. 장벽은 물리적 여유와 RDF 오차 여유의
합을 한 번만 차감한다. 각 자기 충돌 쌍에는 CLF 완화 변수 계수가 0인
완화 불가능한 CBF 행과 공통 RDF 이득을 적용한다.

각 IK 작업자는 자체 기구학을 만들고 산출물을 로드·검증한다.
궤적 초기 상태가 안전하지 않으면 IK, QP, 적분 없이 반환한다.
IK 탐색 자체를 호출할 때는 안전하지 않은 임의 초기 시드도 허용한다.
해법 실패, 실행 불가능한 QP, 형식이 잘못되거나 유한하지 않은 해,
수치 예외가 발생하면 궤적 실행을 멈추고 사유·상태·시점·확인 가능한
장벽값을 기록한다. 적분 후 RDF 추가 검사나 메시 검사는 도입하지 않았다.
최종 상태의 장벽 필드는 마지막 적분 전 제어 평가값을 뜻한다.

RDF 평가기는 동일한 q의 평가를 캐시한다. 제어 진단은 실제 제어에 사용한
장벽을 재사용하며 로그를 위해 다시 계산하지 않는다. NPZ 이력에는
모든 장벽 이름·값, 최소 자기 충돌 장벽과 해당 쌍, RDF 거리 평가·선택·
기울기 계산 각각의 시간, QP 시간·상태, 산출물 SHA-256과 설정을 포함한다.
거리 평가 시간에는 좌표 변환과 값만 계산하는 평가가 포함된다.
기울기 시간에는 이동 좌표계 Jacobian, 선택점 미분, 집계가 포함된다.
안전 IK는 병렬 작업자 결과를 포함한 RDF 누적 시간을 기록한다.
QP를 사용하지 않으므로 IK의 QP 시간은 null이다. 실행 출처 기록에는
해석된 산출물 경로와 파일 해시를 보존한다. 실행 초기화 실패도
요약 JSON으로 저장한다.

산출물 NPZ는 JSON 메타데이터와 수치 배열을 담으며
`allow_pickle=False`로 로드한다. 배열별 해시, 스키마 버전,
전체 링크·쌍 포함 여부, 형상·설정 호환성, 오프라인 통과 기록을 검사한다.
실패한 후보나 누락된 검증 기록 때문에 다른 모델로 자동 전환하거나
재학습하는 일은 없다.
