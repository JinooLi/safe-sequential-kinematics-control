# 문서 안내

현재 구현을 이해하는 설명, 과거 기록, 앞으로 수행할 실험 설계를 디렉토리로 구분한다.

| 위치 | 읽는 목적 | 갱신 기준 |
|---|---|---|
| [current](current/README.md) | 지금 어떤 입력이 어떤 계산을 거쳐 어떤 출력이 되는가 | 코드의 입력·출력이나 실행 경로가 바뀌면 함께 수정 |
| [history](history/README.md) | 어떤 설계를 논의했고 어떤 조건에서 어떤 결과를 얻었는가 | 과거 결과를 현재 결과로 덮어쓰지 않고 후속 기록 추가 |
| [experiments](experiments/panda_monte_carlo_protocol.md) | 어떤 가설을 어떤 공통 조건과 지표로 검증할 것인가 | 실행 전 조건을 확정하고, 결과는 실행 식별자와 함께 별도 기록 |

현재 구현 지도는 코드와 설정을 기준으로 작성한다. 연구 제안, 예정 기능, 예전 기본값은
현재 동작에 섞지 않는다. 확인 날짜와 코드 기준점을 남기고, 구체적인 실행의 조건은
그 실행에 저장된 `config.yaml`, `resolved_config.json`, `metadata.json`에서 확인한다.

`history`에 있다는 이유만으로 내용 전체가 폐기된 것은 아니다. 여전히 적용되는
수식과 정책도 포함하지만, 문서 전체가 최신 코드와 대조되었다는 뜻은 아니다.
과거 문서의 “현재”, “기본값”, “통과”는 해당 기록의 시점과 실험 조건에 한정한다.

2026-10-05에 기존 `docs` 문서와 HTML, 루트 README, `prompts/clarification.md`를
`history`로 옮겼다. 본문은 보존하고 기록 안내와 이동에 필요한 상대 링크만 조정했다.
실행·학습 설정, 소스, 테스트, 모델은 이 문서 정리에서 변경하지 않았다.
설정 옆의 [configs 안내](../configs/README.md)와 외부 자산의 출처·라이선스는 원래 위치에 둔다.

수식은 Markdown의 LaTeX 표기를 사용한다. 본문과 표 안에서는 `$...$`, 독립된 식은
빈 줄로 구분한 `$$...$$` 블록으로 작성한다. 여러 줄의 식은 `aligned`로 정렬한다.
함수명·설정 키·실행 명령·배열 shape에는 코드 표기를 사용한다.
2026-10-05에 기존 문서의 일반 텍스트 수식도 이 표기로 정리했으며,
연구 기록의 수치·실험 조건·결론은 그대로 유지했다.
