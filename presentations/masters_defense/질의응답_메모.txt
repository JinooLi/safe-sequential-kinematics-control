7쪽 및 A17 / Gonçalves의 차원 가정과 manipulator 관련성
기본 모델은 q̇ = u, q ∈ R^n. 기본 circulation 구성 T = ΩN에서 Ωᵀ = −Ω, ΩᵀΩ = I를 요구. 가역 skew-symmetric 행렬은 짝수 차원에만 존재하므로 이 기본 구성에는 n이 짝수라는 조건 존재.
홀수 차원에서는 skew-symmetric Ω가 특이하므로 T가 0이 되는 방향이 존재할 수 있음. Tᵀu ≥ β(D)에서 β(D) > 0인데 T = 0이면 제약이 실행 불가능. 따라서 같은 짝수 차원 정리를 그대로 적용할 수 없음.
다만 논문의 Section IV-C는 홀수 차원 확장을 별도로 논의하고, 3차원 비행 로봇 5대의 15차원 실험도 제시. ‘짝수 차원 전용이라 7-DOF에는 적용 불가능’이라는 단정은 부정확함.
논문은 4-DOF planar manipulator 실험도 포함. 본 연구와의 차이는 로봇팔 적용 유무가 아니라, IK에서 중간 link task를 구성하고 선택하는 구조의 사용 여부. 본 task-construction 절차는 3-DOF와 7-DOF에서 사용하며 짝수 차원 조건을 요구하지 않지만, 이것이 모든 task와 장애물에 대한 QP 실행 가능성이나 전역 수렴 보장은 아님.
출처: https://arxiv.org/html/2307.09901v1 의 기본 모델, circulation 구성, Section IV-C, Section V.

4–6쪽 / 배경: CLF → CBF → 결합한 QP
4쪽(40초): 관절 속도 입력 q̇ = u, task 오차 함수 V = 1/2 ||e(q)||², 감소 조건 ∇Vᵀu ≤ −c_V V 설명.
그릇 모양 그림은 task 오차에 대한 함수의 정성적 개형. V = 0은 task 달성을 의미하며, 여유 자유도로 인해 여러 관절 configuration이 같은 task를 만족할 수 있음.
5쪽(40초): 여유 거리 h = d − d_safe, 안전 집합 C = {q : h(q) ≥ 0}, CBF 조건 ∇hᵀu ≥ −γh 설명.
d는 link와 장애물 사이의 표면 거리. 안전 집합 내부에서는 h의 감소도 허용되지만, h = 0에서는 ḣ ≥ 0 필요. 이 조건이 항상 장애물에서 멀어지는 운동을 요구하는 것은 아님.
6쪽(45초): CLF, CBF, 입력 제한을 제약으로 두고 입력과 slack 비용을 최소화. 매 제어 주기 현재 q에서 다시 계산.
QP는 V 자체를 최소화하는 문제가 아님. Slack δ는 CLF 조건만 완화하며, 양의 δ는 V의 감소를 늦추거나 증가를 허용할 수 있음.
CBF와 입력 제한에는 slack을 두지 않음. CLF slack이 모든 QP의 실행 가능성을 보장하지는 않음.
안전 집합의 순방향 불변성은 barrier의 정칙성, 안전한 초기 상태, 실제 적용한 속도의 미분 부등식 만족을 전제로 하는 성질. 근사 형상, 이산 적분, clipping은 A9와 평가 한계에서 별도로 설명.
출처: 논문 sections/Preliminaries/CLF.tex, CBF.tex, CLF_CBF_QP.tex, sections/Method/Kinematic_Control.tex; Ames et al. (2017).
Planar 실행 단계에서는 6쪽 QP를 동일한 배치로 반복하고 활성 CLF constraint만 색으로 강조. 목적함수와 안전 제약은 그대로 유지.

7쪽 / 관련 연구와 본 연구의 범위 — A7 참고문헌: 44–47쪽
Reis et al. (2021): CLF–CBF QP에 점근적으로 안정한 원치 않는 평형점이 존재할 수 있음을 제시. 모든 episode에서 정체가 발생한다는 의미는 아님.
7쪽 대표식 V(x,R) = V_ref(Rx)는 논문의 Lyapunov shaping을 표시. R ∈ SO(n)은 로봇의 자세가 아니라 기준 CLF를 회전시키는 가상 상태이며, 원문의 Q를 R로 표기. 이 방법은 회전 변수를 최적화하고 추가 barrier 제약을 넣어 안전 경계 부근에서 정체를 유발하는 gradient 정렬을 회피. 회전식 하나만으로 모든 평형점이 제거된다는 의미는 아님. 원문의 비방사형 CLF, convex CBF, 입력 행렬 및 QP 실행 가능성 등 적용 조건 확인 필요. 출처: https://arxiv.org/html/2003.07819 의 Section IV, 식 (6)–(10).
Tan and Dimarogonas, Automatica 2024: 논문의 가정하에서 QP를 재정식화하여 원치 않는 내부 평형점과 한 종류의 경계 평형점을 제거. 모든 경계 평형점의 제거나 보편적인 목표 수렴을 보장하는 결과는 아님. https://arxiv.org/abs/2104.14895
7쪽 대표식은 min_{u,δ} 1/2 ||u − u_nom||² + p/2 δ², CLF 및 CBF 조건 적용. 원문은 보정 입력 u′ = u − u_nom을 최적화하므로, 슬라이드 식은 실제 입력 u로 다시 쓴 동등한 목적함수. u_nom은 CLF를 감소시키는 nominal controller, p > 0은 slack 가중치. CLF slack은 계속 허용하며 안전 제약은 유지. 출처: https://people.kth.se/~dimos/pdfs/Xiao_Automatica_2024.pdf 의 식 (44)–(46), Theorem 3, Remark 6.
Goncalves et al., CDC 2023: nominal gradient controller를 사용하는 CBF-QP에 circulation 부등식을 추가하여 장애물 주위를 도는 운동 유도. 본 발표의 완화된 CLF–CBF 정식화와 관련은 있지만 동일한 방법은 아님. 주요 이론에는 시스템과 형상에 관한 가정이 있으며, 임의의 로봇팔 환경에 대한 포괄적인 보장으로 확대해서는 안 됨.
7쪽 대표식은 T(q)ᵀu ≥ β(D(q)). D는 configuration space에서 장애물과의 거리 척도, T는 D 등고면의 접선 방향. 장애물 가까이에서는 β > 0으로 설정하므로 접선 속도 성분이 양수여야 하며 u = 0은 제약 위반. 멀리에서는 β가 음수가 되어 제약 완화. 이 식은 기존 CBF와 입력 제약에 추가하는 조건이며 독립적인 안전 조건은 아님. β = 0인 영역의 다른 평형점 가능성과 차원·입력 집합에 관한 가정이 있으므로 전역 수렴으로 확대하지 않음. 출처: https://arxiv.org/html/2307.09901v1 의 식 (3), Theorem 3.
본 연구는 중간 link task의 구성과 선택을 별도의 유도 방식으로 실험 평가. 보편적으로 우월한 제어기나 모든 정체 상태를 제거한다는 증명을 주장하지 않음.
기존 연구가 정체를 다루지 않았다고 설명하거나, RDF 자체를 본 연구의 기여로 제시하지 않음.
CLF–CBF QP의 기본 참고문헌인 Ames et al., TAC 2017은 4–6쪽의 배경 설명에 사용. https://arxiv.org/abs/1609.06408
Li et al., ICRA 2024의 Robot Distance Field는 21쪽 Spatial Manipulator 자기 충돌 모델 설명에 사용. https://arxiv.org/abs/2307.00533
Siciliano et al. (2009)은 null-space의 기본 참고문헌. 본 연구의 보조항 정의는 Safe_IK.tex에 수록.
Molnar and Ames (2023)은 매끄러운 CBF 합성 및 soft-min의 근거이며, null-space projector 자체의 근거는 아님.
OSQP: Stellato et al. (2020). Attention: Vaswani et al. (2017).

8–19쪽 / Planar의 기존 방법, 제안 방법, 결과와 해석
8쪽과 11–15쪽은 저장된 episode 30을 사용한 개념 설명이며 수치 축, 시간, episode 번호는 생략. 정량적인 시간 변화는 19쪽, 전체 configuration과 CLF 비교는 A10(50쪽)에 수록.
Direct는 초기 상태부터 중간 task 없이 Vee만 사용. Cartesian 공간의 직선 경로를 의미하는 명칭은 아님.
Sequential은 검증된 하나의 IK configuration에서 link 1과 link 2의 위치 목표를 얻은 뒤 link 1 → link 2 → EE 순서로 실행.
Planar IK는 두 해를 갖는 해석적 계산. 관절 제한과 충돌 검사를 통과한 해 중 초기 configuration에 가까운 해 선택.
Episode 30: 초기 0초, 첫 전환 2.128초, 두 번째 전환 6.874초, 최종 목표 최초 도달 18.226초.
Direct pose도 18.226초의 상태로 표시. 이는 같은 시각의 비교를 위한 값이며 Direct의 실패 판정 시각은 아님.
35초 전체 평가에서 Direct는 qp_infeasible로 분류되며, 실행 불가능한 QP는 3회. Episode 180의 timeout과 구분 필요.
회색 점선 link는 선택한 IK configuration, 별은 link 목표. 13–15쪽의 큰 색상 별은 해당 단계의 목표, 작은 색상 테두리는 실제 제어점을 강조. 큰 별은 허용 오차 경계가 아님. 장애물 주변 원형 테두리는 0.08 m의 기하학적 여유 거리를 나타내며, 정확한 RDF 등고선이 아님.
현재 활성 task에만 CLF 제약 적용. 최종 q가 선택한 IK q*와 같을 필요는 없음.

13–15쪽 / 저장된 Sequential 실행
저장된 configuration은 같은 IK 해에서 얻은 link 목표를 link 1 → link 2 → EE 순서로 추종한 결과.
완료한 task를 해제하므로 앞선 link가 이전 목표에서 벗어날 수 있으며, 최종 q도 q*와 다를 수 있음.
13쪽은 link 1 완료, 14쪽은 link 2 완료, 15쪽은 EE 목표 도달 상태. 각 오른쪽 패널에는 6쪽과 같은 QP를 표시하고 해당 단계의 CLF constraint만 강조.
13쪽과 14쪽의 저장 시점에는 active_link가 이미 다음 단계로 변경된 상태. 따라서 표시한 CLF는 새로 기록된 task가 아니라 그 전환 직전에 완료한 단계의 CLF.
정상 전환은 현재 중간 목표의 허용 오차 만족이 조건. Planar에서는 정체 조건(작은 명령 속도와 작은 충돌 barrier) 또는 실행 불가능한 QP에 의한 전환도 허용.
예외 전환은 중간 목표에 도달하기 전에 발생할 수 있으며, 같은 q에서 새 task의 QP를 다시 계산. QP 실행 불가능에 따른 전환과 일반적인 수치 solver 실패는 구분 필요.
Spatial Manipulator의 정상 전환에는 위치와 방향 허용 오차를 모두 만족해야 함. Stall과 QP 실행 불가능은 실행 종료 조건. 자세한 내용: A5(42쪽).
입력 구성 15초, IK 목표 10초, 실행 단계는 각 20초, CLF 요약은 15초 배정. 배경 CLF·CBF·QP는 총 125초. 전체 발화 계획은 1,140초이며 추가 여유 시간 60초 확보.

13–16쪽 / 활성 CLF와 공통 QP
QP1은 V1, QP2는 V2, QPee는 Vee의 감소 조건만 적용. 세 CLF의 동시 감소를 요구하지 않음.
각 단계에서 목적함수, CBF, 입력 제한은 동일하며, 전환 시 활성 task의 CLF만 교체.
13–15쪽은 동일 QP에서 활성 CLF constraint를 로봇과 목표의 색상으로 강조. CLF 함수 개형은 16쪽에서 비교하고 일반적인 QP는 6쪽에서 먼저 설명.
Vi = w_V ||e_p,i||², i = 1, 2. Vee = w_V [||e_p,ee||² + w_psi (1 − cos e_psi)]. 두 가중치는 모두 양수.
수식의 가중치는 기호로 일반화. 저장된 시간 변화 데이터에는 w_V = 10, w_psi = 0.5 사용.
함수 그림은 task 오차 좌표에서의 정성적 개형이며, 전체 관절 공간의 함수 지형이나 장애물 형상이 아님. 그림 생성에는 w_V = 1.0, w_psi = 0.5를 사용하고 수치 눈금은 생략.

20–23쪽 / Spatial Manipulator 확장
20쪽은 저장된 episode seed2026120000_0007의 초기 configuration, 구형 장애물 10개, 목표 pose를 MuJoCo로 정적 렌더링한 그림.
원본 Spatial Manipulator visual mesh 사용. 초록색 점은 목표 위치, RGB 축은 목표 방향. Collision mesh 표시는 숨김.
물리 적분 0회로 생성하며, 새로운 제어 시뮬레이션이나 학습은 수행하지 않음. 저장된 frame과 렌더링 모델 사이의 최대 잔차는 2.89e-15 m.
출처: scripts/render_panda_slide.py, evidence/mujoco_render_audit.json, Fig/panda_mujoco.png. 이전 Fig/panda_scene.pdf는 보관하지만 20쪽에서는 사용하지 않음.
RDF는 Bernstein 다항식에 의한 부호 있는 거리 근사, 유한한 단방향 surface query, 가까운 K = 2개 점의 soft-min 사용.
Top-K 변경 시 gradient 불연속이 발생할 수 있음. 먼 link 쌍은 sphere gate로 처리. 정확한 최소 mesh 거리를 보장하지 않음.
IK는 capsule 기반의 여러 초기값 탐색 사용. 주항은 damped inverse, 보조항은 Moore–Penrose 역행렬로 구성한 직교 projector 사용.
J v_h = 0과 grad Hᵀ v_h ≥ 0은 clipping 전 보조항의 1차 성질이며, 전체 반복 갱신의 안전성을 항상 보장하는 조건은 아님.
후보 해는 제어기의 RDF 자기 충돌 및 capsule–장애물 모델로 다시 검사. IK 반복 과정 자체를 로봇 궤적으로 실행하지 않음.
Spatial Manipulator Vi = 0.5 ||e_p||² + 0.5 w_R ||epsilon||². 상대 quaternion은 Q* Q^-1.
중간 task와 최종 task에 같은 오차 구성 사용. 가중치와 허용 오차는 별도로 설정할 수 있으며, 관절 공간의 함수 지형과 시간 변화가 같을 필요는 없음.
Quaternion 벡터의 norm은 |sin(theta/2)|이며, 회전각 자체가 아님.

21쪽 / RDF 거리장과 surface query의 관계
그림은 해석적인 capsule 부호 거리장의 개념적 단면. 등고선은 대상 link b의 거리 등위선이며, h = 0인 안전 경계나 학습·근사된 실제 Spatial Manipulator RDF의 렌더링이 아님.
Surface point는 query를 제공하는 link a에 속함. 각 점의 좌표를 link b의 local frame으로 변환한 뒤 b의 거리장에 대입. 좌표 변환으로 점이 물리적으로 이동하는 것은 아님.
실행 시 사용하는 거리장에는 radial extension 포함. 가까운 query 선택과 두 link의 운동학이 미분 계산에 반영. Spatial Manipulator에서는 top-K = 2이며, 유한한 단방향 query가 정확한 mesh 거리 계산과 같지는 않음.
Query 거리에서 물리적인 여유 거리와 근사 오차 여유를 반영하여 barrier 구성. Soft-min의 보정은 이미 그 값에 포함되어 있으므로 두 번 빼지 않음. 근사 오차 여유를 전역적으로 인증된 형상 오차 상한으로 해석해서는 안 됨.
이 barrier의 gradient와 CBF 조건이 앞서 설명한 QP의 안전 제약으로 연결됨.

28쪽 / Binary Cross Entropy (BCE) loss와 selection loss의 의미
한 episode의 후보 pair 번호를 k = 1,…,10, 성공 label을 y_k ∈ {0,1}, 모델의 logit을 a_k로 표기.
BCE에는 각 logit의 독립적인 sigmoid 출력 p̂_k = sigmoid(a_k) 사용. 여러 pair가 동시에 성공할 수 있으므로 성공 score의 합을 1로 제한하지 않음.
Episode별 Binary Cross Entropy (BCE) loss:
  ℓ_BCE = −(1/10) Σ_k [y_k log p̂_k + (1 − y_k) log(1 − p̂_k)].
각 pair의 성공·실패 label을 모두 예측하도록 학습하는 항.
Selection loss에는 같은 logit을 softmax로 정규화한 ω_k = exp(a_k) / Σ_j exp(a_j) 사용. Sigmoid score를 합으로 나누는 방식과는 다름.
성공 후보 집합 K⁺ = {k : y_k = 1}에 대해:
  ℓ_sel = −log(Σ_{k∈K⁺} ω_k), K⁺가 비어 있지 않은 경우;
  ℓ_sel = 0, 모든 pair가 실패한 경우.
성공 후보들의 softmax mass 합을 키우는 항. 여러 성공 후보 중 하나를 임의의 유일한 정답으로 지정하는 loss가 아님.
모든 pair가 실패하면 selection loss만 0이며, BCE는 계속 실패 label을 학습. 모든 pair가 성공한 경우에도 성공 후보의 mass 합이 1이므로 selection loss는 0.
최종 목적함수는 모든 학습 episode에 대한 평균:
  L = (1/N) Σ_n [ℓ_BCE,n + 3 ℓ_sel,n].
BCE는 먼저 10개 pair에 대해 평균하고, 두 loss 모두 실패 episode를 포함한 전체 N개 episode에 대해 평균. Selection loss의 분모를 성공 후보가 있는 episode 수로 바꾸지 않음.
구현은 수치 안정성을 위해 BCEWithLogits와 logsumexp 사용. 추론에서는 가장 높은 성공 score의 pair를 선택하며, softmax에서 확률적으로 샘플링하지 않음. Sigmoid, logit, softmax의 argmax는 동일.
출처: src/safe_ik/application/train_link_selection.py의 successful_mass_loss, loss_components; 논문 sections/Method/Link_Selection.tex.
