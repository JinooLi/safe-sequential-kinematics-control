석사 졸업 발표 자료: 비평 → 수정 2회 기록

요청: 두 서브 에이전트가 발표 자료 자체를 비판하고, 지적을 실제 수정하는 사이클을 2회 수행.
검토자: defense_science_review (과학적 타당성·근거·주장 강도)
        defense_delivery_review (20분 발표 흐름·시각 자료·청중 이해)
형식: 지정 CDSL Beamer 4:3, 한국어, 본문22장+보충8장, 발화19분+전환1분.

진행: 최초본 → 1차 두 리뷰 → 1차 수정 → 수정본에 대한 2차 두 리뷰 → 2차 수정 → 부모 검증.
1차·2차 모두 실제 PDF와 원자료를 읽고 검토했다. 세 번째 서브 에이전트 비평은 진행하지 않았다.

1차 비평 및 반영
--------------------------------------------------
[S1 / P1 / 검토 당시 7, 11, 12쪽]
비판: 평면과 Panda의 단계 전환 규칙 차이가 본문에서 숨겨짐.
수정: 7쪽에 두 로봇의 전환·종료 규칙을 직접 대조하고, 평면 전환이 목표 달성을 뜻하지 않을 수 있음을 명시.

[S2 / P1 / 검토 당시 15, 18, 21쪽]
비판: 단계 축소의 시간은 고정 쌍, 성공률 손실은 균등 선택으로 비교 기준이 바뀜.
수정: 15쪽을 전체 링크 대 고정 (3,5)의 성공률·시간 표로 통일; oracle을 사후 상한으로 표시하고 결론에서 단계 축소와 선택 효과를 분리.

[S3 / P1 / 검토 당시 3, 7, 12쪽]
비판: 실제 자세는 부록에만 있고 사례 11의 yaw 정체가 제대로 설명되지 않음.
수정: 7쪽에 실제 단계별 자세, 12쪽에 직접/순차 실제 자세와 yaw 곡선을 넣음; 전체 4개 진단 곡선은 A1으로 이동.

[S4 / P2 / 검토 당시 2, 5, 10, 21쪽]
비판: 저자 공헌과 기존 CLF-CBF/RDF 기반 기법의 경계가 화면에 드러나지 않음.
수정: 2쪽 공헌 명시, 5쪽 설계 상자 강조, 10쪽 기존 CBF 불변성 논리 적용으로 명명.

[S5 / P2 / 검토 당시 3, 14쪽]
비판: 정체 대응 동기와 실제 stall 증가가 연결되지 않음.
수정: 14쪽에 timeout 448→254, stall 86→144를 표시하여 전체 도달 성공과 정체 감소를 구분.

[D1 / P1 / 검토 당시 5, 6, 7, 12, 23쪽]
비판: 중간 링크 추종에 따라 실제 팔 배치가 어떻게 변하는지 보이지 않음.
수정: 실제 저장된 전환 직전 자세 3개를 7쪽에, 직접/순차 장면을 12쪽 본문에 배치.

[D2 / P1 / 검토 당시 15쪽]
비판: 시간과 성공률 비교 기준의 혼용.
수정: 동일 고정 쌍 기준: 59.00%→57.60%, 47.13s→36.45s; 균등 기대값은 별도 보조 기준.

[D3 / P2 / 검토 당시 17쪽]
비판: 다중 레이블의 필요성을 55초 안에 수식으로만 이해해야 함.
수정: 실제 Validation 장면의 10개 레이블 표로 교체하고 상세 손실·seed/epoch는 새 보충 A8로 이동.

[D4 / P2 / 검토 당시 18쪽]
비판: 가장 중요한 결과가 Validation/Test 10개 막대에 분산됨.
수정: Test 4개 막대로 단순화하고 고정 쌍 대비 +2.20%p 및 95% CI를 같은 슬라이드에 표시.

[D5 / P2 / 검토 당시 13쪽]
비판: 일반 Panda 모델 사진은 실제 장애물 환경의 난이도를 보여주지 못함.
수정: 저장된 평가 장면의 q0·장애물10개·목표좌표축을 정적 시각화; 장면 ID와 프레임 연결선 표현 명시.

2차 비평 및 반영
--------------------------------------------------
[S6/D6 / P2 / 검토 당시 7쪽]
비판: 고정 축 범위로 두 스냅숏의 말단이 잘림.
수정: 세 자세의 모든 관절점·장애물 경계·목표점에서 공통 축 범위를 계산하고 여백 추가. 모든 점의 범위 내부 포함을 검증. 그림 뒤 문단 나눔도 수정.

[S7 / P2 / 검토 당시 18, 19쪽]
비판: Test 성공률 다음에 Validation 시간으로 바뀌어 분할·비교 기준 추적이 어려움.
수정: 19쪽을 Test 두 패널로 통일. 전체 링크 대 학습: 공동 성공467장면,47.97→36.62초. 고정(3,5) 대 학습:514장면,36.12→36.21초. 학습 자체의 추가 속도 이득은 관찰되지 않았음을 명시. 원시 CSV와 보관 대응 비교를 대조.

[D7 / P2 / 검토 당시 7쪽]
비판: 현재 제어점만 있고 추종하는 목표점이 없어 작업 원리가 불완전하게 전달됨. 달성한 최종 자세로 목표를 대체하면 안 됨.
수정: 기존 분석 보고서의 해석적 IK 복원값을 찾고, Direct/Sequential의 모든 저장 CLF 값과 최대 오차3e-14 이내로 재대조. 빈 원으로 p_i*, 점선으로 현재점과 목표점 차이를 표시. 복원 출처와 전환 허용오차를 화면·노트에 명시.

[D8 / P2 / 검토 당시 15, 16쪽]
비판: 1차 표 개편으로 후보 정의 2≤i<j≤6이 빠져 10개 출력의 의미가 불명확해짐.
수정: 15쪽에 링크2–6 중 두 개, 총10쌍, 오름차순 실행을 복원하고 대본에 반영.

2차 검토의 1차 수정 평가
S1–S5 및 D2–D5 해결 확인. D1의 실제 자세 표현은 개선됐으며 2차에서 잘림·목표점 추가 보완.

검증
원자료 SHA, 원시 CSV 성공률·공동 성공 시간, 목표 복원과 전 샘플 CLF 일치, 공통 축 경계,
두 PDF 빌드·페이지 수·4:3 비율·글꼴/넘침·페이지 밖 텍스트·한국어 발표 노트 시간을 확인했다.
검증 결과: 원본17개 SHA 일치, 발표용30쪽·노트용52쪽, 4:3, 넘침·글꼴 오류·페이지 밖 텍스트0건.
발화 목표1140초+전환60초. 수정된7·15·19쪽의 렌더링을 부모 에이전트가 직접 확인했다.
최종 PDF SHA는 evidence/verification.json 및 cycle_2.json에 기록했다.

발표가 정직하게 남긴 연구 한계
- Test의 개발 중 확인 이력이 있으므로 독립 최종 평가로 과장하지 않는다.
- 고정 쌍 대비 +2.20%p의95% CI는[-0.30,4.70]%p이며 확정적 개선으로 주장하지 않는다.
- 새 QP 평가, 온라인 계산 속도, 실제 로봇 검증은 향후 과제로 남긴다.
- 모든 변경은 기존 자료의 재분석·시각화·설명 수정이며 새 실험을 만들어 넣지 않았다.
