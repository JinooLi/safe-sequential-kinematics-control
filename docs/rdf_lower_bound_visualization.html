공간과 방향 미분

실제 거리 ∇d대체 거리 함수 ∇D물리 여유 경계R: 점선 · r₀: 실선 · r₁: 긴 점선

파란 실선: D 등고선 (0.20 m 간격), 굵은 점선: 현재 점과 같은 값 D = D(p). 선택 가능한 초록 점선은 실제 거리 d의 등고선입니다. 화살표는 값이 증가하는 방향이며 길이는 기울기 크기에 비례합니다. 따라서 링크에서 멀어지는 방향과 항상 같지는 않습니다. 등고선은 수치 보간으로 그립니다.

p*는 r₀ 원 위의 방사 투영점으로 위치 참고용입니다. 외부 함수는 p*의 값 대신 원 전체의 최댓값 M을 사용합니다. 음영은 전환 구간이며, 작은 화살표는 ∇D입니다.

이 예제의 수식과 가정

물체는 선분 (−0.65, 0)–(0.65, 0)에 반지름 0.22 m를 더한 캡슐이며 R = 0.87 m, c = (0, 0)입니다. 학습 RDF 대신 정확한 부호 있는 거리 f = d를 사용하여 연결 방식만 검증합니다. ε는 예제 전용 추가 차감으로 physical_margin이나 error_margin이 아닙니다. 기본값 0에서 시작하며 학습 모델의 오차 상한을 검증한 예제가 아닙니다.

실제 코드에서는 r₁이 좌표 정규화 t = (p−c)/(2r₁)+1/2 및 목표 거리/r₁에도 사용됩니다. 따라서 물리 여유를 바꾸면 자동 모드의 학습 영역과 정규화도 달라집니다. 이 그림은 정확한 거리로 즉시 다시 계산할 뿐 기존 학습 계수를 새 반경에 재사용할 수 있음을 뜻하지 않습니다. 실제 모델은 설정·반경 불일치 시 로더가 거부합니다.

m_eff = physical_margin + error_margin
r₀ = R + m_eff
r₁ = max((1+transition_ratio) r₀, R+0.060)
h_demo(p) = D(p) − m_eff

h_demo는 선택한 단일점의 설명용 값입니다. 실제 제어기는 양방향 질의점 거리의 soft-min에서 m_eff를 뺍니다. 여기서 h_demo ≥ 0이어도 링크 전체의 안전을 보장하지 않습니다.

ℓ(p) = d(p) − ε
m = min_{‖x−c‖=r₀} ℓ(x) = r₀ − 0.87 − ε
M = max_{‖x−c‖=r₀} ℓ(x) = r₀ − 0.22 − ε
v = (p − c) / ρ
F(p) = M + ρ − r₀　[ρ ≥ r₀]
F(r₁) = M + Δr > M　[Δr = r₁ − r₀ > 0]
s = (ρ − r₀)/(r₁ − r₀),　σ = 3s² − 2s³
D = ℓ　[ρ ≤ r₀]；D = (1−σ)ℓ + σF　[r₀ < ρ < r₁]；D = F　[ρ ≥ r₁]
그래디언트 계산과 보장 범위
∇F = v
∇D = (1−σ)∇ℓ + σv + (F−ℓ) [6s(1−s)/(r₁−r₀)] v

m과 M은 유한 샘플이 아닌 캡슐의 정확한 식으로 계산합니다. 이 예제의 ℓ는 1-Lipschitz이므로 외부에서 ℓ(p) ≤ ℓ(p*) + (ρ−r₀) ≤ F(p)입니다. 따라서 혼합 보정항은 방사 방향으로 음수가 아닙니다. 캡슐의 외부 방사 미분도 양수이므로 전환 구간에서 D는 방사 방향으로 증가합니다. 다만 폭이 좁으면 기울기 크기가 커질 수 있고, 실제 기울기와 일치하는 것은 아닙니다. smoothstep으로 r₀와 r₁의 값과 기울기는 연결됩니다. 학습 RDF가 같은 Lipschitz·방사 미분 조건을 만족한다고 가정할 수는 없습니다. D는 실제 거리의 하한이 아니며 ε를 차감해도 하한이 보장되지 않습니다. ZCBF로 사용할 때는 안전 집합과 물리적 충돌 영역의 관계를 별도로 검증해야 합니다.
