발표 제목: Collision-Aware Sequential Kinematic Control of Robot Manipulators Using Control Barrier Functions and Supervised Learning-based Subtask Sequencing

목표 발화 1,140초 + 전환과 호흡 60초.
본문 36장 + 보충 자료 21페이지 = 청중용 57페이지.
발표자용 93페이지. Appendix 목차와 A1–A17 포함; A7 참고문헌은 4페이지.

구성 원칙
- 자율실험실·제조 작업의 안전한 목표 도달에서 시작하며, 성능 수치는 결과 장에서 제시.
- Kinematic control의 상태·입력·task error를 정의한 뒤 CLF, CBF, QP를 설명.
- 기존 방법의 한계 → 사람의 팔 배치에서 얻은 설계 직관 → 논문 목차 → 제안 방법 순서.
- 초기 상태·목표·장애물은 한 장, IK 목표는 다음 장에 제시. 실행 단계에서는 동일 QP의 활성 CLF constraint만 강조.
- 공통 알고리즘을 먼저 정리한 뒤 모델별 IK, CLF, 거리 기반 CBF의 차이를 설명.
- 용어: Spatial Manipulator / Preset pair (3,5) / CLF constraint / subtask transition.
- 핵심 메시지는 필요한 슬라이드의 상단에 검은 글자로 배치. 슬라이드 글자 크기 규칙은 본문 10pt, 제목 14.4pt.
- 부제는 논문의 실제 section 또는 subsection 제목. Conclusion과 Bibliography는 별도 표제; 기종명만 Spatial Manipulator로 표기.
- 점 진행 표시는 본문 6개 구간. 표지는 제외하며 보충 자료는 별도 목차와 복귀 링크 사용.
- 성공 기준과 수치·근사 모델의 가정은 한국어 대본 및 질의응답 메모에 보존.

해석 원칙
- 사람의 어깨 선행 배치는 설계 직관이며 보편적 인간 운동 법칙이나 실험 결과를 주장하지 않음.
- Gonçalves는 manipulator 실험이 있으며 기본 이론의 짝수 차원 조건과 홀수 차원 확장을 구분.
- IK configuration은 중간 목표의 출처이지 실행 경로가 아님. 전체 joint velocity와 모든 충돌 제약은 계속 사용.
- Preset pair (3,5)는 Train 최고 성공률로 선정; Appendix A2 막대는 Validation 결과.
- 사후 oracle, 학습 정책의 Test 결과, 서로 다른 공동 성공 집합의 시간 비교를 구분.
- 본문 시간 비교는 All-link 대비 단계 축소의 효과. 같은 단계 수인 Preset pair 대비 시간 비교는 A6에 보존.
- 새 제어 실험이나 학습 없이 보관된 데이터를 사용. 원본 데이터와 식별자는 변경하지 않음.
