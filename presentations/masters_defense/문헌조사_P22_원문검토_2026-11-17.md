## 1. 원문으로 확인된 핵심 내용

**NAF 기반 정책이 장애물 상태를 관측하여 joint target velocity를 생성하고, 움직이는 장애물 회피와 end-effector position 도달을 학습하는 연구.** 실험은 정해진 직선 경로를 움직이는 구형 장애물 1개에 한정되므로, 임의 형상·개수·배치의 장애물에 대한 일반화나 모든 상황의 충돌 회피 보장으로 확대할 수 없음.

| 항목 | 원문 확인 내용 | 위치 |
|---|---|---|
| 알고리즘 | Normalized Advantage Function(NAF) 기반 model-free continuous Q-learning. Advantage를 action에 대한 음의 quadratic으로 구성하여 greedy action을 신경망 출력으로 계산 | §II-D, 식 (6)–(8), 인쇄 p.2065 / PDF p.3 |
| State | Joint position·velocity, end-effector·target·obstacle position, obstacle velocity | §III-A, 식 (9), p.2065 / PDF p.3 |
| 정보 가정 | Joint state를 측정·추정하며, end-effector와 obstacle position을 이용 가능하고 obstacle velocity를 올바르게 추정한다고 가정 | §III-A, p.2065 |
| Action | 각 joint의 target rotational velocity. Joint velocity control이 가용 torque로 추종하는 구성 | §III-B, 식 (10), p.2065 |
| Reward | Target 거리의 Huber term, action 크기, 로봇–장애물 최소 거리 관련 term의 가중합. 최소 거리는 V-REP에서 계산 | §III-C, 식 (11)–(14), pp.2065–2066 |
| Robot·환경 | 6-joint COMAU SMART3-S2의 V-REP simulation, TensorFlow·Gym·Remote API 연결 | §IV, pp.2066–2067 / PDF pp.4–5 |
| 최종 목표 | End-effector를 목표 **point**로 이동. Full pose regulation 실험은 아님 | §IV, pp.2066–2067 |
| Target 배치 | 로봇 앞쪽의 바닥과 평행한 평면 위에 배치. 조건에 따라 고정 또는 episode마다 무작위 초기화 | §IV, p.2067 |
| 장애물 | 로봇과 target 사이의 **구형 장애물 1개**, **직선 경로**에서 이동. Random motion은 그 경로에서 방향 변경·일시 정지 | §IV, p.2067 |
| 제시 결과 | Reward·loss 학습 곡선, target 및 obstacle까지의 거리 궤적, transfer 및 수동 방향 변경 사례 | Fig.3–5, pp.2067–2068 |
| 안전 근거 | Reward 설계와 simulation에서 관찰한 회피 행동. 별도 CBF/QP safety filter나 safe-set invariance 증명은 제시하지 않음 | §III–V |

원문의 관측과 action 정의:

$$
s_t = \{q_t,\dot q_t,p_{e,t},p_{\mathrm{target}},p_{o,t},\dot p_{o,t}\},
\qquad
a_t = \dot q_{\mathrm{tar},t}.
$$

이는 식 (9)–(10)을 시점이 드러나도록 다시 적은 표기. 원문의 $p_t$는 target position을 의미하며, 위 식에서는 시간 첨자와 혼동하지 않도록 $p_{\mathrm{target}}$으로 표기.

따라서 **model-free는 장애물 정보를 사용하지 않는다는 뜻이 아님**. 관측된 상태에서 action을 학습하며, raw image를 policy에 직접 입력하는 visuomotor 학습으로 소개할 근거도 없음.

## 2. 실험 조건과 결과의 범위

### 2.1 네 가지 학습·평가 조건

| 조건 | Target | 구형 장애물의 운동 |
|---|---|---|
| (i) | 고정 | 직선 경로 양 끝 사이를 일정 속도로 왕복 |
| (ii) | 고정 | 같은 경로에서 무작위 방향 변경·정지 |
| (iii) | Episode마다 무작위 | 일정 왕복 |
| (iv) | Episode마다 무작위 | 무작위 방향 변경·정지 |

원문 §IV는 650 episodes, episode당 360 steps 이후의 결과를 제시하며, Table I의 step은 50 ms. 당시 명시한 hardware에서 training process당 약 32시간으로 보고하므로, 이 시간을 현재 장비에서의 학습 비용이나 본 연구 대비 비용으로 직접 사용할 수 없음.

보고된 동작은 target에 접근한 뒤 장애물이 가까워지면 물러나고, 장애물이 멀어지면 다시 접근하는 행동. 지속해서 움직이는 장애물이 있는 조건의 목표 접근·회피를 다루므로, 정적인 장애물 환경에서 목표 pose에 도달하는 본 연구의 완료 시간·성공률과 원문 그림을 직접 수치 비교할 수 없음.

### 2.2 Transfer와 robustness

§IV-A는 random target + deterministic obstacle 조건에서 얻은 신경망 가중치, replay buffer, 또는 둘 모두를 random-obstacle 조건의 **추가 학습**에 활용하는 세 방법 비교. Experience transfer의 학습 개선과 model-only transfer의 좋지 않은 결과를 서술하지만, 이를 재학습 없는 zero-shot generalization의 증거로 사용할 수 없음.

§IV-B는 GUI로 장애물의 방향을 수동 변경하면서 접근시키는 실험. 제시된 회피 궤적은 이 조건의 대응 사례이며, 임의 형상·개수·배치의 새로운 장애물을 포괄하는 검증은 아님.

### 2.3 논문에서 확인되지 않는 평가

- 별도의 held-out 장애물 형상·개수·배치에 대한 일반화 평가.
- 명시적인 train/validation/test 분할과 여러 seed의 성공률·충돌률·신뢰구간 통계.
- Full end-effector pose 도달과 실제 로봇에서의 검증.
- 모든 상태의 충돌 회피 또는 목표 수렴에 대한 정리·증명.

이는 이 논문의 **보고 범위**에 대한 판단이며, 해당 방법으로 그런 평가를 수행할 수 없다는 뜻은 아님.

## 4. 본 연구와 비교할 때의 의미

| 비교 축 | P22 | 본 연구의 현재 범위 |
|---|---|---|
| 학습의 역할 | 매 step의 joint velocity action 학습 | 실행 전 10개 ascending two-link pair 중 하나를 지도학습으로 선택 |
| 목표 구성 | End-effector target point와 거리 reward | Goal IK에서 link target 구성, 최종 end-effector pose 도달 |
| 실행 구조 | 관측 상태에 따른 정책 action과 joint velocity control | 선택한 link subtask의 CLF를 하나씩 활성화하는 CLF–CBF QP |
| 안전 처리 | Robot–obstacle distance reward와 경험적 회피 평가 | 명시적 CBF 제약; 모델·QP feasibility·구현 가정 아래 해석 |
| 환경 | 관측 가능한 위치·속도를 가진 동적 구형 장애물 | 현재 발표의 정적 장애물 평가; 동적 장애물 적용은 별도 구현·검증 대상 |

P22를 통해 **“로봇팔의 회피와 목표 접근 행동을 직접 학습하는 대안이 있다”**는 사실을 설명 가능. 본 연구와의 차이는 IK에서 구성한 subtask, 학습에 맡기는 선택의 범위, 안전 조건을 실행 단계에서 처리하는 방식으로 설명하는 것이 적절.

P22의 제한된 실험 범위나 성능 통계 부재만으로 본 연구가 더 우수하다고 결론 내릴 수 없음. 또한 P22에 CBF filter가 없다는 사실을 모든 RL 방법의 특성으로 일반화하지 않고, P29 OptLayer·P30 RL-CBF와 함께 구분.

## 5. 발표 답변과 필요한 비교 실험

발표 답변 초안:

> “Sangiovanni 등의 연구에서는 로봇과 장애물의 상태를 입력받아 joint velocity를 직접 학습하고, 움직이는 구형 장애물을 피하면서 목표 위치에 접근하는 행동을 보였습니다. 본 연구는 goal IK에서 link subtask를 구성하고 학습에는 실행할 pair의 선택을 맡기며, 실제 joint velocity는 CLF-CBF QP로 계산합니다. 두 방식의 차이는 학습이 결정하는 대상과 안전 조건을 처리하는 구조에 있습니다. 성능이나 학습 비용의 우열은 동일한 과제에서 별도로 비교해야 합니다.”

비교 실험 제안:

1. **공통 과제부터 정의:** 같은 robot, position goal, 관측 정보, obstacle geometry, 입력 제한과 timeout으로 비교. Full pose 확장이나 동적 장애물 처리를 추가하면 원논문 재현과 구분하여 변경 사항 기록.
2. **학습과 안전 기구 구분:** NAF policy, 해당 policy에 동일한 CBF filter를 결합한 변형, 본 연구를 구분해 성공률·clearance·충돌률·완료 시간 평가. CBF를 추가한 변형은 P22 원래 방법으로 표기하지 않음.
3. **공정한 비용·일반화 평가:** 여러 seed와 공통 held-out episodes 사용, RL rollout과 본 연구의 label 생성 비용을 모두 포함. 새로운 형상·개수·배치는 별도 일반화 실험으로 설계하며 policy의 obstacle 표현 변경도 명시.

위 실험은 **향후 제안**이며, 현재 수행하거나 결과를 확보한 것으로 해석하지 않음.

## 6. 재현 전에 확인할 원문 표기

PDF 인쇄 pp.2065–2066을 시각적으로 확인한 결과, 아래 표기와 본문 설명 사이에 불일치가 존재하므로 원문을 임의로 보정한 식을 확정 구현으로 기록하지 않음.

- **Reward 부호:** 식 (12)의 target Huber term과 식 (14)의 obstacle proximity term은 양의 형태이고 Table I의 해당 계수도 양수. 그러나 본문과 Fig.1은 target distance·obstacle proximity에 따른 negative reward와 목표 부근의 높은 reward를 설명. 구현 재현 시 저자 코드나 정오표 등을 통해 실제 부호 확인 필요.
- **Target network update:** Algorithm 1에 기존 target network의 계수로 $(1+\tau)$가 표기됨. Soft update라는 설명과 대조가 필요한 오기 가능성으로 기록하며, 확인되지 않은 수정식을 원문의 식으로 제시하지 않음.

이 때문에 위 요약·비교 문서는 reward의 **구성 요소와 설명된 목적**을 사용하며, 원문의 수식·계수를 그대로 복사한 재현 코드를 제공하지 않음.
