9쪽은 인간의 장애물 회피 연구에서 보고된 팔 자세와 subgoal을 설계 직관의 근거로 제시. 작은 3패널 사진은 Lukic et al. (2014)의 인간 동작 자료이며, 아래 세 자세 그림은 본 연구에서 만든 개념도로 인간 실험 궤적이 아님. 모든 사람이 어깨부터 움직인다는 생체역학 법칙이나 검증된 최적 인간 정책을 주장하지 않음. 문헌의 관찰과 IK 해에서 link subtask target을 구성하는 본 연구의 설계를 구분하며 상세 출처는 아래 9쪽 항목에 수록.
10쪽 Chapter 3: Method Overview는 논문 3장의 다섯 section으로 수행한 방법론의 구성을 설명. 전체 논문 목차나 실제 발표 순서의 재현이 아니며 결과 장은 포함하지 않음.
17쪽 Overall Sequential Control Framework는 실행 전 준비와 제어 주기 반복을 구분. 검증된 IK 해에서 subtask target과 sequence를 한 번 구성하고, 실행 중에는 활성 CLF-CBF QP의 결과와 현재 상태로 전환/종료를 판정. Continue는 유효한 u를 적용하고 q를 갱신한 뒤 같은 subtask의 QP로 복귀. Advance는 s를 증가시키고 입력 적용 없이 같은 q에서 다음 subtask의 QP를 계산. Stop은 실행 종료. QP 실패가 입력 적용을 무조건 거치는 것이 아니며, task 전환 때 IK를 다시 구하거나 로봇 상태를 초기화하는 것도 아님. 모델마다 모든 전환·종료 정책이 같다는 뜻은 아님. Planar에서는 boundary stall 또는 QP infeasibility 때 link subtask를 넘길 수 있지만 Spatial Manipulator에서는 stall, QP infeasibility 및 수치 solver error를 실행 종료로 처리. 일반 solver error와 Planar의 예외 전환을 혼동하지 않으며 A5에서 구체적인 차이 설명.
21쪽은 원 논문의 RDF 표현을 사용하고, 표면 query 좌표변환, soft-min 집계, physical/error safety margin, 양쪽 link 운동을 반영한 relative gradient를 추가해 CBF candidate를 구성. Clearance barrier라는 별도의 정립된 이론 명칭을 도입하지 않음. CBF라는 이론적 성질은 정칙성·안전 초기조건·제약을 만족하는 실제 입력 등의 가정에 의존.
24쪽의 화면 표현은 성공의 핵심을 짧게 나타낸 것. Validation All-link는 goal hit 597개 중 안전 조건 실패 7개를 제외한 590개가 성공이며 joint-limit와 numerical-solver 판정도 포함. 출처: evidence/all_links_analysis.json의 120초 분석. 목표 도달만으로 성공을 재정의하지 않음.
35쪽 / Future Work: Experiments and Sequencing
두 향후 연구 방향에 각각 두 하위항목을 표시하며, 대본은 30초 유지.
Physical-robot experiments: (1) Closed-loop control on the physical robot — 실제 로봇에서 제안 제어기의 폐루프 실행. (2) Success rate, minimum margin, and completion time — 성공률, 최소 margin, 완료 시간 평가. 모두 향후 실험이며 이미 실제 로봇에서 검증한 결과가 아님.
Neural-network-based sequencing improvements: (1) Relative-geometry features and network architecture — 상대기하 특징과 network 구조 개선. 현재 모델도 q0, q*, 목표 pose, 장애물 위치·반지름을 입력으로 사용하고 cross-attention으로 결합하므로 기하 정보를 새로 처음 도입한다는 의미가 아님. 기존 입력 표현과 구조를 개선할 방향이며 특정 network 종류를 확정하지 않음. (2) Link subtask selection without a fixed count — 현재 두 개로 고정한 link subtask 수를 episode에 따라 정하도록 확장 검토. 어떤 link를 몇 개 실행할지 선택하는 방향이며, 임의 개수의 subtask를 무한히 허용하거나 실행 순서를 자유화한다는 뜻이 아님. 현재 방법은 선택한 link를 link index의 오름차순으로 실행하며, 이 순서 규칙의 변경은 이번 향후 연구 항목에 포함하지 않음.
논문에서는 두 개의 link subtask를 이번 연구의 고정 설정으로 사용했으며 그 개수가 최적이라고 입증하지 않음을 명시. 개수 선택을 확장해도 final EE subtask와 QP의 충돌·joint-limit 안전 제약을 유지하고, 선택하지 않은 link도 collision model에 포함. 향후 선택 범위·network 구조·학습 방식과 개선 성능은 아직 확정하지 않으며, 현재 성공률·완료 시간 수치는 기존 두-link 모델의 평가 결과로 유지. 근거: 논문 sections/Method/Link_Selection.tex의 Two-Link Reduction and Selection Objective, Network Architecture.
세부 측정에 관한 Q&A 참고: 실행 전 한 번 수행하는 selector 추론과 매 제어 주기 RDF query·QP 계산 시간을 구분한 온라인 지연·주기 초과, RDF 거리와 기준 mesh 거리의 차이·장애물 pose 추정 오차, 실제 로봇의 명령/측정 joint velocity·최소 여유 거리·목표 pose 오차·완료 시간은 별도로 확인할 측정 항목. 35쪽에서는 성공률·최소 margin·완료 시간으로 평가 방향을 요약하고, 온라인 지연·형상·센싱 등의 상세 목록은 Q&A 참고로 유지하며 세 번째 향후 연구 항목으로 제시하지 않음. 측정 오차를 이용한 collision margin 검토만으로 연속시간 무충돌이 자동 보장되지는 않음. 기록된 한계의 원전 근거는 Conclusion 및 Results/Panda의 Interpretation and Limitations이며 새로운 실험 결과를 추가한 것이 아님.

4–6쪽 / 배경: CLF → CBF → 결합한 QP
4쪽(40초): 관절 속도 입력 q̇ = u, task 오차 함수 V = 1/2 ||e(q)||², 감소 조건 ∇Vᵀu ≤ −c_V V 설명.
그릇 모양 그림은 task 오차에 대한 함수의 정성적 개형. V = 0은 task 달성을 의미하며, 여유 자유도로 인해 여러 관절 configuration이 같은 task를 만족할 수 있음.
5쪽(40초): 여유 거리 h = d − d_safe, 안전 집합 C = {q : h(q) ≥ 0}, CBF 조건 ∇hᵀu ≥ −γh 설명. 거리 개념도의 초록색은 안전 경계 바깥, 흰색 안쪽은 필요한 거리 여유를 만족하지 않는 영역. 점선 경계 h = 0도 안전 집합에 포함. 그림은 거리 조건의 직관적 표현이며 실제 C는 configuration q의 집합.
d는 link와 장애물 사이의 표면 거리. 안전 집합 내부에서는 h의 감소도 허용되지만, h = 0에서는 ḣ ≥ 0 필요. 이 조건이 항상 장애물에서 멀어지는 운동을 요구하는 것은 아님.
6쪽(45초): 기본 QP를 목적함수, CLF constraint, CBF constraint의 세 줄로 제시. 동일 입력 u로 목표 도달과 안전을 함께 고려하며, 1/2 ||u||² + rho/2 delta²를 최소화. rho > 0은 slack penalty weight. CLF만 slack으로 완화하고 매 제어 주기 현재 q에서 다시 계산.
6쪽에서는 구현 세부사항을 생략하고, 13–15쪽과 A12에서 입력 제한을 논문의 Method 식과 같이 두 행으로 명시: −alpha_j(q_j − q_j,min) ≤ u_j ≤ alpha_j(q_j,max − q_j), 그리고 v_min,j ≤ u_j ≤ v_max,j, 모든 j = 1,…,n. 첫 행은 joint-limit CBF로 위치 경계에 가까워질수록 바깥 방향 속도를 제한하며, 둘째 행은 고정된 joint velocity 범위. 두 제한의 교집합을 적용.
QP는 V 자체를 최소화하는 문제가 아님. Slack δ는 CLF 조건만 완화하며, 양의 δ는 V의 감소를 늦추거나 증가를 허용할 수 있음.
CBF와 입력 제한에는 slack을 두지 않음. CLF slack이 모든 QP의 실행 가능성을 보장하지는 않음.
안전 집합의 순방향 불변성은 barrier의 정칙성, 안전한 초기 상태, 실제 적용한 속도의 미분 부등식 만족을 전제로 하는 성질. 근사 형상, 이산 적분, clipping은 A9와 평가 한계에서 별도로 설명.
출처: 논문 sections/Preliminaries/CLF.tex, CBF.tex, CLF_CBF_QP.tex, sections/Method/Kinematic_Control.tex; Ames et al. (2017).
Planar 실행 단계에서는 6쪽의 기본 구조를 구체화한 실제 QP를 제시. 가중행렬, 개별 barrier와 joint/input limits를 표시하며, 13–15쪽 사이에서는 같은 배치로 활성 CLF constraint만 변경.

7쪽 / 관련 연구와 본 연구의 범위 — A7 참고문헌: 44–47쪽

7쪽 및 A17 / Gonçalves의 차원 가정과 manipulator 관련성
기본 모델은 q̇ = u, q ∈ R^n. 기본 circulation 구성 T = ΩN에서 Ωᵀ = −Ω, ΩᵀΩ = I를 요구. 가역 skew-symmetric 행렬은 짝수 차원에만 존재하므로 이 기본 구성에는 n이 짝수라는 조건 존재.
홀수 차원에서는 skew-symmetric Ω가 특이하므로 T가 0이 되는 방향이 존재할 수 있음. Tᵀu ≥ β(D)에서 β(D) > 0인데 T = 0이면 제약이 실행 불가능. 따라서 같은 짝수 차원 정리를 그대로 적용할 수 없음.
다만 논문의 Section IV-C는 홀수 차원 확장을 별도로 논의하고, 3차원 비행 로봇 5대의 15차원 실험도 제시. ‘짝수 차원 전용이라 7-DOF에는 적용 불가능’이라는 단정은 부정확함.
논문은 4-DOF planar manipulator 실험도 포함. 본 연구와의 차이는 로봇팔 적용 유무가 아니라, IK에서 link subtask를 구성하고 선택하는 구조의 사용 여부. 본 subtask-construction 절차는 3-DOF와 7-DOF에서 사용하며 짝수 차원 조건을 요구하지 않지만, 이것이 모든 task와 장애물에 대한 QP 실행 가능성이나 전역 수렴 보장은 아님.

3.2.1의 표시명과 subtask의 의미
11·12쪽 부제는 사용자가 지정한 Decomposition of Regulation Task를 사용. 실제 논문의 sections/body.tex에는 Intermediate Targets and Sequential Tasks가 남아 있어, 장 번호는 유지하고 표시명 alias와 원래 제목을 메타데이터에 함께 보관. 3.3.2는 실제 장명 Intermediate Position Tasks and Final Pose Task를 그대로 표시. 제목 변경을 위해 논문 파일을 수정하지 않음.
논문 Sequential_Frames.tex의 정의: 원래 EE regulation task T_{ee}를 L개의 link subtask와 마지막 final EE subtask로 분해하며, 기호는 굵은 ST_{ee,s} 사용. DT가 아님. s는 실행 단계 번호(1부터 L+1), i_s는 link 단계 s에서 선택한 link/frame 번호, L은 최종 EE를 제외한 link subtask 개수. ST_{ee,s}(s=1,...,L)는 선택한 link i_s의 목표 집합 G_{i_s}에 진입하는 제어 문제이며, 그 목표 위치·pose는 q*에서 계산한 subtask target. 마지막 ST_{ee,L+1}=T_{ee}는 원래 EE 목표 pose의 regulation이며 q* 자체의 정확한 추종을 요구하지 않음. 따라서 subtask를 EE 이전 단계만을 가리키는 말로 사용하지 않음. T_{ee}는 task 기호이며 시간 제한 T_d와 구분.
Planar의 link 1·2 subtask는 위치, final EE subtask는 위치와 yaw 사용. Spatial의 link subtask와 final EE subtask는 위치와 방향 오차를 사용. 각 subtask가 선택한 link 하나를 추종하더라도 모든 joint velocity를 계산하며 모든 충돌 제약은 유지.
한 subtask가 끝나면 이전 CLF 조건을 해제하므로 이전 link 목표에서 벗어날 수 있으며, 최종 q가 IK 해 q*와 같을 필요 없음. Target을 정하는 것, 그 target에 도달할 subtask를 구성하는 것, 실행 순서를 정하는 task sequencing을 구분.
인간 연구의 subgoal은 목표를 향한 도달 동작의 via-point/보조 목표에 관한 표현. 본 제어기의 formal link subtask나 IK 기반 분해를 인간 실험이 직접 검증한 것으로 해석하지 않음.

11–12쪽 / 초기 상태, 목표, 장애물, IK의 단계별 구성
11쪽은 초기 로봇 q0, 원래 EE regulation task T_{ee}의 목표 pose, 장애물을 함께 제시. 12쪽에서 선택한 IK q*와 link subtask target, ST_{ee,1} → ST_{ee,2} → ST_{ee,3}=T_{ee} 추가. 이 Planar 예시는 L=2와 link 순서 (1,2,3)를 사용하므로 단계 번호와 link 번호가 일치하지만, 이를 일반적인 s=i_s 관계로 해석하지 않음. q*에 포함된 전체 link의 목표 배치 → p_i* = p_i(q*)로 subtask target 추출 → 순차 subtask 실행의 연결을 강조. IK를 구하는 것에 그치지 않고 그 정보를 제어 task로 변환하는 절차가 본 연구의 설명 초점.
두 구성 슬라이드 모두 실선 로봇은 같은 q0 유지. 11–15쪽 전체에서 약 48 mm의 동일 그림 영역과 화면 위치·시점·좌표·축척을 유지하여 단계 변화가 애니메이션처럼 이어지도록 구성. 11–12쪽은 추가되는 정보만 강조하며, 로봇이 이동하거나 장애물이 새로 나타나는 실행 단계가 아님.
점선 configuration은 목표 pose와 충돌 검사를 통과한 해. q0에서 q*까지 실행한 경로가 아니며, q* 도달을 보장하지도 않음.

13–15쪽 / 저장된 Sequential 실행
저장된 configuration은 같은 IK 해에서 얻은 link 목표를 link 1 → link 2 → EE 순서로 추종한 결과.
완료한 task를 해제하므로 앞선 link가 이전 목표에서 벗어날 수 있으며, 최종 q도 q*와 다를 수 있음.
13쪽은 ST_{ee,1}의 link 1 완료, 14쪽은 ST_{ee,2}의 link 2 완료, 15쪽은 ST_{ee,3}=T_{ee}의 EE 목표 도달 상태. 각 오른쪽 패널은 subtask 기호를 해당 QP와 연결하고, 6쪽의 기본 구조에 가중행렬과 joint/input limits를 포함한 실제 QP에서 해당 단계의 CLF constraint만 강조.
13쪽과 14쪽의 저장 시점에는 active_link가 이미 다음 단계로 변경된 상태. 따라서 표시한 CLF는 새로 기록된 task가 아니라 그 전환 직전에 완료한 단계의 CLF.
정상 전환은 현재 subtask target의 허용 오차 만족이 조건. Planar의 link subtask에서는 정체 조건(작은 명령 속도와 작은 충돌 barrier) 또는 실행 불가능한 QP에 의한 전환도 허용.
예외 전환은 subtask target에 도달하기 전에 발생할 수 있으며, 같은 q에서 새 task의 QP를 다시 계산. QP 실행 불가능에 따른 전환과 일반적인 수치 solver 실패는 구분 필요.
Spatial Manipulator의 정상 전환에는 위치와 방향 허용 오차를 모두 만족해야 함. Stall은 낮은 적용 속도와 불충분한 오차 감소로 판정하며 충돌 경계 근접을 요구하지 않음. Stall과 QP 실행 불가능은 실행 종료 조건. 따라서 A5의 공통 행 이름은 Stall condition이며, Planar의 경계 정체 조건과 구분. 자세한 내용: A5(42쪽).
입력 구성 15초, IK 목표 10초, 실행 단계는 각 20초, CLF 요약은 15초 배정. 배경 CLF·CBF·QP는 총 125초. 전체 발화 계획은 1,140초이며 추가 여유 시간 60초 확보.

13–16쪽 / 활성 CLF와 공통 QP
ST_{ee,1}의 QP1은 V1, ST_{ee,2}의 QP2는 V2, ST_{ee,3}=T_{ee}의 QP3은 V3 = V_e의 감소 조건만 적용. 16쪽 상단의 ST 열은 실행 단계를 표시하며, ST는 제어 task이고 V는 그 task 오차로 구성한 CLF라는 차이를 유지. 세 CLF의 동시 감소를 요구하지 않음.
각 단계에서 목적함수, CBF, 입력 제한은 동일하며, 전환 시 활성 subtask의 CLF만 교체.
13–15쪽은 동일 QP에서 활성 CLF constraint를 로봇과 목표의 색상으로 강조. CLF 함수 개형은 16쪽에서 비교하고 일반적인 QP는 6쪽에서 먼저 설명.
현재 논문 정의: V_i = 0.5 ||e_p,i||², i = 1, 2. V_e = 0.5 ||p_e − p_d||² + 0.5 w_o [1 − cos(psi_e − psi_d)], V3 = V_e. w_o > 0은 방향 항의 상대 가중치.
원래 저장 실험은 V_i,archive = w_V ||e_p,i||²와 V_ee,archive = w_V [||e_p,ee||² + w_psi(1 − cos e_psi)]를 사용하며 w_V = 10, w_psi = 0.5. 원시 궤적과 평가 결과는 변경하지 않음.
현재 그림은 w_o = 0.5로 두고 저장된 같은 궤적에서 논문의 새 함수를 평가한 값. 이 경우 V_new = V_archive / 20. 제어기를 새 함수로 다시 실행한 결과가 아님.
CLF scaling을 바꾸면서 slack의 가중치를 고정하면 일반적으로 최적 제어 입력도 달라질 수 있음. 새 함수 값으로의 재평가가 원래 제어기와 동일한 QP 또는 동일 제어 입력을 보장한다는 뜻은 아님.
함수 그림은 task 오차 좌표에서의 정성적 개형이며, 전체 관절 공간의 함수 지형이나 장애물 형상이 아님. 그림에는 논문의 0.5 계수와 w_o = 0.5를 사용하고 수치 눈금은 생략.

20–23쪽 / Spatial Manipulator 확장
20쪽은 저장된 episode seed2026120000_0007의 초기 configuration, 구형 장애물 10개, 목표 pose를 MuJoCo로 정적 렌더링한 그림.
20쪽에 Planar/Spatial 비교표를 배치하고 17쪽은 공통 제어 흐름에 집중. Planar는 3개 joint, link-position subtask와 위치·yaw 기반 final EE subtask를 사용하며, Spatial은 7개 joint와 각 subtask의 위치·relative quaternion 오차를 사용. 두 모델 모두 capsule 기반 거리 모델을 사용하고 Spatial의 복잡한 link self-collision에 RDF를 사용하므로, capsule 사용 여부 자체가 차이는 아님.
확장 시 다룰 요소는 위치·방향 목표, 복잡한 link 형상의 self-collision 회피, 여유 자유도로 가능한 여러 IK 해 중 충돌 없는 후보 탐색. ‘Relative motion between robot links’는 독립 문제로 제시하지 않고 self-collision 설명에 통합. 상대 운동 자체가 위험하다는 의미가 아니라, 거리의 변화율에 두 link의 운동을 모두 반영해야 한다는 의미이며 21쪽 CBF gradient에서 연결.
원본 Spatial Manipulator visual mesh 사용. 초록색 점은 목표 위치, RGB 축은 목표 방향. Collision mesh 표시는 숨김.
물리 적분 0회로 생성하며, 새로운 제어 시뮬레이션이나 학습은 수행하지 않음. 저장된 frame과 렌더링 모델 사이의 최대 잔차는 2.89e-15 m.
출처: scripts/render_panda_slide.py, evidence/mujoco_render_audit.json, Fig/panda_mujoco.png. 이전 Fig/panda_scene.pdf는 보관하지만 20쪽에서는 사용하지 않음.
RDF는 Bernstein 다항식에 의한 부호 있는 거리 근사, 유한한 단방향 surface query, 가까운 K = 2개 점의 soft-min 사용.
Top-K 변경 시 gradient 불연속이 발생할 수 있음. 먼 link 쌍은 sphere gate로 처리. 정확한 최소 mesh 거리를 보장하지 않음.
IK는 capsule 기반의 여러 초기값 탐색 사용. 주항은 damped inverse, 보조항은 Moore–Penrose 역행렬로 구성한 직교 projector 사용.
J v_h = 0과 grad Hᵀ v_h = k_h ||N grad H||² ≥ 0은 clipping 전 보조항의 1차 성질. 투영된 gradient가 0이면 변화율도 0이므로 엄격한 증가를 뜻하지 않으며, 주항과 clipping을 포함한 전체 갱신의 증가나 안전성을 보장하지 않음. A3에서도 보조항의 비음수 1차 변화로 설명.
후보 해는 제어기의 RDF 자기 충돌 및 capsule–장애물 모델로 다시 검사. IK 반복 과정 자체를 로봇 궤적으로 실행하지 않음.
Spatial Manipulator V_i = 0.5 ||e_p,i||² + 0.5 w_R ||epsilon_i||². epsilon_i는 상대 unit quaternion Q_i* Q_i^-1의 vector part이며, 단일 현재 자세 quaternion의 vector part가 아님.
일반 목표 집합의 e_o는 최종 EE의 상대 quaternion vector와 대응하므로 e_o = epsilon_ee로 연결. w_R는 현재 Spatial 본문 표기 그대로 유지하며 Planar의 w_o와 기계적으로 통합하지 않음.
23쪽에서 link subtask ST_{ee,s}(s=1,...,L)는 i=i_s로 두어 선택한 link의 V_{i_s}에 대응. 최종 ST_{ee,L+1}=T_{ee}는 원래 EE 목표의 V_{ee}를 사용. 같은 위치·방향 오차 구성을 사용하지만 가중치와 허용 오차는 별도로 설정할 수 있으며, 관절 공간의 함수 지형과 시간 변화가 같을 필요는 없음.
Quaternion 벡터의 norm은 |sin(theta/2)|이며, 회전각 자체가 아님.

21쪽 / RDF 거리장과 surface query의 관계
왼쪽은 서로 다른 복잡한 윤곽을 가진 두 2차원 물체의 개념도. 물체 a의 표면 표본이 query point이며, 배경의 거리장과 등고선은 물체 b에 속함. 강조한 표본은 a의 표면에 그대로 놓여 있고 그 좌표에서 b의 거리 함수를 평가. 점을 b 쪽으로 움직이는 과정이 아님.
그림 전체는 b의 좌표계로 표현. b 경계에서 거리값은 0, 내부에서 음수, 외부에서 양수. 실제 Panda RDF를 학습하거나 제어 실험을 재실행한 결과가 아니며, 다각형 경계까지의 거리를 계산해 RDF query 원리를 설명하는 도식.
직접 제작한 도식의 생성 코드: scripts/build_rdf_complex_query_figure.py. 그림: Fig/rdf_complex_query_field.pdf/png. 기하 검증·출처·파일 해시: evidence/rdf_complex_query_figure_audit.json. 제목의 Li et al. 인용은 RDF 방법의 출처이며 새 도식이 원전에서 재사용한 그림이라는 뜻은 아님.
오른쪽은 본 연구의 self-collision CBF 구성 절차. Query를 제공하는 link a의 표면점 x_{a,k}를 link b의 local frame으로 변환: xi_{ab,k} = R_b^T(x_{a,k} − p_b). 그 위치에서 b의 RDF를 평가하여 d_k = dtilde_b(xi_{ab,k}) 계산. 좌표 변환으로 점이 물리적으로 이동하는 것은 아님. 왼쪽 등고선을 본 연구의 h = 0 안전 경계와 동일시하지 않음.
세 번째 단계는 D_ab = softmin_k d_k, h_ab = D_ab − m_phys − m_err. Link a뿐 아니라 기준 link b도 움직이므로 gradient에는 query점의 운동, b의 병진, b의 회전을 모두 포함. A4의 gradient 식은 고정된 query 집합에서 적용하며 가중치는 pi_k = exp(−beta d_k) / Σ_j exp(−beta d_j). 한쪽을 고정 장애물로 취급하면 거리 변화율과 CBF 제약이 달라질 수 있음. 이 상대 운동 반영은 3차원에서만 발생하는 새로운 현상이 아니라 self-collision 계산의 요구 사항.
실행 시 사용하는 거리장에는 radial extension 포함. 가까운 query 선택과 두 link의 운동학이 미분 계산에 반영. Spatial Manipulator에서는 top-K = 2이며, 유한한 단방향 query가 정확한 mesh 거리 계산과 같지는 않음.
Query 거리에서 물리적인 여유 거리와 근사 오차 여유를 반영하여 barrier 구성. Soft-min의 보정은 이미 그 값에 포함되어 있으므로 두 번 빼지 않음. 근사 오차 여유를 전역적으로 인증된 형상 오차 상한으로 해석해서는 안 됨.
이 barrier의 gradient와 CBF 조건이 앞서 설명한 QP의 안전 제약으로 연결됨.
이전 capsule 개념도와 Li et al. Fig. 1(a)의 로봇 SDF 그림은 출처 추적·재현용으로 보존하며 현재 21쪽에는 표시하지 않음. 원전 이미지 출처: https://arxiv.org/html/2307.00533v3/fig/robot_sdf_compressed.png. 해당 파일의 동일성 기록은 evidence/rdf_original_figure_audit.json에 보존. IK 탐색과 외부 장애물에 사용하는 capsule 모델은 실제 구현의 별도 역할로 유지.

24–27쪽 / All-link Sequential, 소요 시간, 두 link, oracle
All-link Sequential은 L=7로 지정된 frame 1–7의 link-pose subtask ST_{ee,1}부터 ST_{ee,7}을 수행한 뒤 ST_{ee,8}=T_{ee}를 실행하며, 총 8개 subtask로 구성. 마지막 첨자 8은 8번째 link가 아니라 실행 단계 번호. 관절 하나씩 독립적으로 IK 각도에 맞추는 방법이 아님.
두 link 제어는 2 ≤ a < b ≤ 6을 만족하는 10개 pair 중 하나를 선택하며 L=2. ST_{ee,1}은 link a(i_1=a), ST_{ee,2}는 link b(i_2=b), ST_{ee,3}=T_{ee}는 원래 EE goal을 추종하는 총 3개 subtask. 예를 들어 pair (3,5)에서도 첫 단계는 ST_{ee,1}이며 ST_{ee,3}이 아님.
논문 일반 정의의 mathcal S = (i1,...,iL,iL+1)는 최종 EE index까지 포함하며 Planar에서는 (1,2,3). Spatial의 보관 구현과 해당 논문 절에서 mathcal S_all = (1,...,7)은 EE 이전의 link frame 7개를 가리키며 그 뒤 final EE subtask가 추가됨. 발표의 실행 흐름은 이 포함 범위가 다른 link-index 열을 한 정의로 통합하지 않고 ST_{ee,1} → … → ST_{ee,L+1}=T_{ee}로 표시. 논문 파일이나 보관 구현의 sequence 정의는 수정하지 않음.
학습 후보 집합 Omega의 원소 S_k는 두 link subtask의 frame index pair이며 기존 기호를 유지. 선택한 pair로 ST_{ee,1}과 ST_{ee,2}를 구성하고 마지막 ST_{ee,3}=T_{ee}를 수행. 후보 index k, 실행 단계 s, link index i_s를 구분하며 S_k 자체를 ST 기호로 바꾸지 않음.
모든 단계에서 u는 R^7의 벡터. 선택하지 않은 link의 충돌 제약도 계속 유지.

모델은 실행 전에 pair를 선택하며, QP는 매 제어 주기 속도를 계산. 두 구조 설명 슬라이드는 각각 25초와 30초 배정.
Robot/goal encoder는 이 입력을 64차원 feature로 변환하고, 별도 projection으로 32차원 attention query를 생성. 첫 상자의 원시 입력, encoder feature, attention query는 서로 다른 단계. 슬라이드는 차원 숫자를 늘리지 않고 이를 화살표로 구분.

각 sigmoid 출력은 pair 성공 score. 모델은 task를 선택하고, 공통 QP가 속도를 계산.

28쪽 / Binary Cross Entropy (BCE) loss와 selection loss의 의미
한 episode의 후보 pair 번호를 k = 1,…,10, 성공 label을 y_k ∈ {0,1}, 모델의 logit을 a_k로 표기.
BCE에는 각 logit의 독립적인 sigmoid 출력 p̂_k = sigmoid(a_k) 사용. 여러 pair가 동시에 성공할 수 있으므로 성공 score의 합을 1로 제한하지 않음.
Episode별 Binary Cross Entropy (BCE) loss:
  ℓ_BCE = −(1/10) Σ_k [y_k log p̂_k + (1 − y_k) log(1 − p̂_k)].
각 pair의 성공·실패 label을 모두 예측하도록 학습하는 항.
Selection loss에는 같은 logit을 softmax로 정규화한 ω_k = exp(a_k) / Σ_j exp(a_j) 사용. Sigmoid score를 합으로 나누는 방식과는 다름.
성공 후보 집합 K⁺ = {k : y_k = 1}에 대해:
  ℓ_sel = −log(Σ_{k∈K⁺} ω_k), K⁺가 비어 있지 않은 경우;
  ℓ_sel = 0, 모든 pair가 실패한 경우.
성공 후보들의 softmax mass 합을 키우는 항. 여러 성공 후보 중 하나를 임의의 유일한 정답으로 지정하는 loss가 아님.
모든 pair가 실패하면 selection loss만 0이며, BCE는 계속 실패 label을 학습. 모든 pair가 성공한 경우에도 성공 후보의 mass 합이 1이므로 selection loss는 0.
최종 목적함수는 모든 학습 episode에 대한 평균:
  mathcal L(theta) = (1/N_tr) Σ_{n=1}^{N_tr} [ℓ_BCE,n + lambda_sel ℓ_sel,n], lambda_sel = 3.
N_tr는 학습 episode 수이며 평가 episode 수 N과 구분. BCE는 먼저 10개 pair에 대해 평균하고, 두 loss 모두 실패 episode를 포함한 전체 N_tr개 episode에 대해 평균. Selection loss의 분모를 성공 후보가 있는 episode 수로 바꾸지 않음.
구현은 수치 안정성을 위해 BCEWithLogits와 logsumexp 사용. 추론에서는 가장 높은 성공 score의 pair를 선택하며, softmax에서 확률적으로 샘플링하지 않음. Sigmoid, logit, softmax의 argmax는 동일.
현재 loss는 BCE와 성공 후보에 모이는 softmax mass를 키우는 selection loss의 합이며, 완료 시간을 직접 최적화하는 항은 없음. 성공 label에는 제한 시간 조건이 이미 포함되므로 현재 방법이 시간을 전혀 고려하지 않는다고 설명하지 않음. 이는 현재 모델에 대한 설명이며 35쪽의 향후 연구 항목으로 시간 목적함수를 제안하는 것은 아님.

Episode i에서 후보 k의 성공 label을 y_ik, Learned 선택의 성공 여부를 l_i라 두면 m_i = (1/10) Σ_k y_ik, d_i = l_i − m_i. 전체 성공률 차이는 (1/1,000) Σ_i d_i × 100%p. 후보 평균은 실행 가능한 단일 rollout이나 이진 성공 label이 아님.
Episode 1,000개를 복원 추출하며 각 episode의 열 개 후보 결과와 Learned 결과를 함께 유지. 복원 추출 10,000회, seed 20261023. 평균 차이 분포의 2.5번째 및 97.5번째 백분위수 사용. 정규분포 가정을 사용하지 않음. 한 episode의 열 개 결과가 상관되므로 10,000개의 독립 표본으로 bootstrap하지 않음.
이 구간은 후보 평균 대비 양의 차이를 나타내며 가장 좋은 고정 pair 대비 우월성을 뜻하지 않음. 95% 신뢰수준은 우리 방법이 실험의 95%에서 이긴다는 뜻이 아님. 개발 중 Test를 확인한 이력도 bootstrap으로 해소되지 않음.

A15 / 55쪽: Episode-Wise Gain over the Pair Mean
Episode별 d_i = l_i − (1/10) Σ_k y_ik의 분포와 평균을 제시. 후보가 모두 성공하거나 모두 실패하면 d_i = 0. 후보별 결과가 다를 때 모델이 성공 후보를 고르면 양수, 실패 후보를 고르면 음수. 일부 episode에서 손실이 있어도 전체 평균은 +0.057, 성공률 단위로 +5.70%p.
히스토그램의 빈도는 각 d_i를 갖는 실제 episode 수이나, 후보 평균과의 차이 자체는 −1부터 1 사이의 값. 소수의 평균 성공·손실 기여를 정수 episode 수로 표현하지 않음. 기존 고정 pair 대비 회복 95개/손실 73개를 평균 대비 비교에 재사용하지 않음.
95% CI [3.74, 7.65]%p는 위의 episode 단위 bootstrap 결과. 여러 후보의 상관관계를 유지하며 10,000개 pair 결과를 독립 시행으로 다루지 않음.

현재 논문과 발표의 기호 대응 — 2026-11-08
목표 pose: (p_d,R_d), 요구 실행 시간: T_d, 최종 위치·방향 허용 오차: delta_p, delta_o.
Spatial 목표 orientation error e_o는 relative unit quaternion vector epsilon_ee. Planar의 최종 orientation error는 wrap(psi_e − psi_d)이며 단위는 rad. Quaternion vector norm과 yaw 허용 오차의 수치 단위를 섞지 않음.
QP slack delta와 목표 허용 오차 delta_p, delta_o는 서로 다른 기호. IK 검증·link subtask 전환·최종 성공 평가의 tolerance도 역할이 다르므로 같은 수치로 일괄 치환하지 않음.
방법 QP의 현재 활성 CLF는 V_i, 감소율은 c_i. Link subtask ST_{ee,s}에서는 i=i_s로 두고, 마지막 ST_{ee,L+1}=T_{ee}에서는 최종 EE의 V_{ee}를 사용. A12도 이 구분을 명시하며 s를 link 번호로 대입하지 않음. 입력 가중행렬은 W_u(u는 upright 표기), joint-limit CBF gain은 alpha_j. Joint-limit bounds는 −alpha_j(q_j − q_j,min) ≤ u_j ≤ alpha_j(q_j,max − q_j), velocity bounds는 v_min,j ≤ u_j ≤ v_max,j. 13–15쪽의 실제 QP에 두 입력 제한을 명시하고 6쪽은 기본 CLF–CBF 결합 구조만 표시. A12 Common CLF–CBF QP는 논문의 공통 기본식을 표시하며 구현별 세부 제약과 구분. 배경 이론의 일반 CLF 감소율 c_V는 그대로 유지.
전체 문제 정의 A11의 안전 집합은 모든 충돌 barrier가 비음수인 영역과 q_min ≤ q ≤ q_max인 관절 허용 영역의 교집합. 충돌 여유만 만족하고 joint limit를 위반하는 상태를 안전 집합에 포함하지 않음.
그림과 결과의 기준: 저장된 궤적·시간·성공 label·성공률 불변. Planar 함수 값은 현재 정의로 다시 평가하며, 원래 제어 QP를 새 정의로 재실행한 결과는 아님.
논문 내부의 이전 기호가 남은 기호표·설명문·도함수는 현재 Method의 명시적 정의보다 우선하지 않음. 혼재 항목은 기호_동기화_기록.txt에 분리 기록하며 논문 파일 자체는 수정하지 않음.

17쪽 / 실행 전 준비와 제어 주기 반복
Safe IK와 subtask target·sequence 구성은 실행 전에 한 번 수행하며 준비 상자는 ST_{ee,1} → … → ST_{ee,L+1}과 초기 단계 s=1을 표시. 현재 ST_{ee,s}의 QP를 푼 뒤 전환/종료를 판정. 유지 분기에서만 유효한 u를 적용하고 q를 갱신한 뒤 같은 subtask의 QP로 복귀. 전환 분기에서는 입력 적용 없이 s를 증가시키고 같은 q에서 다음 subtask의 QP를 다시 계산. 최종 목표 도달 또는 종료 조건은 Stop으로 연결. A13에도 이 판정·분기 도식을 동일하게 사용. 이 공통 도식이 모든 모델에 같은 예외 정책을 적용하거나, 실행 불가능한 QP의 출력을 그대로 적용한다는 뜻은 아님. 세부 예외 처리는 앞의 13–15쪽 설명 및 A5 참조.

20쪽 / 모델 확장과 충돌 모델 비교
Planar의 링크도 논문에서 capsule-shaped로 정의. 표의 Capsule distances는 중심 선분까지의 거리에서 링크 반지름을 차감하는 모델을 뜻함. Spatial은 IK 탐색에 capsule을 사용하고, online 제어에서는 외부 장애물에 capsule, self-collision에 RDF를 사용. 두 모델의 차이를 capsule 사용 여부로 설명하지 않음. 근거: sections/Method/Planar_Control.tex의 Collision and Joint-Limit Barriers, Panda_Overview.tex, RDF_CBF.tex.
17쪽과 20쪽의 발화는 각각 25초로 유지. 모델 비교는 Spatial을 처음 소개하는 20쪽에 배치하고 기존 MuJoCo 그림 보존. 2쪽 사진 출처는 7 pt로 표시하며 사진·본문·캡션은 기존 크기 유지.

공통 구조와 동일 조건의 표현
16쪽 Unchanged QP objective, CBFs, and input limits는 subtask 전환 시 목적함수·CBF 함수·입력 제한의 구조를 유지한다는 뜻. q가 바뀌어도 제약의 수치나 최적 입력이 그대로라는 의미가 아님.
23쪽 Identical CLF form은 link subtask와 final EE subtask에 위치·quaternion 오차를 조합하는 동일한 식의 형태를 사용한다는 뜻. 각 subtask의 target·오차·함수 값·joint-space 지형이나 시간 변화는 다를 수 있음.
31쪽 identical success criteria는 방법마다 같은 성공 판정 기준을 적용한다는 뜻이며, 성공 episode 집합 자체가 같다는 뜻은 아님.
33쪽 Common initial state and each method’s final configuration은 공통 초기 조건과 각 rollout의 서로 다른 최종 configuration을 구분. 실패 예시 (3,5)의 종료 시각 120초와 Learned (5,6)의 종료 시각 23.42초를 그대로 유지.
