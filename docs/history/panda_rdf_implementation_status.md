별도 저장했다. 기존 `models/panda_rdf.*` 후보와 보고서는 변경하지 않았다.

- 재구성: 110,432개 면, 닫힌 표면, 일관된 면 방향. 원본의 열린 경계 변은 231개.

- 재구성 기준 RDF near 최대오차 **33.647 mm**로, 5 mm 검증 **실패**.
  공간 미분·확장 함수·경계 연속성 검사는 통과했다.

## 구현 및 테스트한 내용

- `src/safe_ik/domain/panda_rdf.py`: CPU 텐서곱 3차원 Bernstein 스칼라 평가,
  미터 단위의 해석적 미분, 배치 재귀 릿지 갱신, 표면 최댓값 기반 $C^1$ 구형 확장,
  수치적으로 안정적인 비정규화 soft-min, 결정적 top-k 선택, 이동 좌표계의 상대 점 Jacobian.
- `tests/test_panda_rdf_primitives.py`: 독립적인 수치 테스트 7개.

위의 기존 두 파일은 수정하지 않고 보존했다. 새 통합 테스트는 형상 추출,
정확한 삼각형 기준 거리, 실제 Panda의 상대 Jacobian과 집계된 관절 기울기,
학습 산출물 호환성, 질의점 갱신, 장애물 모델 보존, 초기 상태 거부,
IK 실패 보고, 완화 불가능한 CBF 제약 행, 비유한 QP 해 거부,
실제 별도 프로세스로 실행하는 IK 작업자의 산출물 로딩을 검증한다.

- 닫힌 손가락 XML, 그룹 2 시각화 메시 추출, 손과 손가락 병합,
  실제 인접 관계 매핑: 형상 9개와 비인접 쌍 28개.
- 최소 포괄 구, 공식 스캔·법선 방식의 데이터 생성, 재귀 릿지 학습 CLI,
  분산된 질의점 샘플링, 구 표면 최댓값 추정.
- 링크당 독립 검증점 5,000개의 삼각형 거리 검증, 미분·경계·관절 검사,
  버전이 명시된 NPZ/JSON 보고서, 검증 실패 시 사용을 거부하는 로딩.
- 자료형을 검증하는 YAML 설정, 자기 충돌의 기본 RDF 구현, 기존 캡슐 장애물 유지,
  안전 자세 IK·후보·병렬 작업자 연결, 자기 충돌 쌍에 별도로 적용하는 공통 CBF 이득.
- 안전하지 않은 궤적 초기 상태 거부, 수치·QP 실패 진단, 적분 전 장벽값 캐시,
  계산 단계별 시간 및 학습 산출물 출처 기록.
- `safe-ik-train-panda-rdf`, `make panda-train-rdf`, `make panda-validate-rdf`,
  학습 계수를 보존하는 질의점·확장 함수 갱신 옵션.

재귀 갱신은 [Li 외, ICRA 2024](https://calinon.ch/papers/Li-ICRA2024.pdf)의
알고리즘 1을 따른다. 확인한 공식 구현은
[RDF 커밋 dc08da7ec78e7cfb002f5a118d06d9eebbf9c37d](https://github.com/yimingli1998/RDF/tree/dc08da7ec78e7cfb002f5a118d06d9eebbf9c37d)다.
`bf_sdf.py`는 계수를 0, B를 I/1e-4로 초기화하고, 회당 표면 근처 표본 1,024개와
무작위 표본 256개로 200회 갱신한다. BP_8은 축당 기저 함수 8개, 즉 7차를 의미한다.
8차라는 뜻이 아니다. 기존 계산 모듈은 역행렬을 직접 구하는 대신 CPU에서
float64 선형계 풀이를 사용한다. 미터 단위 배치를 입력받아 학습 반지름으로
목표 거리를 정규화한다. 현재 9개 형상을 모두 학습한 후보는 생성했지만,
사용 승인을 받은 산출물은 아직 없다.

공식 `sample_sdf_points.py`는 mesh_to_sdf 스캔, 500,000개 표본 풀,
법선 기반 부호 판정, 정규화된 형상을 사용한다. 이를 합의된 시각화 메시와
외부 구 학습 영역에 적용했다. 이전의 독자적인 50,000개·60:40 학습 설정은
다시 도입하지 않았다. 적용상의 변경, 수치 방법, 호환성 규칙, 로그 의미는
[구현 상세](panda_rdf_implementation.md)에 정리했다.

CPU 비교는 BLAS 스레드 1개에서 예열 후 동일한 관절 상태 20개를 사용했으며,
외부 장애물 계산도 포함했다. RDF의 평균/95백분위 시간은 **30.88/39.11 ms**,
캡슐은 **1.40/1.48 ms**였다. 서로 다른 충돌 쌍 정책 때문에 RDF 제약 행은
48개, 캡슐은 55개다. 기존 제어 주기는 50 ms로 유지했다. 이 수치는 안전
평가기만 측정한 결과이며, 실시간 동작이나 궤적 안전성을 보장하지 않는다.

기존 RDF 테스트 7개와 새 통합 테스트 14개를 포함하여 **회귀 테스트 103개가
통과했다.** import 정렬, Python 서식 검사, `git diff --check`도 통과했다.
기본 RDF 설정으로 실제 CLI를 실행했을 때 link0의 검증 실패를 감지하여
시뮬레이션 플랜트 생성과 IK/QP 실행 전에 중단했다. 종료 코드는 2였고,
실패 요약을 `outputs/panda_rdf_rejection/` 아래에 저장했다.

닫힌 표면이 아닌 시각화 메시의 거리 부호에는 여전히 경험적 판정 규칙을
사용한다. 위상 진단용으로 같은 위치의 정점을 합치면 link1과 link2는 닫힌
표면이지만 나머지 조립 형상은 그렇지 않다. 이를 자동으로 보정하지 않았다.
큰 오차를 모두 부호 모호성으로 설명할 수는 없다. link1/link2도 최악 표본에서
부호가 일치하는데 거리 기준을 초과했다. 보고서에는 최악 표본의 좌표,
예측 거리, 기준 거리를 보존했다.

## 남은 장애

검증을 통과한 학습 산출물이 여전히 필요하다. 시각화 형상의 부호 있는 기준
거리와 공식 학습 설정을 검토한 뒤 명시적으로 재학습해야 한다.
자동 파라미터 탐색, 안전 기준 완화, 메시 보정, 캡슐로의 자동 전환,
검증에 실패한 모델을 사용하는 실제 궤적 실험은 수행하지 않았다.
궤적 안전성·성능 비교는 기존 합격 기준을 통과할 때까지 보류한다.
후속 사용자 요청으로 오프라인 학습에는 선택적 GPU 경로를 추가했다.
같은 link4 BP_10 입력의 계산시간·수치 일치 재현이며, 검증 기준 완화나
GPU 제어기 도입이 아니다. 사용법은 [구현 상세](panda_rdf_implementation.md)를 따른다.

## 외부 점만 평가하는 기준으로 재검증 (2026-09-28)

사용자 결정으로 $d_{\mathrm{mesh}} < 0$인 내부 점을 정확도 평가에서 제외했다.
여기서 내부는 기준 mesh의 물체 내부이며, RDF 학습 구 내부를 뜻하지 않는다.
최대오차 합격 기준은 $0 \le d_{\mathrm{mesh}} \le 60\,\mathrm{mm}$에서 5 mm로 유지한다.

#### 부호 규칙과 적용 범위

- 새 오프라인 기준 판정 버전은
  `triangle_normal_fixed_ray_integer_winding_v1`이다. 최근접 삼각형 거리와
  법선 분기, 고정 1차 광선의 정·역방향 parity, 교차점 없는 광선의 외부 판정,
  기존 표면 허용오차 1e-8m의 nonpositive 규칙은 유지한다.
- 기존에 난수 방향으로 재시도하던 **교차점 있는 정·역방향 광선의 불일치**만
  닫힌 일관 방향 mesh의 삼각형 입체각 합으로 대체한다. 각 점에 대해 고정된
  면 순서로 합산하며 RNG를 사용하지 않는다.
  [Generalized Winding Numbers 원 논문](https://igl.ethz.ch/projects/winding-number/)의
  winding 개념을 사용하되, 모든 점의 기존 판정을 새 방법으로 바꾸는 것은 아니다.
- winding 값이 정수에서 1e-5 이내인지 먼저 검사한 뒤 절댓값 0.5 초과를 내부로
  판정한다. 1e-5는 무차원 정수 일관성 검사이며 거리 기준 완화가 아니다.
  mesh가 닫히지 않았거나 방향이 불일치하거나 winding이 모호하면 예외로 중단한다.
  임의 부호 부여나 검증점 제외로 우회하지 않는다.
- 외부 양수/내부 음수, 10mm 거리 기준, 실제 학습점·배치·계수, 음수 RDF 예측의
  평가 포함 규칙은 유지한다. 수정 대상은 오프라인 기준 거리 계산이며 기존
  artifact의 메타데이터를 덮어쓰거나 실행 로더의 승인 조건을 바꾸지 않는다.
  재현 가능한 기준이라는 뜻이지 실제 물체나 연속 공간에 대한 안전 보장은 아니다.

### 2026년 9월 30일 과대·과소평가 한도 분리 및 기존 후보 재검증

사용자가 승인한 비대칭 기준을 설정·검증·로더에 적용했다. 최종 hand 가중치4
후보의 **계수는 그대로이며**, 성능 개선이나 재학습이 아닌 승인 기준 변경이다.
이 절은 새 정책에 따른 별도 결과다. 위의 대칭10mm 기준 미달, 과거 study의
감사 실패와 원본 보고서·완료 상태는 소급 수정하지 않았다.

외부 near 영역에서 signed error를 $e = f_{\mathrm{RDF}} - d_{\mathrm{mesh}}$ (RDF 예측에서 기준 mesh 거리를 뺀 값)로 정의한다.
새 거리 판정은 **$-0.020\,\mathrm{m} \le e \le +0.010\,\mathrm{m}$**이며 등호를 허용한다.

- `error_margin=0.010m`: 과대평가 허용 한도이자 기존 CBF 오차 여유다.
- 새 `underestimation_limit=0.020m`: 과소평가에 대한 검증·성능 한도만 뜻한다.
  생략 또는 null이면 과거 대칭 기준을 유지한다.
- 물리 여유30mm, 유효 여유40mm, soft-min 오차5mm, 반경·정규화·queries와
  제어기 수식은 변하지 않는다. 과소평가20mm를 CBF 여유에 더하지 않았다.
- 평가 마스크는 $0 \le d_{\mathrm{mesh}} \le 60\,\mathrm{mm}$다. 내부점만 제외하고 음수
  RDF 예측은 계속 포함한다. 미분·확장 경계·관절 gradient 검사도 유지한다.

새 정책명은 `asymmetric_exterior_near_error_v1`이다. 절대오차 통계는 보존하고
과대/과소 최대값, 각 한도 초과 수 및 과거 절대10mm 초과 수도 따로 기록한다.
