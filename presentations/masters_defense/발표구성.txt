발표 제목: Collision-Aware Sequential Kinematic Control of Robot Manipulators Using Control Barrier Functions and Supervised Learning-based Task Sequencing

목표 발화 1,140초 + 전환과 호흡 60초.
본문 36장 + 보충 자료 21페이지 = 청중용 57페이지.
발표자용 93페이지. Appendix 목차와 A1–A17 포함; A7 참고문헌은 4페이지.

구성 원칙
- 로봇팔 작업 전반에서 안전한 목표 도달의 필요성으로 시작하고, 자율실험실은 한 가지 실제 예시로 제시. 성능 수치는 결과 장에서 제시.
- Kinematic control의 상태·입력·task error를 정의한 뒤 CLF, CBF, QP를 설명.
- 관련 연구의 대응 → Direct 실패 사례 → 인간의 장애물 회피 연구에서 얻은 팔 자세·subgoal의 설계 직관 → 논문 3장의 방법론 구성 → 제안 방법 설명 순서.
- 7쪽에서 관련 연구의 제어 설계 초점 / 운동 유도 방식을 비교한 뒤 8쪽에서 Direct의 정의와 실패 사례로 문제를 구체화. 연구 질문은 로봇팔의 kinematic structure를 목표 도달에 어떻게 활용하는가. 9쪽 직관 → 12쪽 IK posture에서 link subtask target·순차 subtask 구성 → 17쪽 전체 알고리즘으로 연결. 7·8쪽에서는 Sequential 아이디어를 미리 설명하지 않으며, QP 형식 유지와 잔여 평형점을 비교 우위로 사용하지 않음.
- 11–15쪽은 약 48 mm의 동일 그림 영역과 위치·시점·축척 유지. 초기 상태·목표·장애물에 IK 정보를 추가한 뒤 저장된 실행 상태를 이어서 제시하고, 실행 단계에서는 동일 QP의 활성 CLF constraint만 강조.
- 17쪽은 실행 전 safe IK·subtask target·sequence 구성과 제어 중 QP·전환/종료 판정의 반복을 구분. Continue는 유효한 u 적용·q 갱신 후 같은 task의 QP로 복귀, Advance는 입력 적용 없이 같은 q에서 다음 task의 QP 계산, Stop은 실행 종료. 모델별 비교는 20쪽으로 이동.
- 20쪽은 기존 MuJoCo 그림과 Planar/Spatial 비교표로 확장을 소개. Planar의 위치·yaw와 Spatial의 위치·quaternion 기반 task, 두 모델의 capsule 거리 및 Spatial self-collision용 RDF를 구분. 21쪽은 복잡한 2차원 물체의 표면 query와 거리장 평가를 CBF 구성에 연결. 두 link의 운동을 반영하는 이유는 CBF gradient 설명에서 연결.
- 용어: main regulation task / link subtask / final EE subtask / subtask target. Direct는 EE regulation만, Sequential은 link subtasks 뒤 final EE subtask 수행. Spatial Manipulator / 10-pair mean / Learned selection / CLF constraint / subtask transition 표기 유지.
- 핵심 메시지는 필요한 슬라이드의 상단에 검은 글자로 배치. 슬라이드 글자 크기 규칙은 본문 10pt, 제목 14.4pt.
- 부제는 논문 chapter/section/subsection 번호와 제목 기준. 10쪽은 3장의 TOC short title 사용. 3.2.1은 사용자 지정 표시명 Decomposition of Regulation Task를 사용하고 실제 장명 Intermediate Targets and Sequential Tasks를 메타데이터에 보존. 3.3.2의 Intermediate Position Tasks and Final Pose Task는 원래 장명 그대로 유지. Conclusion과 Bibliography는 별도 표제; 기종명은 Spatial Manipulator로 표기.
- 점 진행 표시는 본문 6개 구간이며 Background 4–8쪽, Planar 9–19쪽. 표지는 제외하며 보충 자료는 별도 목차와 복귀 링크 사용.
- 성공 기준과 수치·근사 모델의 가정은 한국어 대본 및 질의응답 메모에 보존.
- 공통 구성은 Common, 동일한 함수 형식·성공 판정은 Identical, 동일 episode에 대한 통계 비교는 Paired로 표현. A6의 Success in both는 467 episodes와 4,792 episode–pairs를 구분하며, Common obstacle encoder는 모든 장애물에 동일한 파라미터를 적용한다는 의미.

기호: 현재 논문 Method의 명시적 정의와 동기화. Planar CLF 그림은 보관 궤적에 새 함수를 재평가한 값이며 새 QP 실행 결과가 아님. 자세한 대응과 혼재 항목은 기호_동기화_기록.txt 참조.

해석 원칙
- Menger et al. (2012)의 초기 팔 자세 효과와 Lukic et al. (2014)의 subgoal 해석을 9쪽의 문헌 근거로 사용. Lukic의 인간 동작 3패널 사진을 작은 문헌 예시로 제시하고, 아래 세 자세 그림은 본 연구의 개념도로 구분. 사진은 본 연구의 실험이나 IK subtask 검증 결과가 아니며 어깨를 먼저 움직이는 보편적 인간 운동 법칙도 주장하지 않음. IK 해에서 link subtask target을 구성하는 절차는 이 관점에서 착안한 본 연구의 설계.
- Gonçalves는 manipulator 실험이 있으며 기본 이론의 짝수 차원 조건과 홀수 차원 확장을 구분.
- IK configuration은 subtask target의 출처이지 실행 경로가 아님. 전체 joint velocity와 모든 충돌 제약은 계속 사용.
- A3·A4의 미분 성질은 각각 clipping 전 보조항과 고정 query 집합에 대한 성질. A5의 stall 조건은 모델별로 구분. A9의 불변성은 충돌·관절 barrier, 절대연속 궤적과 실제 속도의 CBF 조건, 유한 task 전환을 전제로 하며 A11의 안전 집합에도 joint limit 포함.
- A12는 논문의 공통 기본 QP, A13은 본문 17쪽의 판정·분기 도식. A14는 Train-best fixed pair (3,5)와의 추가 참고 비교(+2.20%p, CI [−0.30, 4.70]%p)와 기록된 평가 한계를 설명. 평균 대비 개선을 고정 pair 대비 우월성으로 일반화하지 않으며 35쪽의 실제 로봇 실험과 뉴럴넷 기반 sequencing 개선으로 연결.
- 26쪽은 열 개 후보의 평균, 27쪽과 A2는 평균·Validation 사후 최고 단일 pair·oracle로 선택 가능성을 설명. 31쪽과 34쪽도 10-pair mean을 기준으로 Test 55.20% → 60.90%, +5.70%p / CI [3.74, 7.65]%p를 제시. 31쪽에는 Test에서 관측된 최고 단일 pair (3,5)의 58.70%(587/1,000)도 표시. 이 pair와의 차이는 +2.20%p이며 별도 CI가 0을 포함하므로 우월성 주장으로 확대하지 않음.
- 33쪽은 열 개 후보 중 (5,6)만 성공하는 episode를 선택 예시로 설명. (3,5)는 실패 rollout 예시이며 평균 baseline의 실행 궤적을 뜻하지 않음.
- A15는 d_i = Learned 성공 여부 − episode i의 10-pair mean 분포와 전체 평균을 제시. 신뢰구간은 episode 단위 복원 추출 10,000회이며 10,000개 pair 결과를 독립 표본으로 취급하지 않음.
- 사후 oracle, 학습 정책의 Test 결과, 서로 다른 공동 성공 집합의 시간 비교를 구분.
- 본문 시간 비교는 All-link 대비 단계 축소의 효과. A6은 같은 단계 수인 후보 평균과 Learned의 공동 성공 4,792개 episode–pair 결과(609개 episode), 평균 시간 36.05/36.20초를 제시. 성공 pair 수만큼 각 episode가 반복되는 조건부 집계이므로 학습 자체의 속도 향상으로 해석하지 않음.
